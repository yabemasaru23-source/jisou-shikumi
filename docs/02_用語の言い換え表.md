# 用語の言い換え表

「会社が自走する仕組みづくり」では、専門用語をワクワクする、小学生でもわかる言葉に言い換えます。
本文では**新しい呼び名**を使い、専門用語は必要なときだけ「（専門用語では〇〇といいます）」と一度だけ添えます。

## 全体・理念

| 旧（専門用語） | 新しい呼び名 | ひとことで言うと |
|---|---|---|
| 仕組み経営 | 会社が自走する仕組みづくり | 社長がいなくても会社が走り続けるようにすること |
| 人依存 → 仕組み依存 | 「あの人頼み」→「仕組みで回る」 | |
| 仕組み化診断 | 自走度チェック | 会社がどれくらい自分で走れているかの健康診断 |
| VPP（価値観・情熱・目的） | 私の人生の羅針盤 | 何のために生きて、何のために経営するのか |
| 組織の機能不全（DBO） | リーダーのクセ発見 | 知らないうちに会社の足を引っぱっている自分のクセ |
| 時間管理＆働き方改革／仕事環境の整理整頓 | 時間と机のお片づけ | 大事なことに使う時間と場所をつくる |
| コアバリュー | わが社の合言葉 | 迷ったときに立ち返る、みんなで大切にすること |
| ビジョン | 会社の夢の完成図 | 10〜20年後、会社がどんな姿になっていたいか |

## 戦略

| 旧（専門用語） | 新しい呼び名 | ひとことで言うと |
|---|---|---|
| SO（戦略的目標） | 3年後のゴール | 夢に向かう途中の、3年後の旗（数字1つ） |
| KSI（戦略的指標） | 8つの作戦 ＋ ものさし | ゴールにたどり着くための作戦と、進み具合をはかるものさし |
| SOマップ | **未来の作戦マップ** | ゴール・8つの作戦・64個の仕組みを1枚にした地図 |
| 組織戦略 | 3年後のチーム図 | ゴールを達成したときのチームの形 |
| 成果定義文 | 役割のひとこと | その役割が「何を生み出すためにあるのか」を1文で |
| 職務契約書 | 役割の約束書 | その役割の目的・仕事・基準を、本人と上司で約束する紙 |
| 仕組み化戦略（仕組み開発ワークシート） | 仕組みの宝さがし（仕組み一覧表） | 会社に必要な仕組みを全部出して、作る順番を決める |

## 8つの作戦の「視点」（旧：バランス・スコアカードなど）

| 旧（専門用語） | 新しい呼び名 | 自分に聞く質問 |
|---|---|---|
| 財務の視点 | お金 | 会社のお財布はどうなっていたい？ |
| 顧客の視点 | お客様の笑顔 | お客様にどう喜ばれていたい？ |
| 業務プロセスの視点 | 仕事のやり方 | どんなムダのない仕事ぶりになっていたい？ |
| 学習と成長の視点 | 人の成長 | 仲間はどう成長していたい？ |
| ブランド | 評判とファン | 町の人になんて言われていたい？ |
| セールス | 売れる力 | どんなふうに買ってもらえていたい？ |
| マーケティング | 知ってもらう力 | どうやって見つけてもらっていたい？ |
| 価値提供 | 商品・サービスの自慢 | どんな「これがうちの自慢！」を届けていたい？ |
| 組織 | チームと職場 | どんな職場で働いていたい？ |
| リーダーシップ | 次のリーダー | 誰が会社を引っぱっていたい？ |

## 経営を回す

| 旧（専門用語） | 新しい呼び名 | ひとことで言うと |
|---|---|---|
| 経営チーム | 作戦会議のメンバー | 社長ひとりで決めず、一緒に会社の舵を取る仲間 |
| 会議システム（経営のリズム） | 会社のリズム | いつ・誰と・何を話すかの決まりごと |
| BDM（全社会議） | 全員集合ミーティング | 会社の夢と方針をみんなで共有する場 |
| EDM（1on1） | 1対1の応援面談 | 上司が部下の成長を応援する定期面談 |
| 委任システム | 任せ方のルール | どこまで任せて、どう報告してもらうか |
| 協業関係のガイドライン | チームの約束ごと | 上司と部下、部署と部署の気持ちよい関わり方 |
| 運営マニュアル | 会社の取扱説明書 | 全員が知っておくべき会社のこと・ルールを1冊に |
| 作業マニュアル | 仕事のレシピ | 誰が作っても同じ味になる、仕事の作り方 |
| 仕組み依存文化への変革 | 変化を仲間に広げる | 反対や不安を味方に変えて、会社を変えていく |
