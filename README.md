# 会社が自走する仕組みづくり

社長がいなくても会社が走り続けるための、20章の学習ワークサイトです。
考え方を読み、質問に答えていくと「わが社の設計図」ができあがります。

- 入力した内容は、見ている人のブラウザの中だけに自動保存されます（サーバーには送られません）
- 「保存・書き出し」から、続きを再開できるファイル（JSON）と Excel ファイルを書き出せます
- 「わが社の設計図」ページから、書いた内容をまとめて印刷・PDF化できます

## フォルダ構成

```
shikumi-keiei/
├─ index.html              サイトの入口
├─ assets/
│   ├─ app.css             見た目
│   └─ app.js              動き（章の読みこみ・入力欄・保存・書き出し）
├─ content/
│   ├─ chapters.json       20章の一覧（章を追加したら "file" にファイル名を書く）
│   ├─ chapters/           各章の本文（Markdown）
│   └─ example/company.md  記入例の架空企業「ひだまりケア株式会社」の設定
└─ docs/
    ├─ 01_設計書.md
    └─ 02_用語の言い換え表.md
```

## 文章を直すには

`content/chapters/` の Markdown ファイルをメモ帳などで開いて、文章を書きかえて保存するだけです。
プログラムを触る必要はありません。

### 入力欄（ワーク）の書き方

本文の中で ```` ```work ```` と ```` ``` ```` で囲んだ部分が、サイトでは入力欄になります。

````
```work
id: 06.so.why                 ← 入力欄の名前（サイト全体で重ならないようにする）
type: textarea                ← 入力欄の種類
label: どうしてこのゴールなのですか？
hint: 社員さんに話すつもりで書いてみてください。
example: 「この町で年をとるのが…」   ← 「記入例を見る」で表示される
```
````

| type | 入力欄 |
|---|---|
| text | 1行の文字 |
| textarea | 複数行の文章 |
| number / date | 数字 / 日付 |
| select | ひとつ選ぶ（`options:` に選択肢） |
| checklist | いくつか選ぶ（`options:`、`min:`、`max:`） |
| table | 表（`columns:` に列名。`rows:` で行見出し固定、`min_rows:`・`max_rows:`、`from:` で前の答えを1列目に入れる） |
| form | 項目の集まり（`fields:`。`repeat: true` で何枚でも） |
| orgchart | チーム図（表に入力すると図ができる） |
| scale | 点数チェック（`groups:`、`compare_with:` で前回と比べる） |
| mandala | 9マス・81マスのマップ |
| display | 前の章の答えを表示する（`source:` に入力欄の名前） |

## パソコンで試しに見るには

このフォルダで次のコマンドを実行し、ブラウザで `http://localhost:8000` を開きます。
（ファイルをダブルクリックして開くだけでは、章が読みこめません）

```bash
python -m http.server 8000
```

## GitHub Pages で公開するには

1. GitHub で新しいリポジトリを作る（例：`jisou-shikumi`）
2. この `shikumi-keiei` フォルダの中身をすべてアップロードする
3. リポジトリの **Settings → Pages** で、Branch を `main`、フォルダを `/ (root)` にして保存
4. 数分後に `https://（ユーザー名）.github.io/jisou-shikumi/` で見られるようになります

公開後に文章を直したいときは、GitHub 上で Markdown ファイルを編集して保存すれば、数分でサイトに反映されます。

## 著作権について

本教材の文章・設問・記入例は、すべてオリジナルで書き下ろしたものです。
記入例に登場する「ひだまりケア株式会社」と人物は架空であり、実在の企業・人物とは関係ありません。
