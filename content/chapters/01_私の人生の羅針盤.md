## ① この章でできるようになること

- 自分が**「何のために生きて、何のために経営しているのか」**を、1文で言えるようになる
- 迷ったときに立ち返る**「大切にしている価値観」**を、3〜5つの言葉にできる
- 人生の目的を、**6か月後・1年後・5年後・10年後の「人生計画表」**に落としこめる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 毎日いそがしく走っているのに、「自分は何のためにこんなにがんばっているんだろう」とふと思う
- 大事な決断のたびに迷って、あとから「本当にこれでよかったのかな」と気になる
- 会社のことばかり考えて、家族や自分の体のことは、いつも後回しになっている
- 「会社の理念をつくろう」と思っても、どこかで見たような言葉しか出てこない

私が社長さんとお話ししていて気づいたのは、**会社のことはスラスラ話せるのに、自分自身のことになると急に言葉につまる方がとても多い**ということです。
「社長はなぜこの会社をやっているんですか？」とたずねると、少し考えてから「……食べていくため、ですかね」と笑う方もいます。

それは、まったく悪いことではありません。毎日が本当にいそがしいのですから。
でも、社長の心の中に「何のために」がないままだと、会社も同じように「何のために」がないまま走ることになります。
会社は、社長の考え方をうつす鏡のようなものだからです。

### 目指す姿

- 大きな決断のとき、「私の羅針盤にてらすと、こっちだな」と、自分で納得して選べる
- 社員さんに「社長はなぜこの会社をやっているんですか？」と聞かれたら、自分の言葉で熱く話せる
- 仕事だけでなく、家族・健康・趣味もふくめて、「こんな人生にしたい」が見えている

## ③ 考え方

### 1. 地図より先に「羅針盤」を持とう

山や海で道に迷わないためには、2つの道具が必要です。
**地図**と**羅針盤（方位磁石）**です。

地図は「どんな道があるか」を教えてくれます。
でも、地図だけでは「自分がどっちに進みたいのか」はわかりません。道がたくさんあるほど、かえって迷ってしまいますよね。

羅針盤は、どんなに霧が出ていても、いつも同じ方角を指してくれます。
だから、道がわからなくなっても「とにかく北へ」と進むことができます。

| 道具 | この教材でいうと | 教えてくれること |
|---|---|---|
| 🧭 羅針盤 | **私の人生の羅針盤**（この章） | 自分はどっちに進みたいのか |
| 🗺️ 地図 | 会社の夢の完成図、未来の作戦マップ（第5・6章） | 会社はどこを目指して、どの道を通るのか |

第6章の「未来の作戦マップ」は、会社の地図です。
でも、その地図を描くのは社長のあなたです。**羅針盤を持たずに地図を描くと、どこかで聞いたような、借りものの地図になってしまいます。**
だから、この教材は「会社」ではなく「あなた自身」からスタートします。

### 2. 羅針盤は「3つの針」でできている

この章でつくる羅針盤には、3つの針があります。

| 針 | 自分に聞く質問 | ひとことで言うと |
|---|---|---|
| 🎯 **人生の目的** | 私は何のために生きている？ | 人生をかけて、いちばん実現したいこと |
| 💎 **大切にしている価値観** | 私がゆずれないことは何？ | 迷ったときの判断の決まりごと |
| 🔥 **情熱** | 私の心が熱くなるのはどんなとき？ | 目的に向かって走るためのエネルギー |

3つはバラバラではありません。
**情熱**を感じる瞬間をふり返ると、**価値観**が見えてきます。価値観がそろうと、**目的**が1文にまとまります。
この章のワークも、この順番で進めていきます。

![羅針盤の3つの針：情熱をふり返ると価値観が見え、価値観がそろうと人生の目的が1文になる](assets/img/ch01-needles.svg)

> 💡 専門用語では、この3つをまとめて「VPP（価値観・情熱・目的）」といいます。この教材では「私の人生の羅針盤」と呼んで進めていきます。

### 3. 答えは「これから」ではなく「これまで」の中にある

「あなたの人生の目的は何ですか？」と、いきなり聞かれても困りますよね。
私も最初に聞かれたときは、頭がまっ白になりました。

実は、人生の目的は、どこか遠くにある「正解」をさがしに行くものではありません。
**あなたがこれまで生きてきた中に、もう答えのかけらが落ちている**のです。

そのかけらを見つけるコツは、**心が大きく動いた瞬間**をふり返ることです。

- 😊 **心からうれしかったこと**：そこには、あなたが「大事にしたいもの」がかくれています
- 😣 **くやしかったこと、腹が立ったこと**：そこには、あなたが「ゆるせないもの」＝ゆずれない価値観がかくれています

たとえば「お客様に名前で『ありがとう』と言われて、涙が出るほどうれしかった」人は、**人とのつながり**を大切にしているのかもしれません。
「ちゃんとやった人が損をするのを見て、腹が立った」人は、**公平さ**や**正直さ**を大切にしているのかもしれません。

うれしかったこと、くやしかったこと、どちらもあなたの羅針盤の材料です。
いい話だけを集めようとしなくて大丈夫ですよ。

### 4. 「80歳の誕生日会」を想像してみよう

もう1つ、目的を見つけるのに役立つ方法があります。
**ずっと先の未来から、いまの自分をふり返ってみる**ことです。

あなたの80歳の誕生日会を想像してみてください。
家族、仲間、社員さん、お客様、長いつきあいの友だちが集まって、ひとりずつ、あなたにお祝いのスピーチをしてくれます。

> 「〇〇さんのおかげで、〜〜になりました。本当にありがとう」

その「〜〜」に、どんな言葉が入っていたら、あなたは一番うれしいですか？

私がこの質問をすると、多くの社長さんが「売上がいくらだった」とは言われたくない、とおっしゃいます。
言われたいのは、「あなたがいてくれたから、私の人生が変わった」のような言葉なんですね。
**その言葉こそが、あなたが本当に目指している人生のゴールです。**

### 5. 「いやなこと」を裏返すと、「ほしいもの」が見えてくる

「何がしたいか」はわからなくても、「何がいやか」はすぐに言える、という方も多いです。
それでまったくかまいません。**いやなことを裏返せば、ほしいものが見えてくる**からです。

| 望まないもの（いやなこと） | 裏返すと…… | 望むもの（ほしいもの） |
|---|---|---|
| 毎日同じことのくり返し | → | 新しいことに挑戦できる毎日 |
| 家族と夕ご飯を食べられない | → | 週に3日は家族と夕ご飯を食べられる暮らし |
| うそやごまかしが通る職場 | → | 正直な人が報われる職場 |

「お金の心配がまったくなくなって、明日から働かなくてよくなったら、何をしますか？」と自分に聞いてみるのもおすすめです。
それでもやりたいことは、あなたが心から大事にしていることです。

### 6. 価値観は「ことば」＋「行動」で書く

価値観を書くとき、いちばん多い失敗は**「立派なことば」だけを並べてしまうこと**です。

> ✕「誠実」「感謝」「挑戦」

どれもすてきな言葉ですが、これだけでは、あなたらしさが伝わりません。
「誠実」の意味は、人によってまったくちがうからです。

そこで、**「私にとってどういう意味か」と「それを守っている私は、どんな行動をしているか」**をセットで書きます。

| | ことば | 私にとっての意味 | 守っているときの行動 |
|---|---|---|---|
| ✕ | 誠実 | （書いていない） | （書いていない） |
| ◯ | 正直でいること | 自分に都合の悪いことほど、先に伝える | ミスがあったら、その日のうちに自分から報告する |

行動まで書いておくと、「いまの私は、価値観どおりに動けているかな？」とふり返れるようになります。

ことばが思いうかばないときは、次の「ことばカード」から、ピンとくるものを選んでみてください。

| | | | |
|---|---|---|---|
| 正直 | 家族 | 挑戦 | 感謝 |
| 自由 | 成長 | 安心 | 健康 |
| 仲間 | 人の役に立つ | 楽しさ | 思いやり |
| 責任 | 学び | こだわり | ゆとり |

**数は3〜5つ**がおすすめです。
10個も並べると、ぜんぶ大事すぎて、いざというときに決められなくなってしまいます。
「どうしても1つしか選べないとしたら？」と自分に聞いて、しぼりこんでみましょう。

### 7. 人生の目的は「1文」にまとめる

材料がそろったら、人生の目的を1文にまとめます。
型は、これだけです。

> **「（だれ・なに）を、（どんな状態）にする。そのために、（私が）〇〇しつづける」**

| | 人生の目的の例 | どこが惜しい？／どこがいい？ |
|---|---|---|
| ✕ | 会社を大きくして、売上10億円にする | それは会社の目標。会社がなくなったら、目的もなくなってしまう |
| ✕ | 幸せな人生を送る | みんなに当てはまって、あなたらしさがない |
| ◯ | 年をとることを「こわいこと」から「楽しみなこと」に変える。そのために、自分が関わる人と町を元気にしつづける | だれに・何を・どうしたいかがはっきりしていて、仕事でも家族でも使える |

いい目的かどうかは、次の4つで確かめられます。

1. **自分の言葉になっている**：声に出して読んで、照れくさいけれど、うそがない
2. **胸が熱くなる**：読むと「よし、やろう」と力がわいてくる
3. **仕事以外にも通じる**：家族や友だちとの関わりにも、そのまま当てはまる
4. **10年たっても変わらなさそう**：一時の目標ではなく、ずっと向かっていく方角になっている

最初から完ぺきな1文は、まず書けません。私自身、何度も書き直してきました。
**今日の時点での「いちばん近い1文」**で大丈夫です。

### 8. 人生計画表で、目的を「いつまでに」に落としこむ

羅針盤で方角が決まったら、最後に**人生計画表**をつくります。
目的を、具体的な「いつまでに、どうなっていたいか」に落としこむ表です。

| | 6か月後 | 1年後 | 5年後 | 10年後 |
|---|---|---|---|---|
| 💴 収入 | | | | |
| 💼 仕事 | | | | |
| 🌱 自己成長 | | | | |
| 👨‍👩‍👧 家族や人間関係 | | | | |
| 🍎 健康 | | | | |
| ✈️ 趣味や旅 | | | | |

書くときのコツは3つです。

- **10年後から先に書く**：遠い未来から逆算すると、「じゃあ5年後はここまで」「1年後はここまで」と決めやすくなります
- **仕事以外の段も、同じくらい大事にする**：社長さんの表は、「仕事」の段だけびっしりで、「健康」や「家族」が空っぽになりがちです。でも、体をこわしたら、会社の夢もかないません
- **6か月後は「本当にやること」を書く**：「〇月の家族旅行を予約する」くらい具体的にすると、実際に動き出せます

この表は、一度書いたら終わりではありません。**半年に1回見直して、書き直していく**ものです。

### 9. 社長の羅針盤は、会社の羅針盤になる

最後に、この章が次の章とどうつながるかをお話しします。

![社長の羅針盤から会社の地図へ：私の人生の羅針盤 → わが社の合言葉 → 会社の夢の完成図 → 未来の作戦マップ](assets/img/ch01-flow.svg)

社長の価値観は、そのまま会社の合言葉にはなりません。会社は社長ひとりのものではないからです。
でも、**社長が自分の価値観を知らないまま合言葉をつくると、社長自身がその合言葉を守れない**ということが起こります。
社員さんは、社長が言っていることよりも、社長がやっていることをよく見ています。

まず自分の羅針盤を持つこと。それが、会社が自分で走り出すための、いちばん最初の土台になります。

```work

type: table
label: これまでの人生で、心が大きく動いた瞬間を書き出してください
```


### ステップ6：人生計画表をつくる

```work
id: 01.lifeplan
type: table
label: 私の人生計画表
rows: [収入, 仕事, 自己成長, 家族や人間関係, 健康, 趣味や旅]
columns: [6か月後, 1年後, 5年後, 10年後]
hint: 10年後の列から先に書いて、逆算していきましょう。「仕事」以外の段も空けずに書くのがポイントです。6か月後の列は「本当にやること」を具体的に書きます。空いているマスがあっても大丈夫。半年に1回見直していきます。
example:
  - [役員報酬はいまのまま。職員さんのお給料アップを先にする, 役員報酬はいまのまま。貯金の目標を決めて、毎月積み立てを始める, 役員報酬をいまの1.3倍に。職員さんの平均年収も地域の介護職でトップクラスに, 老後の暮らしの心配がない蓄えができている]
  - [未来の作戦マップを完成させて、現場に入る日を月の半分から月5日に減らす, 拠点長会議が私ぬきでも回っている。3つ目の拠点の準備を始める, 3つ目の拠点が黒字で回っている。5拠点目の準備中, 6拠点・職員120人。「この町で年をとるのが楽しみ」と言われる会社になり、次の社長を育てている]
  - [経営の勉強会に毎月1回参加する, 人に任せる力をつける。拠点長を育てる研修を自分で1回やってみる, 地域の介護事業者の集まりで、自分たちの仕組みを発表する, 町の人と一緒に、お年寄りと子どもが集まれる場所をつくる活動をしている]
```

#### 記入例：日向陽子社長の「私の人生の羅針盤」

**🎯 私の人生の目的**

**💎 大切にしている価値観**

**🔥 私の心が熱くなるとき**

## ⑤ できあがるもの

入力した内容から、次のものが自動でできあがります。

## ⑦ 次の章へ

羅針盤ができると、「自分はこっちに進みたい」という方角が見えてきます。
でも、進みたい方角がわかっても、**知らないうちに自分のクセが足を引っぱっている**ことがあります。
「任せたはずなのに、つい口を出してしまう」「なんでも自分で決めてしまう」――心当たりはありませんか？

次の**第2章「リーダーのクセ発見」**では、会社が自分で走るのをじゃましている、社長自身のクセを見つけていきます。

> 必修の章だけを進める方は、次は**第4章「わが社の合言葉」**です。
> この章で書いたあなたの価値観を手がかりに、今度は「会社のみんなで大切にすること」を言葉にしていきます。
> 社長の価値観と、会社の合言葉がつながっていると、社長自身がいちばんの「合言葉のお手本」になれます。

## ⑧ 講師ガイド

### この回のねらい
受講者が、会社の話ではなく**自分自身の人生**に目を向け、人生の目的1文・価値観3〜5つ・人生計画表の下書きを完成させること。完成度よりも、「自分の言葉で書けた」という手ごたえを大事にする。

### 事前準備
- 受講者には、はじめにの章（自走度チェック）を終えてから参加してもらう
- 事前課題として「これまでの人生で、心が大きく動いたできごと」を3つ考えてきてもらう
- 「ことばカード」（16枚を印刷して切ったもの）を人数分
- 静かに書ける場所。スマホは机の上に置かないようお願いする

### 時間配分（60分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「子どものころ、何になりたかったか」を1人30秒。場をやわらかくする |
| 0:05〜0:15 | お話：③考え方の1〜4 | 羅針盤のたとえで「なぜ会社ではなく自分から始めるのか」を伝える。講師自身の「心が動いた瞬間」を1つ話すと、受講者が書きやすくなる |
| 0:15〜0:25 | ワーク：ステップ1〜2 | ひとりで静かに書く。うまく書けなくてもOK、と最初に伝える |
| 0:25〜0:30 | ペアで共有 | 80歳の誕生日会で言われたい言葉を、ペアに読み上げる。聞く人は「それを聞いて、どんな人だと感じたか」を返す |
| 0:30〜0:40 | お話＋ワーク：ステップ3〜4（価値観） | ことばカードを机に広げ、選んだカードを3〜5枚に減らしていく。「意味」と「行動」まで書く |
| 0:40〜0:48 | ワーク：ステップ5（人生の目的） | 型にあてはめて1文にする。書けたら声に出して読んでみる |
| 0:48〜0:57 | ワーク：ステップ6（人生計画表） | 時間内は「10年後」と「6か月後」の列だけでOK。残りは宿題にする |
| 0:57〜1:00 | まとめ | 人生の目的を1人ずつ発表（言いたくない人はパスOK）。半年後の見直し日を手帳に書いてもらう |

### 問いかけの例
- 「そのできごとの、どこがそんなにうれしかったのですか？」（価値観を深掘りするとき。「なぜ？」を2〜3回くり返す）
- 「もし会社がなくなったとしても、その目的は残りますか？」（目的が会社の目標になっているとき）
- 「その価値観を守れなかったとき、どんな気持ちになりましたか？」（価値観が本物かどうかを確かめるとき）
- 「10年後のご家族は、あなたにどんな顔をしていてほしいですか？」（計画表が仕事ばかりのとき）
- 「その1文を、ご家族の前で読めますか？」（借りものの言葉になっていないか確かめるとき）

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「人生の目的なんて、考えたことがない」と手が止まる | いきなり目的を書こうとせず、ステップ1の「心が動いた瞬間」にもどってもらう。講師の体験談を1つ話すと動き出しやすい |
| 目的が「売上〇億円」「会社を大きくする」になる | 「それは会社の目標ですね。会社を大きくして、その先に何がしたいのですか？」と聞いて、もう一段深くしてもらう |
| 価値観が「誠実」「感謝」などの立派なことばだけになる | 「〇〇さんにとっての誠実とは、どういう行動ですか？」と聞いて、意味と行動を書いてもらう |
| 価値観を10個以上選んでしまう | 「どうしても1つしか選べないとしたら？」をくり返して、3〜5つにしぼる |
| 人生計画表が「仕事」の段だけうまっている | 「体をこわしたら、会社の夢もかないませんよね」と伝え、「健康」と「家族」の段を先に書いてもらう |
| 照れくさくて、本音を書けない | この用紙は誰にも見せなくていいことを伝える。発表はパスOKにする |
| つらい過去を思い出して、気持ちが落ちこむ | 無理に書かなくていいことを伝える。「うれしかったこと」から先に書いてもらう |
