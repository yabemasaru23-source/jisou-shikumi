## ① この章でできるようになること

- お客様に「うちと関わったら、どんな気持ちになってほしいか」を、**お客様との約束（1文）**にできる
- 自分の会社のいまの「お客様の体験」を、**体験の健康チェック**で点検できる
- 出会いからお別れまで、お客様が通る道すじを**お客様の体験マップ**に描き、どこで誰が約束を守るのかを決められる
- 見た目・音・におい・手ざわりで「うちらしさ」を伝える**五感のおもてなし**を点検し、直すところを決められる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 「うちはサービスには自信がある」のに、なぜかお客様が定着しない、紹介が増えない
- 同じ会社なのに、担当する社員さんによって、お客様の受ける印象がまるでちがう
- 電話の出方、事務所の入り口、書類のわかりやすさなど、「サービスの外側」は誰も気にしていない
- お客様からのお叱りは、いつも「最後に社長が出ていって」おさめている
- 「お客様第一」と壁に貼ってあるけれど、具体的に何をすればいいのかは、人によってバラバラ

私が社長さんとお話ししていて、よく気づくことがあります。
それは、**社長が思っている「うちの良さ」と、お客様が実際に感じている「うちの印象」が、ずれている**ということです。

社長はいちばん良いときの会社を知っています。自分が現場に立てば、お客様はきっと喜んでくださるでしょう。
でも、お客様が出会うのは社長だけではありません。電話に出た事務さん、送迎のドライバーさん、ホームページ、玄関のにおい、請求書……。
**お客様は、そのすべてをまとめて「この会社はこういう会社だ」と感じています。**

社長がいるときだけ良い体験になる会社は、社長が倒れたら止まってしまいます。
だからこそ、「お客様にどんな気持ちになってほしいか」を約束にして、**誰が担当しても、どの場面でも、その約束が守られる道すじ**をつくっておく必要があるのです。

### 目指す姿

- 社員さんの誰に聞いても、「うちはお客様に〇〇という気持ちになってもらう会社です」と同じ答えが返ってくる
- 出会いからお別れまで、お客様が通る場面ごとに「誰が・何をして・約束を守るか」が決まっている
- 社長が現場にいない日でも、お客様から「やっぱりここにしてよかった」と言ってもらえる

## ③ 考え方

### 1. お客様との約束は「気持ち」の約束

お客様との約束というと、「品質が高い」「価格が安い」「対応が早い」のような、**会社がすること**を書きたくなります。
でも、ここで決めたいのは、**お客様がどんな気持ちになるか**です。

誕生日にケーキ屋さんへ行く場面を思いうかべてください。

| | 会社がすること（✕ 約束としては弱い） | お客様の気持ち（◯ お客様との約束） |
|---|---|---|
| ケーキ屋さん | 新鮮な材料で、ていねいに作ります | 箱をあけた瞬間、家族みんなが「わあっ」と笑顔になる |
| 自転車屋さん | 修理が早くて安いです | 「この店に任せておけば、通学の足は止まらない」と安心できる |
| 介護の会社 | 経験豊富な職員がケアします | 「任せているあいだも、親は大丈夫」と、仕事に集中できる |

左側は、ほかの会社もみんな言っていることです。お客様の心には、あまり残りません。
右側は、お客様が**「そう、それがほしかったの」**とうなずける言葉です。そして、社員さんにとっても「じゃあ、この場面で自分は何をすればいいか」を考える手がかりになります。

> 💡 専門用語では、お客様との約束を「ブランドコミットメント」といいます。

### 2. 約束は、社長自身への問いかけから始まる

お客様との約束は、会議室でかっこいい言葉を探してもできあがりません。
まずは社長自身に、3つの問いかけをしてみてください。

| 問いかけ | 見えてくること |
|---|---|
| ① どんな会社として知られたい？ | 社長の「こうありたい」という思い。第1章の人生の目的や、第4章の合言葉ともつながります |
| ② お客様から、いつもほめられることは？ | すでにお客様に届いている、うちの強み |
| ③ お客様から、よく言われる不満は？ | 約束と実際のあいだにある、すき間 |

私がこの3つをお聞きすると、②と③は、意外なほどすらすら出てくる社長さんが多いです。毎日お客様の声を聞いているからですね。

ポイントは、**①の「ありたい姿」と、②の「いま届いている強み」が重なるところ**に約束を置くことです。
①だけで書くと、きれいごとになります。②だけで書くと、いまの延長で終わります。
そして③の不満は、約束を守るために**まず直すべきところ**を教えてくれます。

### 3. お客様の気持ちを「3つの深さ」で聞く

次に、お客様の側から考えます。お客様像は、第5章で書いたものをそのまま使います。
そのお客様の気持ちを、3つの深さで想像してみましょう。

| 深さ | 聞いてみる質問 | 介護の会社の例 |
|---|---|---|
| 🌊 **いますぐ解決したい悩み** | 夜ねる前に、何が気になっている？ | 仕事のあいだ、親が家でひとりで転んでいないか心配 |
| 🕊️ **ほしい自由** | その悩みがなくなったら、何ができるようになる？ | 職場からの電話にびくっとせず、仕事に集中できる |
| 🌟 **どんな自分でいたいか** | うちを選ぶことで、どんな自分でいられる？ | 仕事も親のことも、どちらもあきらめない自分 |

いちばん浅い「悩み」は、どの会社も気づいています。
差がつくのは、2つ目と3つ目です。**お客様が本当に買っているのは、サービスそのものではなく、その先にある「自由」と「なりたい自分」**なのです。

野球のグローブを買う子どもを思いうかべてください。その子がほしいのは革のグローブではなく、「試合でボールをしっかりつかめる自分」ですよね。

### 4. 約束を1文にする

社長の思いと、お客様の気持ちがそろったら、約束を1文にまとめます。
型は、これだけです。

> **「（お客様）が、うちと関わるたびに、（どんな気持ち）になれるようにします」**

| ✕ よくある書き方 | ◯ お客様との約束 |
|---|---|
| 地域に貢献する、信頼の介護サービス | 介護をしながら働くご家族が、うちと関わるたびに「任せているあいだも、親は大丈夫」と思えるようにします |
| 心をこめて、ていねいに対応します | はじめて介護の相談をする方が、話し終えたときに「ここに相談してよかった」とほっとできるようにします |

よい約束かどうかは、次の3つで確かめます。

- **お客様が読んで、うなずけるか**（会社の自慢になっていないか）
- **社員さんが、明日の行動を思いうかべられるか**（ぼんやりした言葉だけになっていないか）
- **ほかの会社がそのまま使えないか**（どこにでも当てはまる言葉になっていないか）

### 5. 体験の健康チェック：約束と「いま」のずれを見つける

約束ができたら、いまの会社がその約束を守れているかを点検します。
遊園地を思いうかべてください。ジェットコースターがどんなに楽しくても、入り口で1時間待たされ、トイレが汚く、係の人が不機嫌だったら、「楽しかった」という思い出はかなり減ってしまいますよね。

お客様の体験も同じです。**いちばん弱いところが、その会社の印象になります。**
そこで、この章のワークでは、次の4つの場所から体験の健康チェックをします。

| 場所 | 見るところ |
|---|---|
| 👥 社員さん | 約束を知っているか、その場で判断できるか、時間の余裕があるか |
| 💬 お客様の声 | 期待や不満を聞く仕組みがあるか、聞いた声がみんなに届くか |
| 📞 入り口（電話・ホームページ） | 見つけやすいか、待たせないか、情報が新しいか |
| 🏠 建物と身だしなみ | 最初に目に入るもの、あいさつ、服装、駐車場 |

点数が低いところは、だめな場所ではありません。**約束を守るために、いちばん効き目のある場所**です。

### 6. お客様の体験マップ：出会いからお別れまでの道すじ

体験の健康チェックで「どこが弱いか」がわかったら、次は**お客様が通る道すじ**を、時間の順に1枚にします。これが、お客様の体験マップです。

修学旅行のしおりを思い出してください。「何時にどこへ行き、そこで何をして、誰が引率するか」が書いてありましたよね。だから、どの先生が引率しても、同じ旅ができました。
体験マップは、**お客様の旅のしおりを、会社の側から書いたもの**です。

![お客様の体験マップ。左から右へ、知る・問い合わせる・相談する・使い始める・使いつづける・お別れの6つの場面が並び、各場面の下に「お客様の目的」「心配・気持ち」「担当」「道具」「作業」「約束を守る行動」の6段が積み重なる。いちばん上に「お客様との約束」の旗が全体にかかっている](assets/img/ch16-journey.svg)

マップの横は、お客様と会社が出会う**場面（接点）**です。たての段には、次のことを書きます。

| 段 | 書くこと |
|---|---|
| お客様の目的 | この場面で、お客様は何をしたいのか |
| 心配・気持ち | この場面で、お客様は何が不安で、どんな気持ちなのか |
| 担当 | この場面で、お客様に責任を持つ役割は誰か |
| 道具 | 使う書類・機械・仕組み |
| 作業 | 担当がすること |
| 約束を守る行動 | お客様との約束を、この場面で守るための「ひと工夫」 |

いちばん大事なのは、最後の**「約束を守る行動」**です。
ふつうの作業手順なら、どの会社にもあります。そこに約束を重ねることで、**作業が「うちらしい体験」に変わります。**

場面を書き出すときは、「お客様がうちを知る前」と「使い終わったあと」を忘れないでください。お別れのしかたは、次のご紹介につながる、とても大事な場面です。

> 💡 専門用語では、お客様の体験マップを「カスタマージャーニーマップ」といいます。

### 7. 五感のおもてなし：言葉より先に伝わるもの

最後は、**見た目・音・におい・手ざわり**です。
人は、説明を聞くよりも先に、目や耳や鼻で「この会社はこんな感じだ」と感じとります。

パン屋さんの前を通ったとき、焼きたてのにおいで思わず入りたくなったことはありませんか？ 反対に、入り口に枯れた植木鉢があると、中のパンまでおいしくなさそうに見えてしまいます。

| 感覚 | 点検するもの | 介護の会社の例 |
|---|---|---|
| 👀 見た目 | 看板・入り口・部屋・服装・書類・ホームページ | 送迎車がきれいか、名札が読みやすいか、パンフレットの写真が明るいか |
| 👂 音 | 電話の声・あいさつ・話し声・BGM | 職員さん同士の大きな声や、テレビのつけっぱなしがないか |
| 👃 におい | 玄関・部屋・車・トイレ | 玄関に入ったときの、介護の場らしいにおいが気にならないか |
| ✋ 手ざわり | いす・タオル・紙・手すり | 連絡帳の紙が書きやすいか、手すりやいすがべたついていないか |

大事なのは、**ぜいたくにすることではなく、約束とそろえること**です。
「任せているあいだも大丈夫」と約束する会社なら、清潔で、落ち着いていて、ちょっとした乱れがないことが、そのまま約束の証拠になります。

> 💡 専門用語では、五感のおもてなしを「感覚パッケージ」といいます。

### ステップ5：体験の健康チェック

```work
id: 16.health
type: scale
label: 体験の健康チェック：いまのお客様の体験は、約束を守れていますか？
scale: [{value: 2, label: できている}, {value: 1, label: ときどき・人による}, {value: 0, label: まだ}]
groups:
  - name: 👥 社員さん
    items:
      - 社員さんが、お客様との約束を自分の言葉で説明できる
      - お客様の困りごとに、上司に聞かなくてもその場で応えてよい範囲が決まっている
      - お客様の話をゆっくり聞くための時間が、毎日の仕事の予定に入っている
  - name: 💬 お客様の声
    items:
      - 使い始める前に、お客様が「期待していること」を聞いて記録している
      - お叱りや不満を受けたら、その日のうちに返事をする決まりがある
      - お客様の声が、受けた人だけでなく、関わる社員さん全員に届いている
  - name: 📞 入り口（電話・ホームページ・資料）
    items:
      - 問い合わせ先が、チラシやホームページですぐに見つかる
      - 問い合わせに、待たせず、たらい回しにせずに答えられる
      - ホームページや資料の情報（空き状況・料金・写真）が新しい
  - name: 🏠 建物・書類・身だしなみ
    items:
      - 入り口に立ったとき、最初に目に入るもの・聞こえる音・においに気をくばっている
      - あいさつと服装の基準があり、誰でも同じようにできている
      - 契約書や請求書が、はじめての人にもわかりやすい
hint: 「できているはず」ではなく、この1か月の実際の様子で答えましょう。現場の社員さんにも同じチェックをしてもらい、点数がずれたところを話し合うと、気づきが大きくなります。
example:
  👥 社員さん: [0, 1, 0]
  💬 お客様の声: [1, 1, 0]
  📞 入り口（電話・ホームページ・資料）: [2, 0, 1]
  🏠 建物・書類・身だしなみ: [1, 1, 0]
```

#### 結果の見方

| それぞれの場所の点数（6点満点） | いまの状態 |
|---|---|
| 5〜6点 | 🍎 **約束が届いている場所**：いまのやり方を、仕事のレシピにして守りましょう |
| 3〜4点 | 🌳 **人によってムラがある場所**：できている人のやり方を、みんなのやり方にしましょう |
| 0〜2点 | 🌱 **いちばん効き目のある場所**：体験マップで、まずここの「約束を守る行動」を決めましょう |

## ⑦ 次の章へ

お客様との約束ができ、体験マップを描いてみると、**「では、お客様はなぜ、ほかではなくうちを選んでくださるのか？」**という問いが出てきます。
約束を守れる会社は、ほかにもあるかもしれないからです。

次の**第17章「選ばれる理由と看板サービス」**では、くらべる相手とのちがいを地図にして、うちが選ばれる理由をひとことで言えるようにします。そして、この章の約束を形にした、誰でも売れて誰でも届けられる自慢の商品をつくっていきます。

また、この章で書いた体験マップの「約束を守る行動」は、**第19章「期待をこえるひと手間と品質を守る仕組み」**で、ひと手間リストやお届けの流れを見直すときの土台になります。

## ⑧ 講師ガイド

### この回のねらい
受講者が、お客様に「どんな気持ちになってほしいか」を1文の約束にし、その約束を守る場面と行動をお客様の体験マップに書きこむこと。

### 事前準備
- 受講者には、第5章（お客様像）を終えてから参加してもらう
- 最近3か月の「お客様からのほめ言葉」と「不満・お叱り」を、社員さんに聞いて3つずつメモしてきてもらう
- できれば、自分の会社に電話をかけてみる・お客様と同じ道で入り口まで来てみる、を1回やってきてもらう
- 体験マップの記入用紙（A3）と、付せん（2色）

### 時間配分（90分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 持ってきた「ほめ言葉」をひとつずつ発表 |
| 0:05〜0:20 | お話：③考え方の1〜4 | ケーキ屋さんのたとえで、「会社がすること」と「お客様の気持ち」のちがいをはっきりさせる |
| 0:20〜0:35 | ワーク：ステップ2〜4 | ひとりで約束を書いたあと、ペアで3つの確かめ方を使って読み合う |
| 0:35〜0:45 | ワーク：ステップ5 | 体験の健康チェック。点数が低い場所を1つ選ぶ |
| 0:45〜0:55 | お話：③考え方の5〜7 | 修学旅行のしおりのたとえで、体験マップの6つの段を説明する |
| 0:55〜1:15 | ワーク：ステップ6 | 付せんで場面を並べてから、表に書く。「約束を守る行動」は全員1つ以上 |
| 1:15〜1:25 | ワーク：ステップ7〜8 | 五感のおもてなしは、宿題として現場で点検してもよい |
| 1:25〜1:30 | まとめ | 最初に変える3つのうち、来週から始める1つを宣言して終了 |

### 問いかけの例
- 「その約束を読んだお客様は、『そう、それがほしかった』とうなずいてくださいそうですか？」
- 「ライバルの会社のパンフレットに、同じ言葉が書いてあっても困りませんか？」
- 「社長が1か月お休みしたら、この場面の約束は守られますか？」
- 「お客様がうちを知る前は、どこで、何を見ていますか？」
- 「お別れのとき、お客様にどんな気持ちで帰っていただきたいですか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 約束が「高品質」「まごころ」など、会社がすることの言葉になる | 「それを受けたお客様は、どんな気持ちになりますか？」と聞いて、お客様の言葉に言い直してもらう |
| 約束が長くなり、いくつも入ってしまう | 「お客様がいちばん心配していることは？」と聞き、その心配がなくなる気持ちを1つ選んでもらう |
| 体験の健康チェックで、全部「できている」にしてしまう | 「現場の社員さんが同じチェックをしたら、同じ点数になりますか？」と聞き、社員さんにもつけてもらう |
| 体験マップの場面が「契約」から始まり、「利用中」で終わる | 「うちを知る前」「お別れのあと」を付せんで先に置き、その間をうめてもらう |
| 「約束を守る行動」の欄が「ていねいに対応する」になる | 「明日入った新人さんでも、同じようにできますか？」と聞き、誰が・いつ・何をするかの形にする |
| 五感のおもてなしで、お金のかかる改装の話になる | 「来週から、お金をかけずにできることは？」と聞き、片づけ・あいさつ・換気などから選んでもらう |
