## ① この章でできるようになること

- 社長が知らないうちにやっている**「会社の足を引っぱるクセ」**を、9つの中から見つけられる
- 自分のクセの**裏側にある「強み」**に気づき、クセを責めずに受けとめられる
- クセを「気合いで直す」のではなく、**「仕組みでカバーする」対処法を3つ**決められる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 「任せた」と言ったはずなのに、気づくと自分が手を出している
- 会議で決めたことが、いつのまにか立ち消えになっている
- 社員さんに言いたいことがあるのに、「まあ、がんばってくれているし」と飲みこんでしまう
- 新しいアイデアを思いつくたびに社員さんに話し、「また始まった」という顔をされる
- 仕組みづくりの本を読んで「よし、やろう」と思うのに、いつも途中で止まってしまう

私が社長さんとお話ししていて気づいたのは、**仕組みづくりが止まる原因の多くは、やり方ではなく、社長自身の「いつものクセ」にある**ということです。

たとえば、「なんでも自分でやっちゃう」クセがある社長さんは、せっかく仕事のレシピをつくっても、レシピどおりにやっている社員さんを見ると、つい「そこはこうした方がいいよ」と手を出してしまいます。
すると社員さんは「結局、社長のやり方が正解なんだ」と思い、レシピを見なくなります。

これは、社長が悪いわけではありません。**クセは、ほとんどの場合、自分では見えない**のです。
私自身にもクセがあります。新しいことを思いつくと、すぐに人に話したくなるクセです。家族に「その話、先週も聞いたよ」と言われて、はじめて気づくこともあります。

第1章で、あなたは「何のために経営するのか」という羅針盤を手にしました。
この章では、その羅針盤の方向に進むときに、**知らないうちにブレーキをかけている自分のクセ**を見つけます。

### 目指す姿

- 自分のクセを2〜3つ、笑いながら社員さんに話せる（「私、こういうところがあるからね」）
- クセが出そうな場面がわかっていて、そのときの「合図」や「仕組み」が用意されている
- 社員さんが「社長、いまクセが出てますよ」と、気軽に言える空気がある

---

## ③ 考え方

### 1. クセは「利き手」のようなもの

あなたは、右利きですか？ 左利きですか？
利き手は、生まれつきだったり、長いあいだ使ってきたりして、自然と決まったものです。良いも悪いもありません。

リーダーのクセも同じです。
**これまでの経験の中で、あなたを助けてきたやり方が、いつのまにかクセになっている**のです。

「なんでも自分でやっちゃう」社長さんは、創業したころ、自分でやらなければ会社がつぶれる状況を乗りこえてきた方です。
「やさしすぎて言えない」社長さんは、人を大切にしてきたからこそ、社員さんに慕われて会社が大きくなってきた方です。

ただ、会社が大きくなると、**昔は自分を助けてくれたクセが、今度は会社の足を引っぱる**ことがあります。
小学生のころにぴったりだった靴が、中学生になると足に合わなくなるのと同じです。靴が悪いのではなく、足が大きくなったのです。

### 2. 社長のクセは、会社では「拡声器」を通したように大きくなる

社長のクセは、社員さんのクセよりも、会社に大きな影響をあたえます。
社長の小さなクセは、会社の中では**拡声器を通したように大きく響く**からです。

| 社長のちょっとしたクセ | 会社の中で起きること |
|---|---|
| 任せた仕事に、ときどき口を出す | 社員さんが「どうせ最後は社長が決める」と考え、自分で考えなくなる |
| 思いついたことを、すぐ話す | 社員さんが「今回の話も、そのうち変わるかも」と様子見をするようになる |
| 気まずい話を、あと回しにする | 問題が放っておかれ、まじめな人ほどつかれてやめていく |

社長ひとりのクセが、気づけば「会社のクセ」になってしまう。
だからこそ、仕組みづくりを始める前に、**まず社長自身のクセを知っておく**ことが大切なのです。

### 3. 会社の足を引っぱる「9つのクセ」

私がたくさんの社長さんとお話ししてきた中で、よく出会うクセを9つにまとめました。

![9つのクセ：決めごとより自由／目の前でいっぱい／心配で足が止まる／新しいことに目移り／なんでも自分でやっちゃう／やさしすぎて言えない／走りつづけてしまう／気まずい話はあと回し／わかってほしい](assets/img/ch02-nine.svg)

| クセ | どんなクセ？ |
|---|---|
| 🕊️ **決めごとより自由** | 自由が好きで、期限や約束でしばられるのが苦手。決めたことが立ち消えになりやすい |
| 🏃 **目の前でいっぱい** | 毎日の対応に追われて、会社の先のことを考える時間がない |
| 🌧️ **心配で足が止まる** | うまくいかなかったときのことを考えて、決めるのが遅くなる |
| 🦋 **新しいことに目移り** | アイデアが次々わいて、始めたことが最後まで続かない |
| 🔧 **なんでも自分でやっちゃう** | 自分でやった方が早いし、うまい。だから任せられない |
| 🧸 **やさしすぎて言えない** | 社員さんを思うあまり、注意や「ノー」が言えない。頼まれごとを全部背負う |
| 🚀 **走りつづけてしまう** | 目標を達成しても休まず次へ。自分にも人にも、ずっと全力を求める |
| 🐢 **気まずい話はあと回し** | 人とぶつかるより、数字や書類と向き合う方が気がらく。人の問題を見て見ぬふりしがち |
| 🌻 **わかってほしい** | 自分のがんばりや「当たり前」を、まわりにわかってほしい気持ちが強い |

ひとつも当てはまらない人は、まずいません。
**誰でも、2つか3つは強く出ているクセがあります。** それがわかるだけで、大きな一歩です。

> 💡 専門用語では、こうした「リーダーのクセが原因で、組織がうまく回らなくなること」を「組織の機能不全」といいます。この教材では「リーダーのクセ」と呼んで進めます。

### 4. クセの裏には、必ず「強み」がある

コインには表と裏がありますよね。
クセも同じで、**裏側には必ず「強み」がかくれています。**

![クセの裏には強みがある。クセ（表）と強み（裏）はコインの両面。直すのではなく、仕組みでカバーすると、強みだけが残る](assets/img/ch02-flow.svg)

「なんでも自分でやっちゃう」の裏には、**仕事の腕前と、品質へのこだわり**があります。
「新しいことに目移り」の裏には、**アイデアと行動の速さ**があります。
「やさしすぎて言えない」の裏には、**人を思いやる心**があります。

だから、クセを見つけても、自分を責める必要はまったくありません。
大事なのは、**強みはそのまま活かして、クセが会社の足を引っぱる場面だけを、仕組みでカバーする**ことです。

### 5. 直すのではなく「仕組みでカバー」する

朝が苦手な人が、「明日からは気合いで早起きする！」と決めても、たいてい3日で終わりますよね。
早起きが続く人は、目覚まし時計を部屋のはしっこに置いて、起き上がらないと止められないようにしています。
**性格を変えるのではなく、仕組みで「そうなるように」しているのです。**

リーダーのクセも同じです。

| | ✕ 気合いで直す | ◯ 仕組みでカバーする |
|---|---|---|
| なんでも自分でやっちゃう | 「もう口を出さないようにしよう」と心に決める | 自分のこだわりを「仕事のレシピ」に書いて渡し、「確認するのは週1回の報告のときだけ」と決めておく |
| 新しいことに目移り | 「思いつきを話すのはやめよう」とがまんする | 思いついたことは「アイデア箱」に入れておき、月1回の作戦会議で、3年後のゴールにつながるものだけ選ぶ |
| やさしすぎて言えない | 「今度こそ言おう」と自分をはげます | 役割の約束書で「ここまでできたら合格」を先に決めておき、毎月の面談で、約束書を見ながら話す |

気合いは、つかれているときや、いそがしいときに負けてしまいます。
**仕組みは、社長の調子が悪い日でも、同じように働いてくれます。**

### 6. 9つのクセの「見方」と「対処法」

診断の結果を見るときは、次の表を使ってください。
強く出たクセの行を読んで、**「その裏にある強み」に印をつけてから、「仕組みでの対処法」を選ぶ**のがおすすめです。

| 強く出たクセ | その裏にある強み | 放っておくと起きやすいこと | 仕組みでの対処法（くわしくは〇章） |
|---|---|---|---|
| 🕊️ 決めごとより自由 | ひらめき、身軽さ、変化に強い | 決めたことが続かず、社員さんが「どうせまた変わる」と思う | 決めたことを「決めごとボード」に書いて貼る。週1回のふり返りの時間を、先に予定に入れる（第9章） |
| 🏃 目の前でいっぱい | 現場で頼られる行動力、お客様思い | 未来をつくる時間がゼロになり、会社の行き先が決まらない | 週に半日の「未来をつくる時間」を、先にカレンダーに入れる（第3章）。3年後のゴールを1枚にする（第6章） |
| 🌧️ 心配で足が止まる | 慎重さ、危ないことに早く気づく力 | 決めるのが遅れて、チャンスや社員さんのやる気がしぼむ | 「いつまでに決めるか」のしめ切りと、「ここまでの失敗ならOK」の線を先に決める。小さく試してから広げる |
| 🦋 新しいことに目移り | アイデア、行動の速さ、まわりを元気にする力 | 始めたことが途中で止まり、現場がつかれる | 思いつきは「アイデア箱」へ。作戦会議で月1回、3年後のゴールにつながるものだけ選ぶ（第6・9章） |
| 🔧 なんでも自分でやっちゃう | 仕事の腕前、品質へのこだわり | 人が育たず、社長がいないと仕事が止まる | こだわりを「仕事のレシピ」にして渡す。「どこまで任せて、いつ報告してもらうか」を決める（第10・11章） |
| 🧸 やさしすぎて言えない | 思いやり、人に信頼される人柄 | 基準があいまいになり、がんばる人ほど損をする | 役割の約束書で基準を先に決め、1対1の応援面談で約束書を見ながら話す（第7・9章） |
| 🚀 走りつづけてしまう | 目標をやりとげる力、熱量 | 社長も社員さんも息切れして、やめる人が出る | 達成したら必ず祝う場を決めておく。休む日を先に予定に入れる。ものさしに「行動の数字」もまぜる（第6章） |
| 🐢 気まずい話はあと回し | 冷静さ、数字や仕組みに強い | 人の問題が放っておかれ、まじめな人からやめていく | 話し合いの「型」を決める（1対1の応援面談の進め方）。チームの約束ごとをつくる（第9・10章） |
| 🌻 わかってほしい | 個性、人を引きつける熱意 | 社員さんが社長の顔色を見て動くようになる | 社長の「当たり前」を言葉にして会社の取扱説明書に書く（第11章）。「ありがとうカード」で、みんなが認め合う仕組みをつくる |

対処法は、**クセ1つにつき1つ**で十分です。
上位のクセから選んで、**全部で3つ**の対処法を決めましょう。

### 7. 「自分の目」と「まわりの目」をくらべる

背中に紙が貼られていても、自分では気づけませんよね。でも、まわりの人にはすぐに見えます。
クセも同じで、**自分の診断と、まわりの人から見たあなたは、ちがうことがよくあります。**

私がおすすめしているのは、診断が終わったら、信頼できる人に**「私のクセって、この9つのうちどれだと思う？」**と聞いてみることです。
相手は、家族でも、長く一緒に働いている社員さんでもかまいません。

聞くときのコツは、ひとつだけです。
**どんな答えが返ってきても、言い訳をせずに「ありがとう」と言うこと。**
社長が「教えてくれてありがとう」と言える会社は、社員さんが本音を話せる会社になっていきます。それ自体が、とても大きな仕組みなのです。

### ステップ2：9つのクセ診断（27問）

この1か月くらいの自分を思いうかべて、直感で答えてください。
**「よくある」ほど点数が低くなります。** 3問の合計（6点満点）が低いグループほど、そのクセが強く出ています。

```work
id: 02.diag
type: scale
label: 9つのクセ診断
scale: [{value: 0, label: よくある}, {value: 1, label: ときどき}, {value: 2, label: ほとんどない}]
groups:
  - name: 決めごとより自由
    items:
      - 「やります」と言ったことが、いつのまにか立ち消えになっていることがある
      - 期限や約束で、自分の動きをしばられるのが窮屈に感じる
      - うまくいかないとき、まず「〇〇さんがちゃんとしてくれたら」と人の動きが気になる
  - name: 目の前でいっぱい
    items:
      - 毎日の対応に追われて、1年後の会社のことを考える時間がほとんどない
      - 計画を立てても、どうせそのとおりにはならないと思ってしまう
      - 社員さんに「会社はこれからどうなるんですか？」と聞かれても、うまく答えられない
  - name: 心配で足が止まる
    items:
      - 新しいことを始める前に、うまくいかなかったときのことばかり考えてしまう
      - 大事な決めごとほど、「もう少し調べてから」と先のばしにしがち
      - やり方を変えるより、いまのままの方が安心だと感じる
  - name: 新しいことに目移り
    items:
      - 新しいアイデアを思いつくと、いまやっていることより、そちらに気持ちが向く
      - 「おもしろそう」と思った話には、つい「やりましょう！」と言ってしまう
      - 社員さんから「社長の言うことは、よく変わる」と思われていそうだ
  - name: なんでも自分でやっちゃう
    items:
      - 人に教えるより、自分でやった方が早いと感じて、手を出してしまう
      - 任せた仕事でも、やり方が気になって、細かいところまで口を出してしまう
      - 自分と同じ出来ばえでないと、どうしても気持ちが落ち着かない
  - name: やさしすぎて言えない
    items:
      - 社員さんががんばっているのを知っているので、注意や指摘を言い出せない
      - 頼まれると断れず、自分の予定があっても引き受けてしまう
      - 社員さんが決めるべきことまで、相談されると自分が答えを出してしまう
  - name: 走りつづけてしまう
    items:
      - ひとつの目標を達成しても、喜ぶより先に、次の目標を探している
      - その日に「何をどれだけやったか」で、自分の気分が大きく変わる
      - 休んでいる時間がもったいなく感じて、体のつかれを後回しにしがち
  - name: 気まずい話はあと回し
    items:
      - 人と向き合う話し合いより、数字や書類と向き合っている方が気がらくだ
      - 社員さん同士のもめごとに気づいていても、「そのうち落ち着くだろう」と様子を見てしまう
      - 自分の思いや会社の夢を、社員さんの前で言葉にするのが照れくさい
  - name: わかってほしい
    items:
      - 自分ががんばっていることを、まわりがわかってくれていないと感じることがある
      - 「自分にとっては当たり前のこと」が社員さんに伝わらないと、イライラしてしまう
      - ほかの人がほめられていると、自分も負けていられないという気持ちになる
hint: 「こうありたい自分」ではなく、「この1か月の自分」で答えるのがコツです。迷ったら「家族や社員さんが私を見たら、どれにつけるかな？」と考えてみてください。
example:
  決めごとより自由: [2, 1, 2]
  目の前でいっぱい: [0, 1, 0]
  心配で足が止まる: [2, 2, 1]
  新しいことに目移り: [1, 1, 2]
  なんでも自分でやっちゃう: [0, 0, 1]
  やさしすぎて言えない: [1, 0, 1]
  走りつづけてしまう: [1, 1, 2]
  気まずい話はあと回し: [2, 1, 2]
  わかってほしい: [2, 2, 1]
```

> 📝 合計点（54点満点）は「クセにじゃまされにくい度」です。高ければいい、低ければだめ、というものではありません。
> いちばん大事なのは、**9つのグループの中で、点数が低い2〜3つ**を見つけることです。

## ⑦ 次の章へ

クセがわかると、多くの社長さんが同じことに気づきます。
「クセが出るのは、たいてい、いそがしくて余裕がないときだ」ということです。

次の**第3章「時間と机のお片づけ」**では、あなたの1週間の活動を全部書き出して、「自分にしかできないこと」「人に任せられること」「やらなくていいこと」に仕分けます。
この章で決めた対処法、たとえば「未来をつくる時間を先に予定に入れる」も、第3章で**理想の1日の時間割**に組みこんでいきます。

> 必修の章だけを進める方は、次は**第4章「わが社の合言葉」**です。
> この章で見つけたクセは、第9章の「1対1の応援面談」や、第10章の「任せ方のルール」で、もう一度役に立ちます。

## ⑧ 講師ガイド

### この回のねらい
受講者が、9つのクセ診断で自分の強く出ているクセを2〜3つ見つけ、その裏にある強みを受けとめたうえで、仕組みでの対処法を3つ決めること。

### 事前準備
- 受講者には、第1章（私の人生の羅針盤）を終えてから参加してもらう
- 9つのクセ診断の記入用紙（または、パソコンやスマートフォンで回答できるようにしておく）
- ③考え方6の「見方と対処法の表」を、A3で印刷して配る
- 講師自身の診断結果と、自分のクセの話（笑って話せるもの）を1つ用意しておく

### 時間配分（60分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 第1章の人生の目的を、1人ひとことで |
| 0:05〜0:15 | お話：③考え方の1〜2 | 講師が自分のクセを先に笑って話す。「クセは利き手」「小さいころの靴」のたとえで、責める話ではないことを伝える |
| 0:15〜0:25 | ワーク：ステップ2（クセ診断） | ひとりで、直感で答える。相談はしない |
| 0:25〜0:35 | お話：③考え方の3〜6 | コインの表と裏。「気合い」と「仕組み」のちがいを ✕・◯ の表で見せる |

### 問いかけの例
- 「そのクセのおかげで、うまくいったことは何ですか？」（クセを見つけて落ちこんでいるとき）
- 「そのクセが出るのは、どんな日・どんな場面が多いですか？」
- 「その対処法は、社長がいそがしくて余裕がない日でも、働きますか？」
- 「社員さんがその合図の言葉を言ったとき、笑って『ありがとう』と言えそうですか？」
- 「3年後も同じクセが続いていたら、会社はどうなっていそうですか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「こうありたい自分」で答えて、どのクセも点数が高くなる | 「この1か月で、実際にあった場面」で答え直してもらう。家族や社員さんの目で見たら、とたずねる |
| クセが見つかって落ちこむ、または言い訳をはじめる | 「クセの裏には必ず強みがある」ことを伝え、裏の強みを先に書いてもらう |
| 対処法が「気をつける」「がんばる」「意識する」になる | 「朝が苦手な人の目覚まし時計」のたとえで、「何を、いつ、どう決めておくか」まで書いてもらう |
| 9つのクセ全部に対処しようとする | 「上位2〜3つ、対処法は全部で3つまで」と伝える。残りは3か月後の再診断で |
| まわりの人に聞くのをこわがる | 講師がまず受講者同士で聞き合う場をつくる。聞く相手は家族からでもよいことを伝える |
| 社員さんのクセの話になってしまう（「うちの社員は〜」） | 「今日は社長ご自身の回です」とやさしく戻す。社員さんのクセは、まず社長のクセとの組み合わせで起きていないかを考えてもらう |
