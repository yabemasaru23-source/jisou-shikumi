## ① この章でできるようになること

- ここまでに**やってきたこと・良くなったこと・まだやれていないこと**を、1枚の**「ふり返りシート」**にまとめられる
- スタートのときと同じ**自走度チェック**をもう一度やって、会社がどれだけ伸びたかを**点数で見比べられる**
- ふり返りをもとに、**「次の90日作戦」**（30日以内・60日以内・90日以内にやること）を決められる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 研修や勉強会に出た直後はやる気満々なのに、1か月たつと、いつもの毎日に戻っている
- 「いろいろやった気はする」けれど、何が良くなったのかを聞かれると、うまく答えられない
- 学んだことはたくさんあるのに、実際に会社でやれているのは、そのうちのほんの少しだけ
- 次に何から手をつければいいのかわからず、また社長の思いつきで動き始めてしまう

まずは、ここまで本当におつかれさまでした。
毎日の仕事をしながら、自分と会社に向き合う時間をつくるのは、簡単なことではありません。途中で「今週はちょっと無理だな」という日もあったと思います。それでもこの章までたどり着いたあなたは、もう「あの人頼みの会社」から一歩、確実にふみ出しています。

そのうえで、私が一番お伝えしたいことがあります。
私はこれまで、せっかく立派な設計図をつくったのに、**ふり返らないまま、机の引き出しにしまってしまう**会社を何度も見てきました。半年後にお会いすると、「そういえば、あのマップどこにしまったかな……」とおっしゃるんです。

どんなにいい仕組みも、**ほうっておくと、少しずつ元に戻ります。**
だから必要なのは、「つくった仕組みを、定期的に見直して、良くし続ける仕組み」です。この章は、その**最初の1回目**です。

### 目指す姿

- 「この4か月で、会社の何がどう変わったか」を、数字と具体的な出来事で話せる
- まだやれていないことを、自分を責めずに「何が壁で、どうすれば越えられるか」で考えられる
- 次の90日で何をするかが決まっていて、作戦会議のメンバーと同じ地図を見ている
- 90日ごとに、この章に戻ってくる日がカレンダーに入っている

## ③ 考え方

### 1. 山小屋でひと休みして、地図を見直そう

第6章で、山登りのたとえをお話ししましたね。
山を登るとき、ずっと歩きっぱなしの人はいません。ときどき山小屋で休んで、水を飲み、地図を広げて「いまどこまで来たかな？」「この先のルートはどうしよう？」と確かめます。

| 山小屋ですること | この章ですること |
|---|---|
| 🍙 ひと休みして、ここまでの道をふり返る | やってきたこと・良くなったことを書き出す |
| 📍 地図で「いまの場所」を確かめる | 自走度チェックをもう一度やって、スタートと比べる |
| 🥾 足のまめや、重すぎる荷物を見直す | まだやれていないことと、その「壁」を見つける |
| 🗺️ 次の山小屋までのルートを決める | 次の90日作戦を決める |

休むことは、サボることではありません。**休まずに歩き続ける人ほど、道に迷ったり、途中で動けなくなったりする**のです。

### 2. 夏休みの宿題の「やりっぱなし」にしない

子どものころ、夏休みの宿題が終わったとき、どうしていましたか？
私はというと、最後の3日間で必死に終わらせて、「終わったー！」と放り投げていました。そして次の夏休みも、同じように最後の3日間で苦しんでいました。

もしあのとき、「どうして最後にあわてたんだろう？」「来年は何を変えよう？」と5分でもふり返っていたら、次の夏休みはきっとちがっていたはずです。

会社も同じです。**ふり返りをしないと、同じつまずきを何度もくり返します。**
この章では、次の5つの問いでふり返ります。

| # | 問い | ねらい |
|---|---|---|
| ① | どんなことをやってきた？ | がんばりを「見える形」にする |
| ② | 何が良くなった？（数字にできること・できないこと） | 小さな変化も見のがさない |
| ③ | 自分の考え方は、どう変わった？ | 社長自身の成長に気づく |
| ④ | 学んだのに、まだやれていないことは？ その壁は？ どうすればやれる？ | 「知っている」を「やっている」に変える |
| ⑤ | ものさしを前に進めるために、何をする？ | 次の90日作戦につなげる |

### 3. 「体重計」と「鏡」の両方で見る

良くなったことには、**数字にできるもの**と、**数字にできないもの**があります。

ダイエットにたとえると、体重計の数字は「数字にできる変化」です。でも、「階段で息が切れなくなった」「服を選ぶのが楽しくなった」という変化は、体重計には出ません。鏡を見たり、自分の気持ちに聞いたりしないとわからないのです。

| | 数字にできる変化（体重計） | 数字にできない変化（鏡） |
|---|---|---|
| 例 | 社長の現場時間、会議の回数、離職率、ものさしの数字 | 会議の空気、社員さんの表情、自分の気持ちのゆとり |
| 見つけ方 | 第6章のものさしと、スタート時の数字を比べる | 「前はこうだったのに、最近はこうなった」という場面を思い出す |
| 注意 | 4か月では動かない数字もある。あせらない | 「なんとなく良くなった」で終わらせず、具体的な出来事で書く |

数字が動いていなくても、がっかりしないでください。
**仕組みの変化は、まず「数字にできない変化」として先にあらわれ、あとから数字がついてくる**ことが本当に多いのです。私はこれを、「芽は、実よりも先に出る」とお伝えしています。

### 4. 「やれていないこと」は、責めずに「壁」をさがす

学んだのに、まだやれていないこと。誰にでも必ずあります。
ここで大事なのは、**「自分はダメだ」と責めないこと**です。やれていないのには、たいてい理由があります。その理由を、この教材では**「壁」**と呼びます。

「知っている」と「やっている」の間には、川が流れています。
川を越えられないのは、泳ぐ力が足りないからではなく、**橋がかかっていない**からです。壁の種類がわかれば、かける橋も見えてきます。

| 壁の種類 | よくある声 | かける橋の例 |
|---|---|---|
| ⏰ 時間がない | 「毎日の仕事で手いっぱい」 | 作戦会議の時間の中でやる。カレンダーに先に予定を入れる |
| ❓ やり方がわからない | 「何から始めればいいの？」 | 小さく1つだけためす。その章をもう一度読む |
| 😣 気が重い・こわい | 「反発されそうで言い出せない」 | まず1人だけに相談する。第12章「変化を仲間に広げる」を使う |
| 🙅 仲間が乗ってこない | 「私だけが盛り上がっている」 | 「なぜやるのか」を合言葉や夢とつなげて話し直す |
| 💭 忘れてしまう | 「気づいたら1か月たっていた」 | 毎月の会議の議題に入れる。担当としめ切りを決める |

私自身、何度もこの壁にぶつかってきました。やれていないことが見つかったら、それは**「次の90日でかける橋の候補」**です。

### 5. 自走度チェックで「背くらべ」をする

子どものころ、家の柱に身長の印をつけた経験はありませんか？
毎日見ていると背がのびているなんてわかりませんが、半年前の印と比べると「こんなにのびたんだ！」とびっくりしますよね。

第0章でやった自走度チェックは、**スタートのときの柱の印**です。
この章でもう一度、**まったく同じ20問**に答えて、スタート時の点数と並べて比べます。

見るポイントは3つです。

1. **合計点**はどれだけ変わった？（第0章の「結果の見方」で、どの段階に進んだ？）
2. **一番のびた分野**はどこ？（それが、この4か月でがんばった証拠です）
3. **まだ4点以下の分野**はどこ？（それが、次に進む選択章のヒントです）

ひとつ、知っておいてほしいことがあります。
**点数が下がる項目が出ることもあります。** でも、それは悪いことではありません。学ぶ前は「できている」と思っていたことが、学んだあとで「まだまだだった」と見えるようになった――つまり、**見る目が育った証拠**なのです。

### 6. 次の作戦は「90日」で考える

どうして「90日」なのでしょうか。

| 期間 | たとえ | よいところ・困るところ |
|---|---|---|
| 1年 | 遠くの山のてっぺん | 遠すぎて、「まだ時間はある」と後回しにしがち |
| 1か月 | 次の曲がり角 | 近すぎて、日々の仕事にのみこまれ、大きなことができない |
| **90日** | **次の山小屋** | **見える距離で、本気を出せば仕組みを1つ形にできる** |

90日は、季節がひとつ変わるくらいの長さです。
そして、90日をさらに**30日ずつ3つ**に分けると、ぐっと動きやすくなります。

| 期間 | 役割 | 山登りでいうと |
|---|---|---|
| 30日以内 | **準備する**：担当を決める、下書きをつくる、メンバーに話す | 靴ひもを結んで、荷物をつめる |
| 60日以内 | **ためす**：小さくやってみて、うまくいかない所を直す | 歩き出して、ペースをつかむ |
| 90日以内 | **定着させる**：いつものやり方にして、ものさしで確かめる | 次の山小屋に着いて、地図に印をつける |

そして、ここが一番大切なところです。
**作戦テーマは、多くても3つまで**にしてください。
やりたいことは山ほどあると思います。でも、10個のテーマを少しずつ進めるより、3つのテーマをやり切るほうが、会社は確実に変わります。リュックに荷物をつめこみすぎると、かえって歩けなくなりますからね。

テーマの選び方は、次の3つを見るとスムーズです。

- 第6章の**8つの作戦のうち、ものさしが止まっているもの**
- 自走度チェックで**点数が低いままの分野**
- ふり返りで見つけた**「まだやれていないこと」**

### 7. この教材は「1回で終わり」ではありません

最後に、この教材の本当のゴールをお伝えします。

この教材は、20章を読み終えたら卒業、というものではありません。
**90日ごとに、この章に戻ってくる**。それ自体が、この教材の最後の、そして一番大事な仕組みです。

![90日サイクルの図。①ふり返る→②決める→③やる→④はかる、と円を回り、90日で1周・1年で4周する](assets/img/ch20-cycle.svg)

1年に4回、季節が変わるたびに山小屋でひと休みして、地図を見直す。
これを続けていくと、会社の仕組みは少しずつ、でも確実に良くなっていきます。私はこれを**「仕組みを良くし続ける仕組み」**と呼んでいます。

会社が自走するというのは、完ぺきな仕組みができあがることではありません。
**社長がいなくても、みんなで仕組みを良くし続けられる会社になること**です。いつか、このふり返りを作戦会議のメンバーが中心になって進めるようになったら、それが本当の「自走」だと私は思っています。

```work
  ・毎週月曜60分の作戦会議を始めた（17回中16回開催）
```

```work
example:
  - [社長が現場に入る日数, 月15日, 月8日]
```

```work
id: 20.review.better_feel
type: textarea
label: ②-2 良くなったこと（数字にできないこと）

example: 前は会議が私の報告会で、誰も発言しなかった。先月の作戦会議で、森さんが「利用率が下がっているので、ケアマネジャーさんへの空き状況のお知らせを毎週にしたい」と自分から提案してくれた。合言葉の「迷ったら、まず聞く」が、職員さん同士の会話で自然に出てくるようになった。私自身、日曜の夜に「明日が不安」と感じることが減った。
```

```work
id: 20.review.mind
type: textarea
label: ③ 社長として、リーダーとして、自分の考え方はどう変わりましたか？
hint: 「前は〇〇だと思っていた → いまは△△だと思う」の形で書くと、変化がはっきりします。うまくいかなかった経験から気づいたことも、立派な変化です。
example: 前は「私がやったほうが早いし、確実」と思っていた。いまは「私がやると早いけれど、私がやらないほうが人が育つ」と思うようになった。森さんに利用率の数字を任せてみたら、最初はまちがいもあったけれど、3か月で私より細かく見るようになった。社長の仕事は答えを出すことではなく、みんなが答えを出せる場をつくることだと気づいた。
```

```work
id: 20.review.gap
type: table
label: ④ 学んだのに、まだやれていないことは？ その壁は？ どうすればやれる？
columns: [学んだのに、まだやれていないこと, その壁（なぜやれていない？）, どうすればやれる？（かける橋）]
hint: 自分を責めるためではなく、「次の90日でかける橋」を見つけるための欄です。③考え方の4の「壁の種類」の表を見ながら書いてみてください。2〜3個で十分です。
example:
  - [請求の仕事を「仕事のレシピ」にして、石田さんひとりに頼らない形にする, 石田さんが「自分の仕事がなくなる」と不安に思っていて、言い出しにくい（気が重い）, 石田さんに「レシピをつくる先生役」をお願いする。レシピができたら、石田さんには新しい拠点の事務の立ち上げを任せたいと伝える]
  - [役割の約束書を、部長候補3人全員と本人とすり合わせる, 森さんとはできたが、残り2人は日程が合わないまま先のばしになった（忘れてしまう）, 作戦会議の議題に入れて、2月末までに1人ずつ60分の時間をカレンダーに先に入れる]
  - [社長が1週間まるごと現場をはなれる, 「何かあったらどうしよう」という自分の不安（こわい）, いきなり1週間ではなく、まず2日間から。任せ方のルールで「連絡してよいこと・待ってよいこと」を先に決める]
```

### ステップ3：ものさしの進み具合を確かめる

```work
example:

  - [住みなれた家での暮らしを長く支える, 1年後も在宅の方 90%, 未計測, 未計測（集計方法を決めた）, くもり]
  - [長く働ける職場をつくる, 離職率 25% → 10%, 25%, 21%（直近1年）, くもり]
  - [拠点を任せられるリーダーを育てる, 拠点長を任せられる人 3人, 0人, 1人（森さん）, 晴れ]
```

```work
id: 20.ksi.push
type: textarea
label: ⑤ ものさしを前に進めるために、何をしますか？
hint: 「雨」や「くもり」の作戦から1〜3つ選んで、「何をすれば、この数字が動きそうか」を書きます。ここで書いたことが、ステップ5の「次の90日作戦」のテーマの候補になります。
example: 一番の「雨」は「自分で考えて動ける職員さんを育てる」。育成プログラムそのものがまだないので、まずは新人さんの最初の90日の育て方を決めたい。これは離職率（入社1年以内にやめる人が多い）にも効くはず。「記録と請求」は、石田さんの請求の仕事をレシピにできれば、100時間に一気に近づく。
```

### ステップ4：自走度チェックをもう一度やる

第0章とまったく同じ20問です。
スタートのときの点数は見ずに、**いまの本当の姿**で答えてください。答え終わると、スタートのときの点数と自動で並んで表示されます。

```work
id: 20.diag
type: scale
label: 自走度チェック（2回目）
compare_with: "diag.basic"
scale: [{value: 2, label: できている}, {value: 1, label: 少しできている}, {value: 0, label: できていない}]
groups:
  - name: 会社の軸と作戦
    items:
      - 会社が大切にしていること（合言葉）が言葉になっていて、社員さんが言える
      - 10年後くらいの会社の姿（夢の完成図）が文章になっている
      - 3年後のゴールが数字で決まっていて、社員さんも知っている
      - ゴールに向けて、毎月チェックする数字が決まっている
  - name: 会社のリズム
    items:
      - 会議の目的・参加する人・回数が決まっていて、会議で物事が決まる
      - 上司と部下が、定期的に1対1で話す時間がある
      - 社長が1〜2週間休んでも、会社の判断が止まらない
      - 会社の基本ルールが、1冊（1か所）にまとまっている
  - name: チームと仕事
    items:
      - チーム図（組織図）があって、それぞれの役割と責任が書いてある
      - 主な仕事に、手順書やチェックリストがある
      - 仕事を任せるとき、「どこまで任せるか」「どう報告するか」が決まっている
      - 「あの人しかできない仕事」がほとんどない
  - name: 仲間集めと育成
    items:
      - どんな人に仲間になってほしいかがはっきりしていて、選び方の手順が決まっている
      - 新しく入った人の、最初の3か月の育て方が決まっている
      - 役割ごとに「何を学べばいいか」が決まっている
      - がんばりを評価する基準がはっきりしていて、社員さんが納得している
  - name: お客様への価値
    items:
      - お客様にどんな気持ちになってほしいかが言葉になっていて、社員さんがわかっている
      - 「他ではなく、うちが選ばれる理由」を社員さんが説明できる
      - 新しいお客様と出会う流れが決まっていて、数字で追いかけている
      - サービスの品質の基準があって、定期的にチェックしている
hint: 迷ったら「社員さんに同じ質問をしたら、同じ点数をつけてくれるかな？」と考えてみてください。作戦会議のメンバーにも答えてもらい、点数を見比べるのもおすすめです。
example:

  お客様への価値: [1, 1, 0, 1]
```

**「誰が責任を持つか」**も必ず決めてください。社長が全部を持つと、また「あの人頼み」に戻ってしまいます。

## ⑤ できあがるもの

入力した内容から、次のものが自動でできあがります。

- **ふり返りシート**：やってきたこと／良くなったこと（数字にできること・できないこと）／考え方の変化／まだやれていないこと・その壁・かける橋／ものさしを前に進めるためにすること。A4 1枚で印刷できます
- **ものさしの天気図**：8つの作戦のものさしを、スタート時といまで並べ、晴れ・くもり・雨で色分けした表
- **自走度チェックのビフォー・アフター**：スタート時（第0章）と今回の合計点・分野ごとの点数を、2色のくもの巣グラフで重ねて表示
- **次の90日作戦表**：テーマ × 30日・60日・90日 × 責任者。作戦会議の壁に貼って、毎週チェックできます

> 90日後にこの章に戻ってくると、前回の「次の90日作戦」が自動で表示され、「やり切れたか」から ふり返りを始められます。ふり返りシートと自走度チェックの点数は、回ごとに記録として残っていきます。

### 問いかけの例
- 「4か月前の自分に、いまの会社を見せたら、何と言うと思いますか？」
- 「数字にはまだ出ていないけれど、『あ、変わったな』と感じた場面を1つ教えてください」
- 「それがやれていないのは、時間・やり方・気持ち・仲間・忘れる、のどの壁が一番大きいですか？」
- 「その3つのテーマのうち、1つしかできないとしたら、どれを選びますか？」（テーマをしぼれないとき）
- 「このテーマの責任者を、社長以外の人にするとしたら誰ですか？」
- 「90日後のふり返りは、誰と一緒にやりますか？ その日はもうカレンダーに入っていますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「何も変わっていない」と落ちこむ | 「やってきたこと」を小さなことまで書き出してもらう。数字より先に、数字にできない変化（芽）が出ていないか一緒にさがす |
| 良くなったことが「なんとなく雰囲気が良くなった」で終わる | 「それを感じたのは、いつ、誰の、どんな言葉や行動でしたか？」と聞いて、具体的な出来事にする |
| やれていないことを「自分の意志が弱いから」で片づける | 壁の種類の表を見せて、「意志以外の理由」を1つ見つけてもらう。自分を責める場ではないことを伝える |
| 自走度チェックの点数が下がって、がっかりする | 「見る目が育った証拠」であることを伝える。下がった項目は、次の90日作戦のテーマ候補になる |
| 次の90日作戦のテーマが5つも6つも出てくる | 「リュックに入れすぎると歩けない」たとえで、3つまでにしぼる。残りは「次の次の90日」の候補として残しておく |
| 30日以内にやることが「検討する」「考える」になっている | 「来週の月曜に、誰が、何をしますか？」と聞いて、行動の言葉にする |
| 責任者が全部社長になっている | 「このままだと、また『あの人頼み』に戻りませんか？」と聞き、少なくとも1つは社長以外の人に任せる |
| 「これで終わり」と思い、次のふり返りの日を決めない | サイクル図を見せて、90日ごとに戻ってくることが教材の最後の仕組みであることを確認し、その場で日付を決める |
