## ① この章でできるようになること

- 入社1か月前から12週目までに、**「いつ・誰が・何をするか」**を1枚にした**90日の旅の地図**をつくれる
- 受け入れる側の準備を、誰がやってももれない**受け入れチェックリスト**にできる
- 新しい仲間に渡す**ようこそセット**と、**入社日の予定表**を用意できる
- **最初の応援面談**と**本人の成長計画**で、「ここで成長していける」という見通しを一緒につくれる
- 新しい仲間が定着しているかを、**ものさし**で毎月たしかめられる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 入社の日に、机も制服も名札も間に合っておらず、「あ、今日からだったね」と言われてしまう
- 「とりあえず先輩について、見て覚えて」で、新人さんが一日中、所在なさげに立っている
- 誰が教えるのか決まっていない。忙しい日は、新人さんがほったらかしになる
- 入社して1〜2か月で、「思っていたのとちがいました」と、静かにやめていく
- 新人さんが困っていたことを、やめるときになってはじめて知る

私は社長さんと定着のお話をするとき、「やめた方は、入社して何日目くらいに『ここじゃないかも』と思ったと思いますか？」とお聞きすることがあります。
すると多くの社長さんが、少し考えて、「……たぶん、最初の1週間ですね」とおっしゃいます。

人は、新しい場所に来て最初の数日で、「自分はここで歓迎されているか」「ここで、うまくやっていけそうか」を、驚くほど早く感じとります。
その気持ちは、口には出しません。でも、小さな「あれ？」が積み重なると、ある日、退職届という形で表に出てきます。

第13章で、合言葉に共感する仲間と、ていねいに出会う流れをつくりました。
でも、どんなに合う人と出会えても、**最初の90日の迎え方しだいで、その出会いは実を結ぶことも、しぼんでしまうこともある**のです。

### 目指す姿

- 新しい仲間が、入社の日の朝に「待っていたよ」と迎えられ、帰りには「来てよかった」と思って帰る
- 誰が受け入れ担当になっても、**同じチェックリストで、同じように準備できる**
- 新人さんが「いま自分は90日の旅のどのあたりで、次に何ができるようになればいいか」を知っている
- 入社して1年以内にやめる人が減り、新人さん自身が「友だちにもすすめたい」と言ってくれる

## ③ 考え方

### 1. 最初の90日は「転校生の最初の1学期」

転校生だったときのことを、思い出してみてください。（転校したことがなければ、転校生を迎えたときのことでも大丈夫です）

朝、教室に入ったら、自分の机といすがちゃんと用意されていて、名前の書かれた名札が貼ってある。
となりの席の子が「教科書、一緒に見よう」「音楽室はこっちだよ」と案内してくれる。
担任の先生が、放課後に「1週間たったけど、どう？」と声をかけてくれる。

こんなふうに迎えられた転校生は、1学期が終わるころには、すっかりクラスの一員になっています。
反対に、机が用意されておらず、誰も話しかけてくれず、移動教室の場所もわからない。そんな1週間を過ごしたら、学校に行くのがつらくなりますよね。

会社も、まったく同じです。

| | ✕ 「見て覚えて」で放っておく | ◯ 90日の歓迎プランで迎える |
|---|---|---|
| 入社の前 | 何の連絡もなく、入社日を待つだけ | ようこそセットが届き、最初の90日の見通しがわかる |
| 入社の日 | 書類を書いて、あとは「先輩について」 | 予定表どおりに進み、みんなから「待っていたよ」 |
| 最初の1か月 | 誰に聞けばいいかわからない | お世話係の先輩がいて、迷ったら聞ける |
| 3か月たって | 「思っていたのとちがう」 | 「聞いていたとおりだ。ここで成長したい」 |

> 💡 専門用語では、新しい仲間を迎え入れて職場になじんでもらうまでの流れを「オンボーディング」といいます。この教材では「入社90日の歓迎プラン」と呼びます。

### 2. 90日の旅の地図を、先に描いておく

歓迎プランの中心になるのが、**90日の旅の地図**です。
入社1か月前から12週目までを横にならべ、時期ごとに「目指す状態」と「誰が何をするか」を書きこんだ、1枚の表です。

![90日の旅の地図。入社1か月前・入社1週間前・入社日・1週目・2〜4週目・5〜8週目・9〜12週目を横に並べ、時期ごとの目指す状態と、本人・お世話係と上司・受け入れ担当の3人の役割を書きこんだ1枚の地図](assets/img/ch14-journey.svg)

地図づくりのコツは、**「何をするか」より先に「目指す状態」を決める**ことです。
遠足のしおりにも、「何時にどこへ行く」だけでなく「今日のめあて」が書いてありますよね。めあてがあるから、予定どおりにいかなくても、何を大事にすればいいかがわかります。

| 時期 | 目指す状態（例） |
|---|---|
| 入社1か月前 | 「楽しみ」が「不安」より大きい |
| 入社1週間前 | 入社の日に、何を持って、どこへ、何時に行けばいいかがわかっている |
| 入社日 | 「待っていてもらえた」「ここでやっていけそう」と思って帰る |
| 1週目 | 会社の夢・合言葉・チームの顔ぶれ・お客様のことが、ひととおりわかる |
| 2〜4週目 | 先輩と一緒なら、毎日の仕事の流れについていける |
| 5〜8週目 | 1つ目の仕事を、ひとりでやりきれる（**最初の成功**） |
| 9〜12週目 | 自分の役割がわかり、これからの成長の目標を自分の言葉で話せる |

そして、それぞれの時期に**3人の登場人物**の役割を書きます。
**本人**、いつもとなりにいる**お世話係の先輩と上司**、そして準備や手続きを受け持つ**受け入れ担当**（事務・管理の人）です。
誰か1人のがんばりにまかせず、3人で分けて持つことで、忙しい日でも旅が止まりません。

### 3. 歓迎は、入社の日より前から始まっている

内定を出してから入社までの1か月は、思っている以上に、本人が不安になる時期です。
「本当にやっていけるかな」「前の職場に残ったほうがよかったかな」。この時期に何の連絡もないと、不安だけがふくらんでいきます。

そこで、入社の前に**ようこそセット**をお届けします。

| ようこそセットの中身（例） | ねらい |
|---|---|
| 💌 ようこそカード（社長や先輩からの手書きのひとこと） | 「待っている人がいる」と感じてもらう |
| 🗺️ 90日の旅の地図 | 最初の90日の見通しを持ってもらう |
| 📅 入社日の予定表 | 当日の不安をなくす（何時に・どこへ・何を持って） |
| 📝 入社前にやることリスト | 書類や準備物を、あわてずにそろえてもらう |
| 📖 会社のことがわかる冊子（会社の夢・合言葉・チーム図） | 入社の前から、会社の考え方にふれてもらう |
| 🎁 ちょっとしたおみやげ（名札・ペンなど） | 「仲間の一員」になる実感 |

全部そろえなくてかまいません。私のおすすめは、まず**ようこそカードと入社日の予定表の2つ**から始めることです。
手書きのカード1枚で、入社の日の表情がまったくちがってきます。

### 4. 入社の日は「主役の日」

入社の日は、本人にとって**主役の日**です。お誕生日会に、主役の席が用意されていなかったら悲しいですよね。

✕ 朝、出社したら「ちょっと待ってて」と言われ、30分ひとりで座っている。午前中は書類を書いて、午後は「とりあえず先輩について」
◯ 玄関で名前を呼んで迎えられ、自分の机と名札がある。予定表どおりに、あいさつ・職場の案内・お昼ごはん・ふり返りと進み、帰りに「明日もよろしくね」と見送られる

入社の日の予定表には、次のことを入れておくと安心です。

- 迎える人と時間（誰が玄関で待っているか）
- チームへのあいさつと、職場の案内（トイレ・休憩室・更衣室も忘れずに）
- ようこそセットの中身の説明と、書類の手続き
- 社長や上司との時間（会社の夢と合言葉を、社長の口から直接伝える）
- 先輩とのお昼ごはん
- その日のふり返り（「今日はどうだった？」「明日は何をするか」）

### 5. 1週目は「会社の地図」、1〜3か月目は「最初の成功」

**1週目**は、仕事をおぼえるより先に、**会社の地図を頭に入れる週**です。
転校生も、まずは校舎のどこに何があるか、クラスにどんな子がいるかを知ってから、授業に集中できるようになります。

- 会社の夢と合言葉（なぜこの会社があるのか、何を大切にしているのか）
- チームの顔ぶれと、それぞれの役割（第7章のチーム図）
- お客様のこと（どんな方が、何に困って、うちを選んでくださっているのか）
- 毎日使う道具やしくみ（記録のしかた、連絡のルールなど）
- 働くうえでのきまり（休みの取り方、困ったときの連絡先）

**1〜3か月目**のいちばん大事な目標は、**最初の成功**です。
「1つ目の仕事を、ひとりでやりきれた」という手ごたえは、どんな励ましの言葉よりも、本人の自信になります。

逆上がりの練習を思い出してください。最初は補助してもらい、次は少しだけ手をそえてもらい、ある日ひとりでくるっと回れた。あの瞬間の「できた！」です。
だから、最初の仕事は**少しがんばれば届く、小さめのもの**を選び、できたときには、まわりのみんなでしっかり喜びましょう。

### 6. 「お世話係」と「受け入れチェックリスト」で、あの人頼みにしない

歓迎プランがうまくいかない会社の多くは、**受け入れが「たまたま手のあいた先輩」まかせ**になっています。
やさしい先輩についた人は残り、忙しい先輩についた人はやめていく。それでは、新人さんの定着が運しだいになってしまいます。

そこで、2つの仕組みを用意します。

**① お世話係を決める**
入社の前に、新人さん1人に**お世話係の先輩を1人**決めておきます。仕事を教える係というより、「困ったら、まずこの人に聞けばいい」という**相談の入り口**です。
上司とは別の人にしておくと、上司には言いにくい小さな困りごとも話しやすくなります。

**② 受け入れチェックリストをつくる**
机・制服・名札・パソコンや記録用のタブレットの準備、チームへの連絡、入社日の予定の確認……。受け入れの準備は、細かいことの積み重ねです。
これを**「いつまでに・何を・誰が」**のチェックリストにしておけば、担当が変わっても、同じように準備できます。

| | ✕ あの人頼みの受け入れ | ◯ 仕組みで回る受け入れ |
|---|---|---|
| 準備 | 担当者の記憶がたより | チェックリストで、入社1か月前から順番に |
| 教える人 | その日に手のあいた人 | 決まったお世話係＋上司 |
| 進み具合 | 誰も知らない | 90日の旅の地図で、いまどこにいるかがわかる |

### 7. 最初の応援面談と、本人の成長計画

第9章で決めた**1対1の応援面談**は、新人さんにとって特に大切です。
ただし、新人さんの場合は、毎月の面談を待たずに、**少し早めに、少しこまめに**行います。

| いつ | ねらい | 聞くことの例 |
|---|---|---|
| 1週目の終わり | 最初の「あれ？」を早めに拾う | 「この1週間で、いちばんうれしかったこと・困ったことは？」 |
| 30日目 | 入社前のイメージとのちがいを確かめる | 「聞いていた話と、ちがったことはありますか？」 |
| 60日目 | 最初の成功をふり返り、次の目標を決める | 「ひとりでできるようになったことは何ですか？」 |
| 90日目 | 90日の旅をふり返り、成長計画をつくる | 「この会社を、友だちにすすめたいと思いますか？」 |

面談で大切なのは、**上司が話すより、本人の話を聞くこと**です。
新人さんは遠慮して、困りごとを自分から言いません。だからこそ、「困ったことはない？」ではなく、**「いちばん困ったことは何？」と、あると決めて聞く**のがコツです。

そして90日目には、本人と一緒に**成長計画**をつくります。
むずかしく考える必要はありません。次の3つを、本人の言葉で書いてもらうだけです。

- **いま、どこにいるか**（いまの役割、できるようになったこと）
- **これまで、どこにいたか**（前の仕事や経験で、ここで活かせること）
- **これから、どこへ行きたいか**（1〜2年後の目標、3〜5年後の目標）

そこに上司から、「あなたの強みはここだと思う」「ここが伸びしろだと思う」を書き添えます。
「この会社で、自分はこうやって成長していける」という道が見えると、人は長く働きたいと思えるようになります。この成長計画は、第15章「人が育つ仕組み」につながっていきます。

### 8. ものさしで「定着」をはかる

歓迎プランも、ほかの仕組みと同じで、つくって終わりではありません。
本当に新しい仲間が定着しているかを、**ものさし**で確かめます。

| ものさし | はかり方 | 何がわかる？ |
|---|---|---|
| 🚪 **入社して1年以内にやめた人の割合** | 1年以内にやめた人 ÷ その年に入社した人 | 歓迎プランが、いちばん最後に効いているか |
| 📩 **内定を出して入社しなかった人の割合** | 入社しなかった人 ÷ 内定を出した人 | 入社前のつながり（ようこそセットなど）が届いているか |
| ✅ **歓迎プランを予定どおり終えた割合** | 90日の旅を予定どおり終えた人 ÷ 入社した人 | 受け入れる側が、仕組みどおりに動けているか |
| 😊 **「来てよかった」アンケート** | 30日目・90日目に5点満点で聞く | 本人が、どう感じているか |
| 🤝 **「友だちにすすめたい」度合い** | 「この職場を、友だちにすすめたいですか？」を0〜10点で聞く | 職場そのものへの愛着 |

最初の「1年以内にやめた人の割合」は、わかるまでに1年かかる**結果の数字**です。
第6章の「テストの点数と毎日の勉強時間」を思い出してください。結果を待つだけでなく、**「予定どおり終えた割合」や「来てよかったアンケート」のような、毎月見られる数字**をあわせて追いかけると、手を打つのが早くなります。

> 💡 「友だちにすすめたい」度合いを0〜10点で聞いて、職場への愛着をはかる方法は、専門用語では「eNPS（イーエヌピーエス）」と呼ばれています。

## ⑦ 次の章へ

90日の歓迎プランで、新しい仲間が「来てよかった」と思えるスタートを切れるようになりました。
でも、90日はゴールではなく、**長い成長の旅の、最初の区間**です。90日目に書いた成長計画を本当に実現していくには、誰が教えても人が育つ道すじが必要です。

次の**第15章「人が育つ仕組み」**では、全員共通・役割別・リーダーの3段の育成メニューをつくり、「教えるのが上手な先輩についた人だけが育つ」状態から抜け出していきます。
この章でつくった90日の旅の地図は、その育成メニューの「最初の90日」の部分になります。

## ⑧ 講師ガイド

### この回のねらい
受講者が、次に迎える新しい仲間を1人思いうかべながら、90日の旅の地図と受け入れチェックリストの下書きを完成させること。

### 事前準備
- 受講者には、できれば第13章（仲間集めの仕組み）を終えてから参加してもらう
- 最近1〜2年で入社した人の数と、そのうち1年以内にやめた人の数・やめた時期を調べておいてもらう
- いま新人さんに渡している資料や、入社日の流れのメモがあれば持ってきてもらう
- できれば、入社1〜2年目の職員さん2〜3人に「入ったころ、何がいちばん困った？」と聞いてきてもらう
- 90日の旅の地図の記入用紙（A3）と、付せん（3色：本人・お世話係と上司・受け入れ担当）

### 時間配分（60分の例）

### 問いかけの例
- 「最近やめた方は、入社して何日目くらいに『ここじゃないかも』と思ったと思いますか？」
- 「新人さんが入社の日の朝、玄関に入って最初に目にするものは何ですか？ 最初に声をかけるのは誰ですか？」
- 「その新人さんが困ったとき、上司の次に、誰に聞けばいいか知っていますか？」
- 「90日の中で、新人さんが『できた！』と思える最初の仕事は何ですか？ それは何週目ですか？」
- 「受け入れ担当の人が休んだら、この準備は誰が代わりにできますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 90日の旅の地図が、教えることの一覧（研修の予定表）だけになる | 「その時期に、新人さんがどんな気持ちでいてほしいですか？」と聞き、「目指す状態」の列から書き直してもらう |
| 「うちは小さい会社だから、そこまでできない」と言う | ようこそカードと入社日の予定表の2つだけで始めてよいと伝える。手間ではなく、「ひとりで待つ時間をなくす」ことが目的だと話す |
| お世話係を上司と同じ人にしてしまう | 「上司には言いにくい小さな困りごとは、誰に話せますか？」と聞いて、別の先輩を選んでもらう |
| 最初の成功が大きすぎる（例：「ひとりで1日を回せる」） | 逆上がりの補助のたとえを思い出してもらい、5〜8週目にひとりでやりきれる小さな仕事に分けてもらう |
| 応援面談が、上司からの注意や指導の時間になる | 「本人が話す時間のほうが長かったですか？」と聞き、聞くことの例をそのまま使ってもらう |
| 定着のものさしが「1年以内にやめた人の割合」だけになる | 第6章の「テストの点数と毎日の勉強時間」を思い出してもらい、毎月見られる数字を1つ足してもらう |
