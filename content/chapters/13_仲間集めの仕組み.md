## ① この章でできるようになること

- 3年後のチーム図から、**「いつ・どの役割に・何人」**仲間を迎えるかの**仲間集めの計画表**をつくれる
- 能力と合言葉の2つの目で、**「どんな人と一緒に働きたいか」**をはっきり言葉にできる
- 会社と仕事の魅力、**向いている人・向いていない人**まで正直に書いた**求人メッセージ**をつくれる
- 説明会・見学・面接をどう組み合わせるかの**選び方の流れ**と、誰が面接しても同じものさしで見られる**面接シート**をつくれる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 人がやめてから、あわてて求人を出している。いつも「とにかく早く誰か」になってしまう
- 求人サイトにお金をかけているのに、応募が来ない。来ても、思っていた人とちがう
- 面接は社長の「なんとなくの感じ」で決めている。面接する人によって、合否がバラバラ
- 「経験者だから」と採用した人が、職場の雰囲気になじめず、まわりとぶつかってやめていった
- 入社してから「聞いていた話とちがう」と言われることがある

私は社長さんと採用のお話をするとき、まず「最近、入社してすぐにやめた方は、なぜやめたと思いますか？」とお聞きします。
すると、多くの社長さんが少し考えてから、「仕事ができなかったというより、**うちと合わなかった**んですよね」とおっしゃいます。

つまり、問題は面接の最後の5分にあるのではなく、**「どんな人と働きたいか」を決めないまま、仲間集めを始めている**ところにあるのです。
探しているものがはっきりしていなければ、見つかるはずがありません。そして、合わない人を迎えてしまうと、その人も、まわりの職員さんも、つらい思いをします。

この章では、第4章の**わが社の合言葉**と、第7章の**3年後のチーム図**を土台にして、合う仲間と出会うための流れを、最初から最後まで仕組みにしていきます。

### 目指す姿

- 人がやめてからではなく、**チーム図をもとに前もって**仲間集めを始めている
- 求人メッセージを読んだ人が、「ここは私のための職場だ」か「私には合わないかも」かを、応募する前に自分で判断できる
- 誰が面接をしても、**同じ質問・同じものさし**で見られる。合否の理由を言葉で説明できる
- 不合格になった人からも、「ていねいな会社だった」と言ってもらえる

## ③ 考え方

### 1. 仲間集めは「部活の新入部員さがし」

学校の部活の、新入部員の勧誘を思い出してください。
「誰でもいいから入って！」と呼びかける部と、「毎朝7時から練習します。きついけれど、県大会を本気で目指す仲間を探しています」と呼びかける部。

前の部には、たくさんの人が集まるかもしれません。でも、朝練が始まると「こんなはずじゃなかった」と、ひとり、またひとりとやめていきます。
後ろの部は、集まる人数は少ないかもしれません。でも、来た人は最初から覚悟ができているので、長く続きます。

会社の仲間集めも、まったく同じです。

| | ✕ 誰でもいいから来て | ◯ 合う人に来てほしい |
|---|---|---|
| 始めるとき | 人がやめてから、あわてて | チーム図をもとに、前もって |
| 求人の中身 | 給料・休み・勤務地の条件だけ | 会社の夢・合言葉・仕事のやりがい・向いていない人まで |
| 選び方 | 面接1回、社長の勘で決める | 見学・面接・体験で、おたがいに確かめ合う |
| 入社したあと | 「聞いていた話とちがう」 | 「聞いていたとおりだ」 |

ここで大事なのは、**仲間集めは「会社が選ぶ」だけではなく、「相手にも選んでもらう」もの**だということです。
お見合いと同じで、おたがいに「この人と一緒にやっていきたい」と思えてはじめて、うまくいきます。

この章でつくる流れは、次の図のようになります。

### 2. 始まりは「合言葉」と「チーム図」

仲間集めの出発点は、求人サイトではありません。
第4章でつくった**わが社の合言葉**と、第5章の**会社の夢の完成図**、そして第7章の**3年後のチーム図**です。

合言葉と夢は、「どんな人と一緒に働きたいか」を決める土台です。
求人を見た人が「この夢に、自分も参加したい」と思えるかどうか。まずは、社長自身が**1分で夢と合言葉を話せるか**を確かめてみてください。

チーム図は、「**いつ・どの役割に・何人**」が必要かを教えてくれます。
空欄の役割、社長が兼務している役割、新しい拠点を開くときに増える役割。チーム図を見れば、次の1〜2年でどんな仲間が必要になるかが、先に見えてきます。

おなかがすいた状態でスーパーに行くと、ついよけいなものを買ってしまいますよね。
仲間集めも同じで、**人がやめて困ってから探すと、「とにかく誰か」で決めてしまいがち**です。前もって計画を立てておけば、あわてずに、合う人を待つことができます。

### 3. 理想の仲間像は「能力」と「合言葉」の2つの目で見る

どんな人を探すかを考えるとき、見るところは大きく2つあります。

- **能力**：経験・資格・技術など、「その仕事ができるか」
- **合言葉**：わが社の合言葉に共感して、そのとおりに動けるか

この2つを組み合わせると、4つのタイプに分かれます。

![能力と合言葉の4つの組み合わせ。両方そろった人は迷わず仲間に、合言葉は合うが能力はこれからの人は育てる、能力は高いが合言葉が合わない人はいちばん注意、どちらも合わない人は見送る](assets/img/ch13-two-eyes.svg)

ここで私がいちばんお伝えしたいのは、**右下の「能力は高いけれど、合言葉が合わない人」に、いちばん気をつけてください**ということです。

能力は、入社してから育てることができます。資格も取れますし、技術も練習すれば身につきます。
でも、「何を大切にするか」という考え方は、大人になってから変えるのはとてもむずかしいのです。

私が出会った社長さんの中にも、「経験10年のベテランだから」と採用したら、「前の職場ではこうだった」が口ぐせで、まわりの職員さんが次々とやめてしまった、というお話をされた方がいました。
能力の高い人ほど、まわりへの影響も大きいのです。

もちろん、役割によっては、どうしても必要な資格や経験があります。
だから、「**必ずほしいこと**」と「**入ってから育てられること**」を分けて考えるのがコツです。

> 💡 専門用語では、能力が合うことを「スキルフィット」、価値観が合うことを「カルチャーフィット」といいます。

あわせて、**その役割の仕事のタイプ**も考えておきましょう。向いている人がちがうからです。

| 仕事のタイプ | どんな仕事？ | 向いている人 |
|---|---|---|
| 🔁 **くり返しの仕事** | 決まった手順を、毎回ていねいに回す（例：送迎、入浴の介助、請求の入力） | コツコツと、同じことを同じ質でくり返せる人 |
| 👀 **見守る仕事** | 手順どおりに仕事が回っているかを見て、整える（例：介護リーダー、事務のチェック役） | 細かいところに気づき、やさしく声をかけられる人 |
| 🎓 **専門の仕事** | 専門の知識で、ほかの人にはできない価値を生む（例：看護、ケアマネジャー、地域連携） | 学び続けるのが好きで、自分の判断に責任を持てる人 |
| 🧭 **計画する仕事** | 会社や部門全体を見て、先のことを考える（例：部長、拠点長） | 目の前のことだけでなく、1年先・3年先を考えられる人 |

### 4. 求人メッセージは「条件の一覧」ではなく「招待状」

求人サイトを見ると、多くの会社が「月給〇万円、週休2日、交通費支給」と、条件ばかりを並べています。
条件はもちろん大切です。でも、条件だけで選んだ人は、もっといい条件の会社があれば、そちらに移っていきます。

求人メッセージは、**「あなたと一緒に、こんな夢を目指したい」という招待状**です。
書くことは、次の10の材料です。

| 材料 | 自分に聞いてみる質問 |
|---|---|
| ① 会社の魅力 | 応募する人から見て、うちの会社のどこがいいと思われそう？ |
| ② 仕事の魅力 | この仕事の、どんな瞬間がうれしい？ やりがいは？ |
| ③ ほかとのちがい | 同じような会社とくらべて、うちは何がちがう？ |
| ④ ここで身につく力 | ここで5年、10年働いたら、どんな力がついている？ |
| ⑤ 職員さんの声 | いま働いている人は、どこが好きだと言っている？ |
| ⑥ 安心の証 | 信頼できる会社だとわかる事実は？（長く続いている制度・数字など） |
| ⑦ 向いている人 | どんな人なら、ここで生き生き働ける？ |
| ⑧ 向いていない人 | どんな人には、正直おすすめしない？ |
| ⑨ 選び方の流れ | 応募してから入社が決まるまで、何がある？ |
| ⑩ 入社したあと | 入社したら、最初の90日はどう過ごす？ |

この中で、社長さんがいちばん驚かれるのが、**⑧の「向いていない人」をあえて書く**ことです。
「応募が減ってしまうのでは？」と心配されるのですが、それでいいのです。

- ✕「アットホームな職場です。どなたでも歓迎！」 → 誰にも響かず、合わない人も応募してくる
- ◯「決められた手順どおりに、テキパキこなしたい方には、正直むずかしい職場かもしれません。私たちは、手順よりも『この方はどうしたいか』を先に考えるからです」 → 合う人は「ここだ！」と思い、合わない人は自分で判断できる

応募の数より、**合う人の割合**を増やす。これが、入社後にやめる人を減らすいちばんの近道です。

### 5. 届け方は「探している人がいる場所」から考える

いい求人メッセージができても、届かなければ意味がありません。
求人サイトだけに頼らず、**理想の仲間が、ふだんどこにいるか**から考えてみましょう。

| 届け方 | どんなときに強い？ |
|---|---|
| 👥 **職員さんからの紹介** | 合言葉を知っている人が紹介してくれるので、合う人が来やすい。いちばんおすすめ |
| 🏠 **自社のホームページ・SNS** | 職員さんの声や写真で、職場の雰囲気まで伝えられる |
| 🚪 **見学会・説明会** | 応募の前に、実際の職場を見てもらえる |
| 🏫 **学校・地域のつながり** | 専門学校、ハローワーク、地域の集まりなど、顔の見える関係から |
| 📰 **求人サイト・求人誌** | 多くの人に一度に届く。メッセージの中身で差がつく |

特に**職員さんからの紹介**が多い会社は、職員さんが「自分の友だちにすすめたい」と思っている会社です。紹介の数は、職場の元気さをはかるものさしにもなります。

### 6. 選び方の流れは「何回も会って、おたがいを知る」

面接1回、30分だけで「一緒に働くかどうか」を決めるのは、とてもむずかしいことです。
相手も緊張していますし、こちらも、その人のことをほんの少ししか知ることができません。

そこで、選び方の流れを**いくつかのステップに分けて**組み立てます。

| ステップ | ねらい | 例 |
|---|---|---|
| 説明会・見学 | 会社の夢と職場の雰囲気を、自分の目で見てもらう | 毎月1回の見学会、30分の職場案内 |
| 1回目の面接 | 合言葉と、これまでの経験を聞く | 拠点長と管理部の2人で、45分 |
| 現場の体験 | 実際の仕事を少しやってみて、おたがいに確かめる | 半日、先輩と一緒に過ごす |
| 2回目の面接 | 夢と役割の約束書を伝え、最後の気持ちを確かめる | 社長と、30分 |

ステップを増やすほど時間はかかりますが、**入社してからの「こんなはずじゃなかった」が減ります**。
特に現場の体験は、応募した人にとっても「ここで働く自分」を想像できる、いちばんの材料になります。

> 💡 必要に応じて、前の職場の方に働きぶりを聞く「身元の確認」や、性格や考え方の傾向を見る「適性検査」を入れる会社もあります。入れるかどうかは、役割の重さで決めましょう。

### 7. 面接は「準備が8割」。質問と評価シートを先につくる

面接でよくある失敗は、**面接する人によって、聞くことも、見るところもバラバラ**なことです。
料理コンテストで、審査員がそれぞれ好きな基準で点をつけたら、結果に納得できませんよね。だから、コンテストには必ず**審査表**があります。

面接も同じで、次の3つを前もってつくっておきます。

1. **面接チェックリスト**：面接の前・当日・あとに、誰が何をするか（部屋の準備、資料、案内、次の連絡など）
2. **面接の質問**：役割と合言葉に合わせて、全員に同じ質問をする
3. **評価シート**：見るところ・どんな答えなら◎か・合格ラインを決めておく

質問のつくり方には、コツが2つあります。

| | ✕ よくある質問 | ◯ おすすめの質問 |
|---|---|---|
| 過去の行動を聞く | 「あなたの長所は何ですか？」（用意してきた答えが返ってくる） | 「前の職場で、決まりと、目の前の人の希望がぶつかったことはありますか？ そのとき、どうしましたか？」 |
| 場面で聞く | 「チームワークは大切だと思いますか？」（誰でも「はい」と答える） | 「仕事が終わらず、まわりも忙しそうなとき、あなたならどうしますか？」 |

「〜だと思いますか？」と考えを聞くと、正解がわかってしまいます。
**「そのとき、実際にどうしましたか？」と行動を聞く**と、その人らしさが見えてきます。

そして、合言葉の1つ1つに、確かめる質問を1つずつ用意しておくと、評価シートとぴったりつながります。

### 8. 最後は「手紙」で、気持ちよく終わる

選び方の流れの最後に、合格した人と、残念ながらご縁がなかった人の両方に、手紙を送ります。

- **合格の手紙**：「なぜあなたと一緒に働きたいのか」を、面接で聞いた話を入れて伝えます。入社の日までの不安を、期待に変えるための手紙です
- **お礼の手紙**：時間をつくって来てくれたことへの感謝を伝えます。不合格の理由をくわしく書く必要はありませんが、ていねいに

特に、**お礼の手紙**を大切にしてください。
地域で事業をしている会社にとって、不合格になった人は、将来のお客様やそのご家族、あるいは誰かを紹介してくれる人かもしれません。
「落ちたけれど、ていねいな会社だった」と言ってもらえるかどうかで、町での評判は大きく変わります。

## ⑦ 次の章へ

合う仲間と出会えたら、次は**その人が「来てよかった」と思える最初の90日**をつくる番です。
どんなに合う人を迎えても、入社した日に誰も声をかけてくれず、何をしていいかわからないまま1週間が過ぎたら、その人の気持ちは少しずつ離れていきます。

次の**第14章「入社90日の歓迎プラン」**では、入社1か月前から12週目までの「90日の旅の地図」と、受け入れる側のチェックリストをつくります。
この章の求人メッセージに書いた「入社したあとの流れ」を、本当にそのとおりにする仕組みです。

## ⑧ 講師ガイド

### この回のねらい
受講者が、3年後のチーム図から仲間集めの計画を立て、いちばん急ぐ役割について、求人メッセージ・選び方の流れ・面接シートの下書きを完成させること。

### 事前準備
- 受講者には、第4章（わが社の合言葉）と第7章（3年後のチーム図と役割の約束書）を終えてから参加してもらう
- いま使っている求人の文章（求人サイトの画面のコピーなど）と、面接で使っている質問があれば持ってきてもらう
- 最近1〜2年で入社した人と、そのうち1年以内にやめた人の数を調べておいてもらう
- 能力と合言葉の4つのタイプの図（大きく印刷したもの）と、付せん（2色）

### 時間配分（90分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「最近やめた人は、能力と合言葉のどちらが合わなかった？」を1人ひとことで |
| 0:05〜0:20 | お話：③考え方の1〜3 | 部活のたとえと、能力と合言葉の4つのタイプ。「能力は高いが合言葉が合わない人」の話をいちばん強調する |
| 0:20〜0:35 | ワーク：ステップ1〜4 | 仲間集めの計画表を書き、いちばん急ぐ役割を1つ選んで理想の仲間像まで |
| 0:35〜0:45 | お話：③考え方の4〜5 | 「向いていない人」を書く理由。✕と◯の求人メッセージを読みくらべる |
| 0:45〜1:00 | ワーク：ステップ5〜6 | 求人メッセージの材料から本文へ。ペアで読み合い、「応募したくなるか」「合わない人は自分で気づけるか」を聞き合う |
| 1:00〜1:10 | お話：③考え方の6〜8 | 選び方の流れと、行動を聞く質問のつくり方 |

### 問いかけの例
- 「この役割の人が、もし明日やめたら、いまから何か月で次の人を迎えられますか？」（計画を前もって立てる大切さに気づいてもらうとき）
- 「その『必ずほしいこと』は、入社してから育てることはできませんか？」（条件が多すぎるとき）
- 「この求人を読んで、合わない人は自分で『やめておこう』と気づけますか？」
- 「その質問には、誰でも『はい』と答えられませんか？」（考えを聞く質問になっているとき）
- 「面接した2人の点数が大きくちがったら、どうやって決めますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 計画表に、いま足りない人だけを書く | チーム図を横に置き、空欄・社長兼務・新しい拠点で増える役割を1つずつ確かめてもらう |
| 理想の仲間像が「明るく元気で、経験豊富で、リーダーシップがあって……」と、全部入りになる | 「必ずほしいこと」を1〜2つにしぼり、残りは「入ってから育てられること」に移す |
| 「向いていない人」を書くのをこわがる | 「応募の数より、合う人の割合」と伝え、入社後すぐやめた人の数を思い出してもらう |
| 求人メッセージが、給料・休みなどの条件ばかりになる | 「この仕事で、いちばんうれしい瞬間は？」と聞いて、仕事の魅力から書き直してもらう |
| 面接の質問が「長所は？」「志望動機は？」だけになる | 「そのとき、実際にどうしましたか？」の形に言いかえる練習をする |
| 評価シートの合格ラインが決められない | まず「合言葉が合わない人は、ほかが高くても合格にしない」の1本だけ決めてもらう |
