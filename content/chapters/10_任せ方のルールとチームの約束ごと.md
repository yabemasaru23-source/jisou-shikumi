## ① この章でできるようになること

- 「任せる」には**7つの段階**があることを知り、決めごとごとに「いまはどの段階か」を言えるようになる
- 会社の決めごとを洗い出して、**いまの段階 → 目指す段階 → そのために必要な仕組み**を1枚にまとめた**「任せ方ボード」**をつくれる
- 上司と部下、部署と部署が気持ちよく仕事をするための**「チームの約束ごと」**を、自分の会社の言葉で決められる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 「任せたよ」と言ったのに、気になって結局あとから口を出してしまう
- 部下からは「任されたと思って決めたのに、あとでひっくり返された」という声が出る
- 逆に「全部任せた」つもりが、いつのまにか丸投げになって、トラブルになってから知る
- 「これ、私が決めていいんですか？」という確認の電話が、一日に何本も社長にかかってくる
- 別の部署の人から急に仕事を頼まれて、自分の上司が知らないうちに予定がくずれる

私が社長さんとお話ししていて、本当によく聞くのが「うちの社員は、なかなか自分で決めてくれないんですよ」というお悩みです。
ところが、社員さんの側にお話を聞くと、まったく逆の答えが返ってきます。
「どこまで自分で決めていいのか、わからないんです。前に自分で決めたら、あとで社長にやり直しになったので……」

ひだまりケアの日向社長も、最初はこうおっしゃっていました。
「森さんには拠点を任せているつもりなんです。でも、シフトのことも、備品のことも、結局は私に電話がかかってくるんですよね」

つまり、問題は**社員さんのやる気ではなく、「どこまで任されているのか」が見えていないこと**なんです。
「任せる」と「任せない」の2つしかないと思っていると、こうしたすれちがいが起こります。
実は、任せ方にはその間にいくつもの段階があります。それを上司と部下で同じ言葉で話せるようにするのが、この章のねらいです。

### 目指す姿

- 大事な決めごとについて、「これは段階⑥（あなたが決めて、あとで教えて）ね」と、上司と部下が同じ言葉で話せる
- 社長に届く「これ、決めていいですか？」の確認が減り、社長が未来をつくる仕事に使える時間が増える
- 段階を上げるときは、「そのために必要な仕組み」を先に用意してから手をはなしている
- 部署をまたぐお願いや、予定どおりいかないときの知らせ方が決まっていて、「聞いてないよ」が起きない

## ③ 考え方

### 1. 任せることは「自転車の練習」と同じ

子どもに自転車を教えたときのことを思い出してください。
最初は補助輪をつけて、次は補助輪を外して、うしろの荷台をしっかり持って走ります。
少し安定してきたら、持っている手を軽くして、最後には、そっと手をはなしますよね。

もし初日から、いきなり手をはなしたらどうなるでしょう。転んで、こわくなって、もう乗りたくなくなってしまいます。
反対に、いつまでも荷台を持ち続けていたら、子どもはいつまでもひとりで乗れるようになりません。

仕事を任せるのも、まったく同じです。

| | ✕ うまくいかない任せ方 | ◯ 自走につながる任せ方 |
|---|---|---|
| いきなり全部 | 「今日から全部任せたから」→ 何をどこまで決めていいかわからず、転ぶ | 決めごとごとに段階を決めて、少しずつ手をはなす |
| いつまでも持ったまま | 「任せた」と言いながら、全部あとから口を出す | 決めた段階のあいだは、口を出さずに見守る |
| 手をはなす前の準備 | 気合いと「がんばってね」だけ | 基準・やり方の手順・報告のタイミングを先に用意する |

大切なのは、**「任せる／任せない」の2つではなく、その間にある段階を一段ずつ上がっていく**ことです。

### 2. 任せ方の「7つの段階」

任せ方は、上司がどのくらい決めて、部下がどのくらい決めるかで、7つの段階に分けられます。

| 段階 | ひとことで | 上司のセリフの例 | 決めるのは |
|---|---|---|---|
| ① | **私が決める** | 「今回はこうします。この通りにお願いします」 | 上司 |
| ② | **私が決めて、理由を話す** | 「こうしようと思います。なぜかというと……」 | 上司 |
| ③ | **意見を聞いてから、私が決める** | 「あなたの考えを聞かせて。それをふまえて私が決めます」 | 上司 |
| ④ | **一緒に話し合って決める** | 「2人とも納得できる答えを、一緒に探しましょう」 | 上司と部下 |
| ⑤ | **あなたが決める。私は意見を言う** | 「私ならこうするけど、最後はあなたが決めていいよ」 | 部下 |
| ⑥ | **あなたが決めて、あとで教えて** | 「決めたら、どうしたかだけ教えてね」 | 部下 |
| ⑦ | **すっかりお任せ** | 「この件は、もう報告もいらないよ。全部お願いします」 | 部下 |

![任せ方の7つの段階。段階①では上司が全部決め、段階が上がるほど部下が決める部分が増え、段階⑦では部下がすべて決める](assets/img/ch10-levels.svg)

ここで大事なのは、**どの段階が「正しい」ということはない**ということです。
大きなお金が動くことや、会社の方向を変えることは、ずっと①〜④のままでいいものもあります。
逆に、毎日のように起きる小さな決めごとが①のままだと、社長のところに確認の電話が鳴りっぱなしになります。

> 💡 専門用語では、任せることを「権限委譲（デリゲーション）」といいます。この教材では「任せ方」と呼んでいきます。

### 3. 段階は「人」ではなく「決めごと」ごとに決める

「森さんには、もう全部任せているんです」という言い方を、よく耳にします。
でも、本当にそうでしょうか。

同じ森さんでも、決めごとによって段階はちがうはずです。

| 決めごと | 森さんとの段階（ひだまりケアの例） |
|---|---|
| 拠点の行事やレクリエーションの中身 | ⑦ すっかりお任せ |
| 毎月のシフトの組み方 | ③ 意見を聞いてから、社長が決める |
| 拠点の備品を買う | ① 社長が決める |
| パートさんの採用 | ① 社長が決める |

こうして書き出してみると、「全部任せている」つもりだったのが、実はほとんど①〜③だった、ということがよくあります。
日向社長も、書き出したあとで「私、森さんに任せているつもりで、ほとんど自分で決めていたんですね」と苦笑いされていました。

**「誰に任せるか」ではなく、「どの決めごとを、どの段階で任せるか」**。この見方に変えるだけで、上司と部下のすれちがいはぐっと減ります。

### 4. 任せ方ボード：いま → 目指す → 必要な仕組み

決めごとと段階を1枚の表にしたものが、**「任せ方ボード」**です。
書くことは、次の4つだけです。

| 列 | 書くこと |
|---|---|
| 決めごと | 会社の中で、誰かが決めなければいけないこと（シフト、備品、採用、苦情への返事 など） |
| いまの段階 | 実際には、いまどの段階になっているか（正直に） |
| 目指す段階 | 3年後のチーム図で、その役割の人が自分で回せるようにするなら、どの段階にしたいか |
| 必要な仕組み | 段階を上げるために、先に用意しておくもの（基準・仕事のレシピ・お金の上限・報告のタイミング など） |

![任せ方ボードの記入例。決めごとごとに、いまの段階（白い丸）から目指す段階（黄色い丸）へ矢印がのびている](assets/img/ch10-board.svg)

ポイントは、**4列目の「必要な仕組み」**です。
自転車でいえば、手をはなす前に「ブレーキのかけ方を教える」「広い公園で練習する」のと同じです。

- 備品を任せたいなら → 「1回いくらまで」「月の予算はいくら」というお金の上限
- シフトを任せたいなら → シフトの基本パターンと、急な休みが出たときの連絡の流れ
- 苦情への返事を任せたいなら → 対応の手順と、「その日のうちに上司へ報告」というルール

仕組みのないまま手をはなすと、それは「任せた」ではなく**「丸投げ」**になってしまいます。
反対に、仕組みがそろえば、上司は安心して手をはなせますし、部下も安心して決められます。

### 5. 段階は一気に上げず、本人と一緒に決める

任せ方ボードを書くときに、守ってほしいことが2つあります。

**ひとつめは、段階は1回に1〜2段ずつ上げること。**
①から⑦にいきなり飛ぶと、自転車の初日に手をはなすのと同じことになります。
「3か月は⑤で、うまくいったら⑥へ」のように、ステップを刻むのがおすすめです。

**ふたつめは、段階を本人と一緒に決めること。**
上司が「これは⑥で任せた」と思っていても、部下が「③のつもり（最後は社長が決める）」と思っていたら、すれちがいは消えません。
私は、上司と部下がそれぞれ「いまの段階」を同時に指で出し合ってみる、というやり方をよくおすすめしています。ずれていたら、そこが話し合うべきところです。

任せ方ボードができたら、第9章の**1対1の応援面談**で、ときどき見直してください。
「この決めごとは、そろそろ⑥に上げてもいいかな？」と話せるようになると、部下にとっても成長が目に見えるようになります。

### 6. チームの約束ごと：みんなが気持ちよく動くための「試合のルール」

任せ方がはっきりしても、もうひとつ困ることがあります。
それは、**上司と部下、部署と部署の「関わり方」がばらばら**なことです。

サッカーで考えてみましょう。
選手それぞれがどんなに上手でも、「オフサイドのルール」や「ボールを持った人にどう声をかけるか」がチームでそろっていないと、試合になりませんよね。

会社にも、みんなで守る**「試合のルール」**が必要です。これを**「チームの約束ごと」**と呼びます。
よく使われる約束ごとを、私の言葉で9つにまとめました。

| 約束ごと | ひとことで言うと |
|---|---|
| ① 3つに同意してから始める | 仕事を頼むときは、上司と部下で「中身・やり方・期限」に同意してからスタートする |
| ② 予定どおりいかないときは、すぐ知らせる | 知らせがなければ「予定どおり進んでいる」とみんなが考えてよい |
| ③ 上司はひとり | 仕事の指示は、直属の上司からだけ出す（第7章の約束と同じ） |
| ④ 社長も例外なし | 社長がほかの役割を兼務しているときは、その役割の人として約束ごとを守る |
| ⑤ 上司が留守のときは、その上の上司へ | 上司が休みや出張のときに迷ったら、上司の上司に相談する |
| ⑥ 部署をまたぐお願いは、両方の上司に知らせる | 直接お願いしてよい。ただし、お願いした人・された人の上司にも伝える |
| ⑦ 任せるときは、ゴールと期限を言葉にする | できれば紙に書き、本人の「やります」を聞いてから任せる |
| ⑧ 任せっぱなしにも、口出ししすぎにもしない | 報告のタイミングを先に決めて、それ以外は見守る |
| ⑨ 集中する時間を大切にする | 相手が集中している時間には、急ぎでない声かけをしない |

> 💡 専門用語では、こうしたルールを「協業のガイドライン」などと呼ぶことがあります。

### 7. 特に大事な3つの約束

9つすべてが大事ですが、私が「まずこれだけは」とお伝えしているのは、次の3つです。

**① 3つに同意してから始める**
「あれ、やっておいて」で始まった仕事は、たいてい「思っていたのとちがう」で終わります。
**中身（何を）・やり方（どうやって）・期限（いつまでに）**の3つを、頼む側と頼まれる側で確かめ合ってから始める。これだけで、やり直しがぐんと減ります。

**② 予定どおりいかないときは、すぐ知らせる**
この約束の裏側には、「知らせがなければ、予定どおり」という安心があります。
上司は、何度も「あれ、どうなった？」と聞かなくてよくなり、部下は、見張られていると感じずに仕事ができます。
ひだまりケアの合言葉「②迷ったら、まず聞く」とも、ぴったり重なりますね。

**⑥ 部署をまたぐお願いは、両方の上司に知らせる**
訪問介護の職員さんが、デイサービスの職員さんに直接手伝いを頼むのは、とても良いことです。
ただ、お互いの上司が知らないと、「今日はなぜか人が足りない」というナゾの穴があいてしまいます。
**直接お願いしていい。そのかわり、両方の上司にひとこと伝える。** これで、助け合いとチームの予定の両方を守れます。

### 8. 約束ごとは「選んで、自分たちの言葉に書き直す」

ここで紹介した9つを、そのまま壁に貼る必要はありません。
むしろ、**自分の会社に合うものを選び、自分たちの言葉に書き直す**ことが大切です。

- ✕ 本やテキストの言葉をそのまま書き写す → 誰の心にも残らない
- ◯ 「うちの会社だと、こういう場面だよね」と話しながら書き直す → 自分たちのルールになる

たとえば、ひだまりケアでは「⑨集中する時間を大切にする」を、こう書き直しました。
「記録を書いている人には、急ぎでなければ声をかけない。記録の時間は、ご利用者を守る時間」

そして最後に、**④社長も例外なし**を忘れないでください。
社長が約束ごとを破ると、ほかの誰も守らなくなります。社長が一番に守ることが、約束ごとを根づかせるいちばんの近道です。

## ⑤ できあがるもの

入力した内容から、次のものが自動でできあがります。

- **任せ方ボード**：決めごとごとの、任せる相手・いまの段階・目指す段階・いつまでに・必要な仕組みの一覧。1対1の応援面談で、上司と部下が一緒に見直せます
- **任せ方の7つの段階カード**：①〜⑦の段階とセリフの例。上司と部下が同じ言葉で話すための早見表です
- **チームの約束ごとポスター**：わが社の言葉で書いた約束ごと。休憩室や事務所の壁に貼れるA4サイズ
- **伝える計画**：誰に、いつ、どうやって伝えて練習するかの一覧

## ⑥ セルフチェック

- [ ] 「任せる・任せない」の2つではなく、7つの段階で話せるようになった
- [ ] 任せ方ボードは「人」ではなく「決めごと」ごとに書いてあり、いまの段階を正直に選んでいる
- [ ] 段階を上げる決めごとには、「必要な仕組み」が書いてあり、一気に何段も上げていない
- [ ] チームの約束ごとは、選んだうえで自分たちの言葉に書き直してあり、社長も守ることになっている
- [ ] 任せ方ボードと約束ごとを、誰に・いつ・どうやって伝えるかが決まっている

## ⑦ 次の章へ

任せ方の段階を上げようとすると、必ずぶつかる壁があります。
それは、**「任せたいけれど、やり方が人によってちがう」「あの人しかやり方を知らない」**という壁です。

任せ方ボードの「必要な仕組み」の欄に、「〇〇の手順」「〇〇のやり方」と何度も書いた方も多いのではないでしょうか。

次の**第11章「会社の取扱説明書と仕事のレシピ」**では、全員が知っておくべき会社のことを1冊にまとめた「取扱説明書」と、誰がやっても同じようにできる「仕事のレシピ」をつくります。
レシピがそろうほど、任せ方ボードの矢印は、安心して右へ進めるようになります。

## ⑧ 講師ガイド

### この回のねらい
受講者が「任せ方の7つの段階」を自分の言葉で説明でき、自社の決めごとを5つ以上洗い出した任せ方ボードと、自社用に書き直したチームの約束ごとの下書きを完成させること。

### 事前準備
- 受講者には、第7章（チーム図と役割の約束書）と第9章（会社のリズム）を終えてから参加してもらう
- この1週間で、部下から「これ、決めていいですか？」と聞かれたことをメモしてきてもらう
- 7つの段階を書いたカード（①〜⑦の7枚を1人1セット）、任せ方ボードの記入用紙（A3）

### 時間配分（60分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「任せたのに、うまくいかなかったこと」を1人ひとことで |
| 0:05〜0:15 | お話：③考え方の1〜3 | 自転車の練習のたとえ。7つの段階の表とセリフを読み上げる。「人ではなく決めごとごと」を強調する |
| 0:15〜0:30 | ワーク：ステップ2〜3（決めごとの洗い出しと任せ方ボード） | メモしてきた「決めていいですか？」から書き出す。いまの段階は正直に |
| 0:30〜0:35 | 段階カードあそび | ペアで、相手の決めごとを1つ聞き、「いまの段階」を同時にカードで出し合う。ずれたら理由を話す |
| 0:35〜0:45 | お話：③考え方の4〜8 | 必要な仕組みのない手ばなしは「丸投げ」。チームの約束ごとの9つと、特に大事な3つ |
| 0:45〜0:55 | ワーク：ステップ5〜6（約束ごとを選んで書き直す） | 「うちの会社だと、どんな場面？」と考えながら、1〜2文で |
| 0:55〜1:00 | まとめ | ステップ4（最初に手をはなす決めごと）を1人ずつ宣言して終了 |

### 問いかけの例
- 「『全部任せている』という方、決めごとを1つずつ見ていくと、本当に⑦ですか？」
- 「その決めごとを⑥に上げるには、部下の方に何を渡せば安心ですか？」（必要な仕組みが書けないとき）
- 「部下の方は、いまの段階をいくつだと思っていると思いますか？」
- 「この1か月、社長ご自身が約束ごとを破ってしまいそうな場面はありますか？」
- 「知らせがないとき、『予定どおり』と信じて待てますか？ 待てないとしたら、何があれば待てますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「いまの段階」を、実際より高く書いてしまう | 「最後にひっくり返したことはありませんか？」と聞く。ひっくり返すなら、実際は①〜③ |
| 全部の決めごとを⑦にしたがる | 「大きなお金や会社の方向は、①〜④のままでいい」と伝える。自転車の初日に手をはなす話を思い出してもらう |
| 必要な仕組みの欄が「本人のやる気」「がんばる」になる | 「新人さんが同じ立場になっても決められる道具は何ですか？」と聞いて、基準・手順・上限・報告のタイミングに言いかえる |
| 「人」ごとに書いてしまう（「森さん：⑥」） | 「森さんのどの決めごとですか？」と聞いて、決めごとごとに分けてもらう |
| 約束ごとを、例の文のまま書き写す | 「職員さんが読んだら、どの場面を思いうかべますか？」と聞いて、自社の場面の言葉にする |
| 約束ごとが10個以上になる | 「いちばん困っていることに効くもの」から5〜7つにしぼる。残りは半年後の見直しで |
| 「社長も例外なし」に抵抗がある | 社長が守らないと誰も守らなくなることを伝え、兼務している役割では「その役割の人」として守ることを確認する |
