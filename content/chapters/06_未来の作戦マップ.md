## ① この章でできるようになること

- 会社の夢に向かう**「3年後のゴール」**を、数字1つで決められる
- そのゴールにたどり着くための**「8つの作戦」**と、進み具合をはかる**「ものさし」**を決められる
- 作戦ごとに必要な**「仕組み」**を書き出して、**1枚の「未来の作戦マップ」**にまとめられる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 会社の夢（ビジョン）は立派だけど、毎日の仕事とのつながりが見えない
- 毎年目標を立てるのに、いつのまにか忘れられて、達成できずに終わる
- 社員さんはみんながんばっているのに、会社全体としてはバラバラに動いている
- 「次に何をやるか」を、社長の思いつきで決めている

私はこれまで、「夢はあるのに、なかなか近づかない」という社長さんとたくさん出会ってきました。
お話を聞いていて気づいたのは、**夢が遠すぎて、明日の行動に結びついていない**ということです。

第5章で描いた「会社の夢の完成図」は、10〜20年先の姿です。
富士山のてっぺんを見上げているだけでは、今日どっちに一歩をふみ出せばいいのかわかりませんよね。

必要なのは、**「まずはあそこまで行こう」という途中の目印**と、**「いま、どのくらい登れたかな？」をはかるものさし**です。
それを1枚にまとめたものが、この章でつくる**「未来の作戦マップ」**です。

### 目指す姿

- 社員さんの誰に聞いても、「うちの3年後のゴールは〇〇です」と同じ答えが返ってくる
- 毎月の会議で、決まった数字を見て「順調だね」「ちょっと遅れているね」と話せる
- 「その仕事は、8つの作戦のどれにつながるの？」で、やることの順番を決められる

## ③ 考え方

### 1. 山登りで考えてみよう

未来の作戦マップは、山登りにたとえるとよくわかります。

| 山登り | 未来の作戦マップ | 意味 |
|---|---|---|
| 🏔️ 山のてっぺん | **会社の夢の完成図**（第5章） | 10〜20年後に、会社がなっていたい姿 |
| 🚩 3合目の山小屋 | **3年後のゴール** | 夢に向かう途中の、3年後の目印。数字1つで表す |
| 🗺️ 登山ルート | **8つの作戦** | ゴールにたどり着くために、特に力を入れること |
| 📏 標高計 | **ものさし** | 作戦がどこまで進んだかをはかる数字 |
| 👟 毎日の歩き方や道具 | **仕組み** | 作戦を実行するために、くり返しやること |

これを1枚の絵にすると、こうなります。

![未来の作戦マップのしくみ：夢の完成図 → 3年後のゴール1つ → 8つの作戦 → 仕組み最大64個](assets/img/ch06-structure.svg)

実際のマップは、9×9のマス目で作ります。
真ん中にゴール、そのまわりに8つの作戦、さらにその外側に仕組みが広がっていく形です。

> 💡 専門用語では、3年後のゴールを「SO（戦略的目標）」、8つの作戦とものさしを「KSI（戦略的指標）」といいます。この教材では、わかりやすい言葉で進めていきます。

### 2. 3年後のゴールは「数字1つ」にしぼる

ゴールを決めるとき、いちばん多い失敗があります。
それは、**ゴールをいくつも並べてしまうこと**です。

> ✕「売上5億円、利益3,000万円、拠点を3つ、職員60人」

私もよくこういうゴールを見せていただくのですが、気持ちはとてもよくわかります。どれも大事ですからね。

でも、ゴールが4つあると、どれかが遅れても「ほかの3つは順調だから」と言いわけができてしまいます。
社員さんも「結局どれを一番がんばればいいの？」と迷ってしまいます。

サッカーを思いうかべてください。
「ゴールをたくさん決める」「パスをたくさんつなぐ」「たくさん走る」……どれも大事ですが、試合の勝ち負けを決めるのは**「点数」ただ1つ**です。パスも走ることも、点を取るための手段ですよね。

会社も同じです。

> ◯「2029年9月30日までに、**経常利益3,000万円**を達成する」

売上や拠点の数、職員の数は、このゴールにたどり着くための**手段**です。手段は、8つの作戦の方に入れます。

**ゴールにする数字の選び方**

| 数字 | どんな会社に向いている？ |
|---|---|
| 経常利益（本業とその他でしっかり残るもうけ） | もうかる体質に変えたい会社。**多くの会社におすすめ** |
| 粗利（売上から仕入れや材料費を引いたもうけ） | 商品やサービスの価値を高めたい会社 |
| 売上 | 始めたばかりで、まずは大きくなりたい会社 |
| その他（会員数・契約数など） | もうけより先に、お客様を増やしたいビジネス |

### 3. いいゴールかどうかの「5つのチェック」

いいゴールは、次の5つにすべて「はい」と答えられます。

| チェック | 質問 | ✕ の例 | ◯ の例 |
|---|---|---|---|
| ① はっきりしている | 誰が読んでも、同じ意味になる？ | 「会社を大きくする」 | 「経常利益を3,000万円にする」 |
| ② 数えられる | できた・できないが、数字でわかる？ | 「12億円規模」 | 「12億円」 |
| ③ 届きそう | 背のびすれば届く高さ？ | 3年で利益を100倍 | 3年で利益を2倍 |
| ④ 夢につながる | 達成したら、夢の完成図に近づく？ | 夢と関係ない数字 | 夢の実現に必要なお金や体制につながる |
| ⑤ しめ切りがある | 「いつまでに」が入っている？ | 「なるべく早く」 | 「2029年9月30日までに」 |

書き方の型は、これだけです。

> **「〇〇年〇月〇日までに、〇〇を〇〇にする」**

> 💡 この5つのチェックは、専門用語では「SMART（スマート）の法則」と呼ばれています。

### 4. 作戦は「やること」と「ものさし」の2段で書く

8つの作戦は、それぞれ**上の段に「やること（作戦）」、下の段に「ものさし（数字）」**を書きます。

| | ◯ いい例 | ✕ よくある失敗 |
|---|---|---|
| 上の段：やること | 長く働ける職場をつくる | 「離職率」（数字の名前だけで、何をするかがわからない） |
| 下の段：ものさし | 離職率を 25% → 10% にする | 「職員の満足を高める」（数字がなくて、はかれない） |

そして、**1つの作戦に、ものさしは1つだけ**にします。
ものさしが3本も4本もあると、ゴールと同じで、何を一番大事にするのかがぼやけてしまうからです。

### 5. 8つの作戦は「10の見方」から選ぶ

作戦が「売る」ことばかりにかたよると、人や仕組みが追いつかず、3年目に息切れしてしまいます。
山登りでも、スピードばかり気にして水や食料を準備しないと、途中で動けなくなりますよね。

そこで、次の**10の見方**から、あなたの会社にとって大事な**8つ**を選びます。

| 見方 | 自分に聞いてみる質問 | ものさしの例 |
|---|---|---|
| 💰 **お金** | 会社のお財布はどうなっていたい？ | 利益率、一人あたりのもうけ |
| 😊 **お客様の笑顔** | お客様にどう喜ばれていたい？ | 満足度、リピート率、紹介の数 |
| ⚙️ **仕事のやり方** | どんなムダのない仕事ぶりになっていたい？ | 作業時間、ミスの数 |
| 🌱 **人の成長** | 仲間はどう成長していたい？ | 研修を終えた人数、資格を持つ人数 |
| ⭐ **評判とファン** | 町の人になんて言われていたい？ | 名指しでの問い合わせ数、口コミの数 |
| 🤝 **売れる力** | どんなふうに買ってもらえていたい？ | 契約できた割合、新しい契約の数 |
| 📣 **知ってもらう力** | どうやって見つけてもらっていたい？ | 問い合わせの数、見学に来た人数 |
| 🎁 **商品・サービスの自慢** | どんな「これがうちの自慢！」を届けていたい？ | 品質基準の達成率、クレームの数 |
| 🏠 **チームと職場** | どんな職場で働いていたい？ | 離職率、職員の満足度 |
| 🧭 **次のリーダー** | 誰が会社を引っぱっていたい？ | 任せられるリーダーの人数 |

このうち、**💰お金・😊お客様の笑顔・⚙️仕事のやり方・🌱人の成長**の4つは、会社のバランスを見るための基本の見方です。
**この4つは、できるだけ入れてください。**

> 💡 この4つの見方は、専門用語では「バランス・スコアカード」と呼ばれる考え方がもとになっています。

### 6. 「テストの点数」と「毎日の勉強時間」

ものさしには、2つの種類があります。

| 種類 | たとえると | 特徴 | 会社の例 |
|---|---|---|---|
| 🏁 **結果の数字** | テストの点数 | 最後に出てくる数字。わかったときには、もうやり直せない | 売上、利益、離職率 |
| 👣 **行動の数字** | 毎日の勉強時間 | 結果の前に動く数字。毎週・毎月チェックできて、すぐ手を打てる | 面談をした回数、提案した件数、研修の受講率 |

テストの点数を上げたければ、テストの日を待つのではなく、毎日の勉強時間をチェックしますよね。

3年後のゴールは「結果の数字」です。
だからこそ、**8つの作戦のものさしには「行動の数字」もまぜておく**と、毎月の会議で「じゃあ今月は何をしよう？」が決めやすくなります。

### 7. 仕組みは「作戦のために、くり返しやること」

8つの作戦のまわりに、それぞれの作戦を実行するための**仕組み**を最大8つ書きます。

- ✕「がんばる」「気をつける」「徹底する」 → 気合いは仕組みではありません
- ◯「月に1回の、上司との1対1の応援面談」「新人さんの90日育成プログラム」 → 誰がやっても同じようにできます

見分け方はかんたんです。
**「明日入ったばかりの新人さんでも、同じようにできる？」**と聞いてみて、「はい」なら仕組みです。

ここで書き出した仕組みが、このあとの第7章（チーム図）、第8章（仕組みの宝さがし）、第9章からの各章でつくっていく仕組みの**リスト**になります。
64個をいますぐ全部つくる必要はまったくありません。安心してくださいね。

### ステップ4：未来の作戦マップをつくる

真ん中に3年後のゴール、そのまわりに8つの作戦（やること＋ものさし）、さらに外側に、作戦を実行する仕組みを書きます。
**空いているマスがあっても大丈夫です。** 思いつくものから書いて、あとで何度でも見直しましょう。

```work
id: 06.somap
type: mandala
label: 未来の作戦マップ
center: "06.so.statement"
cells: 8
cell_fields:
  - {key: perspective, label: 見方, from: "06.ksi.perspectives"}
  - {key: theme, label: やること（上の段）}
  - {key: indicator, label: ものさし（下の段）}
outer_cells: 8
outer_label: この作戦を実行する仕組み
```

#### 記入例：ひだまりケア株式会社の未来の作戦マップ

**🚩 3年後のゴール：2029年9月30日までに、経常利益3,000万円を達成する**

| 見方 | やること（上の段） | ものさし（下の段） |
|---|---|---|
| 💰 お金 | どの拠点も黒字で回す | すべての拠点で営業利益率 6%以上 |
| 😊 お客様の笑顔 | ご利用者とご家族に「任せてよかった」と言われる | 満足度調査で「大変満足」が70%以上 |
| ⚙️ 仕事のやり方 | 記録と請求の手間を半分にする | 記録・請求にかかる時間 月200時間 → 100時間 |
| 🌱 人の成長 | 自分で考えて動ける職員さんを育てる | 育成プログラムを終えた人 20人 |
| 🤝 売れる力 | ケアマネジャーさんから選ばれる | 新しいご紹介 年間120件 |
| 🎁 商品・サービスの自慢 | 住みなれた家での暮らしを長く支える | 1年後も在宅で暮らせている方 90% |
| 🏠 チームと職場 | 長く働ける職場をつくる | 離職率 25% → 10% |
| 🧭 次のリーダー | 拠点を任せられるリーダーを育てる | 拠点長を任せられる人 3人 |

**それぞれの作戦を実行する仕組み（外側の64マス）**

| 記録と請求の手間を半分にする | ①タブレットでの記録 ②記録の書き方のひな形 ③請求の仕事のレシピ ④請求のダブルチェック表 ⑤事務の仕事の月間カレンダー ⑥やめる紙の書類リスト ⑦ITツールを選ぶときの基準 ⑧事務長の仕事の棚おろし |
| 自分で考えて動ける職員さんを育てる | ①新人さんの90日育成プログラム ②役割ごとの研修メニュー ③先輩が同行して教えるルール ④迷ったときの事例集 ⑤資格取得の応援制度 ⑥毎月の事例検討会 ⑦研修を受けた記録表 ⑧教える人のための研修 |
| ケアマネジャーさんから選ばれる | ①ケアマネジャーさん訪問の計画表 ②空き状況の毎週のお知らせ ③サービス紹介の資料 ④ご紹介いただいた後の報告ルール ⑤定期的な見学会 ⑥紹介してくれた方の一覧表 ⑦「お断りゼロ」の受け入れ体制 ⑧紹介件数の毎月の集計 |

### ステップ5：物語で確かめる

```work
id: 06.so.story
type: textarea
label: 「この8つの作戦がうまくいけば、ゴールにたどり着ける」理由を、物語のように説明してください
hint: 8つの作戦がどうつながってゴールに届くのかを、社員さんに話すつもりで書いてみましょう。うまく説明できない作戦があったら、選び方を見直すチャンスです。
```

## ⑧ 講師ガイド

### この回のねらい
受講者が3年後のゴールを1つにしぼり、8つの作戦と仕組みを書いた未来の作戦マップの下書きを完成させること。

### 事前準備
- 受講者には、第5章（会社の夢の完成図）を終えてから参加してもらう
- 最近の決算書の数字（売上・粗利・経常利益）を持ってきてもらう
- 未来の作戦マップの記入用紙（A3）と、付せん（3色）

### 時間配分（3時間の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:10 | チェックイン | 会社の夢の完成図を、1人1文で発表 |
| 0:10〜0:35 | お話：③考え方の1〜4 | 「ゴールは1つ」をいちばん強調する。サッカーのたとえと ✕・◯ の例を見せる |
| 0:35〜1:00 | ワーク：ステップ2（3年後のゴール） | ひとりで書いたあと、ペアで「5つのチェック」をクリアしているか確認し合う |
| 1:00〜1:15 | お話：③考え方の5〜6 | 10の見方の選び方と、「テストの点数」と「毎日の勉強時間」のちがい |
| 1:15〜1:25 | 休憩 | |
| 1:25〜2:05 | ワーク：ステップ3〜4（8つの作戦） | 付せんに作戦の候補を10個以上出してから、8つにしぼる |
| 2:05〜2:35 | ワーク：ステップ4（仕組み） | 全部うめなくてOK。それぞれの作戦に最低3つを目標に |
| 2:35〜2:50 | グループ発表 | ステップ5の物語を1人3分で発表。聞く人はセルフチェックの5項目で質問する |
| 2:50〜3:00 | まとめ | ステップ6（仲間に伝える計画）を決めて終了 |

### 問いかけの例
- 「このゴールを達成したら、夢の完成図に何%くらい近づきますか？」
- 「3つのゴールのうち、1つしか達成できないとしたら、どれを選びますか？」（ゴールを1つにしぼれないとき）
- 「この作戦がうまくいかなかったら、ゴールにはたどり着けませんか？」（作戦が本当に必要か確かめるとき）
- 「そのものさしは、毎月はかれますか？ 誰がはかりますか？」
- 「『お客様の笑顔』の作戦がありませんが、お客様が増えずにゴールにたどり着けますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| ゴールを2つ・3つ書いてしまう | 「1つしか選べないとしたら？」と聞き、残りは8つの作戦に移す |
| 「12億円規模」のように、ぼんやりした言い方になる | 「規模」を取って、はかれる数字（12億円）にする |
| 上の段に数字の名前を書いてしまう（例：「離職率」） | 「離職率をどうしたいのですか？」と聞いて、「長く働ける職場をつくる」のような、やることの言葉にする |
| 1つの作戦に、ものさしを何本も書く | 「一番大事な1本」を選んでもらう。残りは仕組みのチェック項目として残す |
| 「お金」と「チームと職場」ばかりで、「お客様の笑顔」や「売れる力」がない | 「お客様が増えずに、ゴールにたどり着けますか？」と聞いてみる |
| 大きな構想（新しい事業など）とゴールの関係が説明できない | 「その構想は、8つの作戦のどこに入りますか？」と聞いて、マップの中に置き場所をつくる |
| 仕組みの欄に「がんばる」「徹底する」と書く | 「明日入った新人さんでも、同じようにできますか？」と聞いてみる |
