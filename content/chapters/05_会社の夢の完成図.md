## ① この章でできるようになること

- 10〜20年後の会社の姿を、**「〇〇年までに、〇〇になる」のひとこと**で言えるようになる
- そのひとことを、**規模・社員・お客様の姿など8つの要素**に分けて、夢が叶ったときの様子を具体的に描ける
- 「うちのお客様はどんな人か」を言葉にして、**A4 1枚の「会社の夢の完成図」**にまとめられる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 「うちの会社はこれからどうなるんですか？」と社員さんに聞かれて、うまく答えられなかった
- 会社の目標といえば「今年の売上」だけで、その先の姿は社長の頭の中にしかない
- 新しい事業や設備の話が出るたびに、「やる・やらない」をその場の気分で決めている
- 「会社の夢」は何となくあるけれど、言葉にしようとすると「地域に貢献する」くらいしか出てこない

私が社長さんに「10年後、この会社はどうなっていたいですか？」とお聞きすると、ほとんどの方が少し考えこまれます。
夢がないわけではありません。むしろ、みなさん熱い思いを持っていらっしゃいます。
ただ、その思いが**頭の中でぼんやりした「雲」のままで、絵になっていない**のです。

社長の頭の中にある雲は、社員さんからは見えません。
見えないものに向かって、一緒に走ることはできませんよね。

この章では、その雲を**誰が見ても同じ景色が浮かぶ「完成図」**に描き直していきます。

### 目指す姿

- 社員さんに「10年後のうちの会社って、どんな会社？」と聞くと、ひとことで同じ答えが返ってくる
- 新しい事業や設備の話が出たとき、「それは夢の完成図に近づく？」でみんなが判断できる
- 仲間集めの面接で夢の完成図を話すと、「ここで働きたい」と言ってくれる人が増える

## ③ 考え方

### 1. 夢の完成図は「ジグソーパズルの箱の絵」

1000ピースのジグソーパズルを、箱の絵を見ないで完成させられる人はほとんどいません。
どのピースも、「空の青い部分かな」「お城の屋根かな」と箱の絵と見比べるからこそ、はめる場所がわかるのです。

会社も同じです。
社員さん一人ひとりの毎日の仕事は、パズルのピースです。
**箱の絵（夢の完成図）がないと、みんなが自分なりに一生けんめいピースをはめても、ちがう絵ができあがってしまいます。**

私が関わってきた会社でも、社員さんが「バラバラに動いている」と感じる会社ほど、この箱の絵がありませんでした。
逆に、箱の絵がはっきりしている会社では、社長が細かく指示しなくても、社員さんが「このピースはここだよね」と自分で考えて動き始めます。

> 💡 専門用語では、夢の完成図のことを「ビジョン」といいます。この教材では「会社の夢の完成図」と呼んでいきます。

### 2. 人生の目的・合言葉・夢の完成図のつながり

ここまでの章で、あなたは「人生の目的」（第1章）と「わが社の合言葉」（第4章）を言葉にしてきました。
夢の完成図は、この2つとつながっています。旅にたとえると、こうなります。

| 旅にたとえると | この教材では | 答える問い |
|---|---|---|
| 🧭 なぜ旅に出るのか | **人生の目的**（第1章） | 何のために経営をしているの？ |
| 🎒 旅のあいだ守る約束 | **わが社の合言葉**（第4章） | どんなふうに進むの？ |
| 🏝️ 目的地の景色 | **会社の夢の完成図**（この章） | どこへ向かっているの？ |

「なぜ」と「どんなふうに」が決まっても、「どこへ」がないと、旅はいつまでも出発できません。
反対に、「どこへ」だけ決めて「なぜ」がないと、たどり着いても心から喜べない目的地になってしまいます。

ですから、夢の完成図を描くときは、**人生の目的と合言葉を横に置いて、見比べながら**書いてください。
このあとのワークでも、最初に2つを画面に表示します。

### 3. 「〜を目指す」ではなく「〜になっている」で書く

夢の完成図を書くとき、いちばん大事なポイントがあります。
それは、**「〜を目指す」「〜したい」ではなく、「〜になっている」と、もう叶った姿で書く**ことです。

| ✕ 目指す形（方針） | ◯ なっている形（完成した姿） |
|---|---|
| 地域に信頼される会社を目指す | 町の人から「介護のことなら、ひだまりさん」と名前で呼ばれている |
| 職員が働きやすい職場をつくりたい | 職員の平均年収が地域の介護職で一番で、10年以上働く人が半分をこえている |
| サービスの質を高める | ご利用者の9割が、1年後も住みなれた家で暮らしつづけている |

左の書き方だと、「どこまでいけば目指せたことになるのか」がわかりません。ゴールテープのないマラソンのようなものです。
右の書き方なら、その景色を思い浮かべることができますし、「いまはまだそうなっていないね」と今との差も見えてきます。

家を建てるときの完成予想図を思い出してください。
「明るい家を目指します」と書いた紙より、「南向きの大きな窓から、リビングいっぱいに朝日が入っている絵」のほうが、家族みんなでワクワクできますよね。
夢の完成図も、**写真に撮れるくらい具体的な「完成した状態」**で書きましょう。

### 4. ひとことの型は「〇〇年までに、〇〇になる」

夢の完成図は、まず**ひとこと**で表します。型はこれだけです。

> **「〇〇年までに、〇〇になる」**

**① 「〇〇年」の決め方**

| 何年先？ | 特徴 |
|---|---|
| 5年以内 | 近すぎて、いまの延長になりがち。これは第6章の「3年後のゴール」の役目です |
| **10〜20年先** | **いまのやり方では届かないけれど、本気で取り組めば届く距離。おすすめ** |
| 30年以上先 | 遠すぎて、社員さんが自分ごとにしにくい |

迷ったら、**「自分が何歳のときか」**で考えてみてください。
「社長を次の人にバトンタッチするときに、どんな会社を渡したいか」から逆算すると、年が決まりやすくなります。

**② 「〇〇になる」の書き方**

ひとことに入れるのは、次の2つです。

- **誰に**：どんなお客様や町にとって
- **どんな存在**：どんなふうに言われている、どんな会社か

ひだまりケアの日向社長は、こう書きました。

> **「2036年までに、『この町で年をとるのが楽しみになる』と言われる、地域でいちばん信頼される介護の会社になる」**

第1章で日向社長が書いた人生の目的は、「年をとることを『こわいこと』から『楽しみなこと』に変える」でした。
その思いが、会社の夢の完成図にそのままつながっているのがわかりますね。

### 5. ひとことを「8つの要素」に広げる

ひとことだけでは、まだ「雲」が少し残っています。
「地域でいちばん信頼される介護の会社」と言っても、そのとき職員さんは何人いるのか、どんな建物なのか、お客様はどんな顔をしているのか――人によって思い浮かべる景色がちがうからです。

そこで、ひとことを真ん中に置いて、そのまわりに**8つの要素**を書いていきます。

```
 ┌──────────┬──────────┬──────────┐
 │ ① 規模     │ ② 社員     │ ③ 組織     │
 ├──────────┼──────────┼──────────┤
 │ ⑧ 提供して │  夢の完成図  │ ④ 振る舞い │
 │  いる価値   │  のひとこと  │           │
 ├──────────┼──────────┼──────────┤
 │ ⑦ お客様の │ ⑥ 商品と   │ ⑤ 設備と   │
 │   姿       │  サービス   │   道具     │
 └──────────┴──────────┴──────────┘
```

それぞれの要素は、次の質問に答える形で書きます。

| 要素 | 自分に聞いてみる質問 | 書くことの例 |
|---|---|---|
| ① **規模** | 夢が叶ったとき、会社はどのくらいの大きさ？ | 売上、利益、拠点や店の数 |
| ② **社員** | 社員さんは何人で、どんな顔で働いている？ | 人数、お給料、長く働く人の割合、誇り |
| ③ **組織** | 誰が会社を回している？ 社長は何をしている？ | チームの形、リーダーの数、社長の役割 |
| ④ **振る舞い** | 社員さんのあいさつ・言葉づかい・服装は？ | 合言葉がどんな行動にあらわれているか |
| ⑤ **設備と道具** | どんな建物で、どんな道具を使っている？ | 事務所や店の雰囲気、ITツール、におい・音・明るさ |
| ⑥ **商品とサービス** | どんな商品やサービスを届けている？ | 看板の商品、新しいサービス、ほかとのちがい |
| ⑦ **お客様の姿** | お客様はどんな人で、どんな様子？ | 利用する前と後の変化、口ぐせ、表情 |
| ⑧ **提供している価値** | お客様や町に、どんな「よかった」を届けている？ | お客様の人生や町が、どう良くなっているか |

家の完成予想図も、外から見た絵だけでなく、リビング・キッチン・子ども部屋と、部屋ごとの絵があると一気に暮らしが想像できますよね。
8つの要素は、夢の完成図の「部屋ごとの絵」です。

書くときのコツが3つあります。

- **8つより多く出してから、8つを選ぶ**。上の8つはあくまで例です。「地域とのつながり」「お金の使い方」など、あなたの会社にとってもっと大事な要素があれば、入れかえてかまいません
- **どの要素も「なっている形」で書く**。「採用をがんばる」ではなく「毎年、合言葉に共感した仲間が10人ずつ加わっている」
- **数字が入れられるところには数字を入れる**。特に「規模」は、第6章の「3年後のゴール」を決めるときの目安になります

> 💡 真ん中にテーマを置いて、まわりの8マスに広げていく書き方は、専門用語では「マンダラチャート」と呼ばれています。第6章の「未来の作戦マップ」でも同じ形を使います。

### 6. お客様像は、この章で一度だけ決める

8つの要素のうち、「⑦お客様の姿」を書くには、その前に**「うちのお客様はどんな人か」**がはっきりしている必要があります。

ここで決めるお客様像は、このあと**第16章（お客様との約束と体験マップ）・第17章（選ばれる理由と看板サービス）・第18章（お客様との出会いの道）**でも、そのまま使います。
ですから、この章でしっかり一度決めておきましょう。あとの章で何度も考え直さなくてすみます。

お客様像を書くときの大事なポイントは、**「たった一人の人」を思い浮かべること**です。

| ✕ ぼんやりしたお客様像 | ◯ 顔が浮かぶお客様像 |
|---|---|
| 高齢者とその家族 | 市内で一人暮らしか夫婦で暮らす、70〜80代の方。介護が必要になっても「できるだけ家で暮らしたい」と思っている |
| 介護が必要な人すべて | 仕事を続けながら親の介護をしている、50〜60代の娘さん・息子さん。「自分がいないあいだが心配」と感じている |

「すべての人」に向けた手紙は、結局誰の心にも届きません。
「〇〇さんへ」と書いた手紙のほうが、読んだ人は「これは自分のことだ」と感じてくれます。
お客様像も同じで、しぼればしぼるほど、商品やサービス、声のかけ方がはっきりしていきます。

お客様像を書くときは、次の4つを入れてみてください。

1. **どんな人？**（年代・住んでいる場所・家族・仕事など）
2. **どんなことに困っている？ 何を心配している？**
3. **本当はどうなりたいと思っている？**
4. **買う（使う）ことを決めるのは誰？ 紹介してくれるのは誰？**

4番目は意外と見落としがちです。
介護のように、使う人（ご利用者）と決める人（ご家族）、紹介してくれる人（ケアマネジャーさん）が別々のこともあります。

### 7. すごいことを書こうとしなくていい

夢の完成図を書くとき、多くの社長さんが手を止めてしまう理由があります。
それは、**「立派なことを書かなければ」と思ってしまう**ことです。

私も最初に自分の会社の夢を書いたときは、何度も消しては書き直しました。
でも、あとから気づいたのは、**最初から完成した夢の完成図なんて、ない**ということです。

- **とりあえずの仮置きでOK**。単語だけでもかまいません
- **空いているマスがあってもOK**。思いつくものから書きましょう
- **人の目は気にしない**。ほかの会社と比べる必要はありません
- **書いていて気が重くなることは書かない**。「やらなきゃ」ではなく「こうなったらうれしい」を書きます
- **何度でも書き直す**。読み返して、しっくりくる言葉に少しずつ育てていきます

夢の完成図は、一度書いたら額に入れて飾っておくものではありません。
**毎年読み返して、手を入れて育てていく「生きた絵」**です。

### 8. 8つの要素をつなげて「A4 1枚の文章」にする

最後に、8つの要素を文章としてつなげ、**A4 1枚（800〜1,200字くらい）**にまとめます。

マップだけだと、要素がバラバラの点に見えます。
文章にしてつなげることで、**「社員が長く働いているから、お客様に良いケアが届き、だから町の人に名前で呼ばれている」**というように、点と点が線になります。

文章にするときのコツは、**「夢が叶ったある1日」を、見学に来た人に案内するつもりで書く**ことです。

> 「2036年のある朝、ひだまりケアのデイサービスに行ってみると……」

こんなふうに書き始めると、自然と「なっている形」の文章になりますし、読む人の頭にも景色が浮かびます。
この文章は、全員集合ミーティングや仲間集めの面接で、そのまま読み上げて使えます。

### ステップ4：8つの要素マップをつくる

真ん中にひとこと、そのまわりに8つの要素を書きます。
**先に付せんやメモに10個以上の要素を出してから、大事な8つを選ぶ**のがおすすめです。
空いているマスがあっても大丈夫。すべて「夢が叶ったときの状態」で書きましょう。

```work
id: 05.vision.map
type: mandala
label: 会社の夢の完成図 ― 8つの要素マップ
center: "05.vision.oneline"
cells: 8
cell_fields:
  - {key: element, label: 要素, default: [規模, 社員, 組織, 振る舞い, 設備と道具, 商品とサービス, お客様の姿, 提供している価値]}
  - {key: state, label: 夢が叶ったときの状態}
outer_cells: 0
hint: 要素の名前は入れかえてかまいません。「〜を目指す」「〜をがんばる」と書いてしまったら、「それが叶ったら、どんな景色になっている？」と自分に聞いて書き直しましょう。「お客様の姿」は、ステップ2のお客様像が夢の中でどうなっているかを書きます。
example: 下の「記入例」を参照してください。
```

#### 記入例：ひだまりケア株式会社の8つの要素マップ

**🏝️ 真ん中：2036年までに、「この町で年をとるのが楽しみになる」と言われる、地域でいちばん信頼される介護の会社になる**

| 要素 | 夢が叶ったときの状態 |
|---|---|
| ① 規模 | 6拠点（訪問介護・デイサービス・居宅介護支援）、職員120人、売上10億円。どの拠点も黒字で、次の拠点を出す力を自分たちで生み出している |

## ⑧ 講師ガイド

### この回のねらい
受講者が、人生の目的と合言葉につながった「会社の夢の完成図」を、ひとこと・8つの要素マップ・A4 1枚の文章の形で下書きし、あわせてお客様像を言葉にすること。

### 事前準備
- 受講者には、第1章（私の人生の羅針盤）と第4章（わが社の合言葉）を終えてから参加してもらう
- いまの会社の数字（売上・利益・社員数・拠点数）をメモしてきてもらう
- 8つの要素マップの記入用紙（A4）と、付せん（1人20枚ほど）
- ひだまりケアの記入例（8つの要素マップと文章）を印刷しておく

### 時間配分（90分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 自分の人生の目的を、1人1文で発表 |
| 0:05〜0:20 | お話：③考え方の1〜4 | ジグソーパズルの箱の絵のたとえと、「目指す」→「なっている」の✕・◯の例をしっかり見せる |
| 0:20〜0:30 | ワーク：ステップ2（お客様像） | 「たった一人の人」を思い浮かべて書く。あとの章でも使うことを伝える |
| 0:30〜0:40 | ワーク：ステップ3（ひとこと） | ひとりで書いたあと、ペアで読み合い「なっている形になっているか」を確認し合う |
| 0:40〜0:50 | お話：③考え方の5〜7 | 8つの要素と記入例を見せる。「すごいことを書かなくていい」を強調する |
| 0:50〜1:10 | ワーク：ステップ4（8つの要素マップ） | 付せんに要素を10個以上出してから8つを選ぶ。空欄があってもOK |
| 1:10〜1:25 | グループ発表 | 3〜4人組で、1人3分でマップを発表。聞く人は「その景色、写真に撮れますか？」の視点で質問する |
| 1:25〜1:30 | まとめ | ステップ5（A4 1枚の文章）は宿題に。ステップ6（見せる計画）の日付を決めて終了 |

### 問いかけの例
- 「その夢が叶った日に、会社の玄関を入ったら、何が見えて、何が聞こえますか？」
- 「その夢は、第1章で書いた人生の目的とどうつながっていますか？」
- 「『〜を目指す』が叶ったら、どんな景色になっていますか？」（方針の形で書いてしまったとき）
- 「お客様像の中で、いちばん顔が浮かぶ実際のお客様は誰ですか？ その人を思い浮かべて書いてみましょう」
- 「その夢が叶ったとき、社長のあなたは毎日何をしていますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「〜を目指す」「〜したい」と方針の形で書いてしまう | 「それが叶ったら、どんな景色が見えますか？」と聞いて、「〜になっている」に書き直してもらう |
| 3〜5年先の、いまの延長の目標になってしまう | 「それは第6章の3年後のゴールで考えます。その先、10年後はどうなっていたいですか？」と、もう一段先を聞く |
| 売上や拠点数など、数字だけの夢になる | 「その数字が叶ったとき、社員さんとお客様はどんな顔をしていますか？」と、8つの要素の「社員」「お客様の姿」に広げる |
| お客様像が「高齢者」「中小企業」のように広すぎる | 「いちばん喜んでくれた実際のお客様を1人思い浮かべてください」と聞き、その人の特徴から書いてもらう |
| 立派なことを書こうとして手が止まる | 「単語だけ、仮置きでOK。あとで何度でも書き直せます」と伝え、まず付せんに思いつくまま出してもらう |
| 人生の目的と夢の完成図がつながっていない | 2つを並べて読み上げてもらい、「この夢が叶ったら、人生の目的にどう近づきますか？」と聞く |
