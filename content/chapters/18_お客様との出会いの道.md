## ① この章でできるようになること

- お客様が、うちを**知ってから紹介してくれるまで**の道すじを、**7つの段**に分けて書き出せる
- それぞれの段で「誰が・何を・どのくらいの間隔でやるか」を決めて、**社長ひとりの営業から、チームで回る仕組み**に変えられる
- 道がうまく流れているかを、**ものさし（数字）**で毎月たしかめられる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- お客様が増えるかどうかは「社長の顔の広さ」しだい。社長が動けない月は、問い合わせがぱったり止まる
- チラシやホームページをつくったけれど、それで何人のお客様につながったのか、誰もわからない
- 問い合わせはあるのに、見学やおためしのあと「検討します」で終わってしまうことが多い
- 一度使ってくださったお客様が、いつのまにか来なくなっている。理由もわからない
- 「紹介でお客様が来る」とよく言うけれど、紹介はたまたま起きるもので、増やし方がわからない

私が社長さんとお話ししていて、とても多いと感じるのは、**「お客様を増やす＝新しい人に知ってもらう」とだけ考えている**ということです。
だから「チラシを増やそう」「広告を出そう」と、入口ばかりにお金と力を使ってしまいます。

でも、お客様がうちのお客様になるまでには、いくつもの「段」があります。
知ってもらっても、好きになってもらえなければ次に進みません。好きでも、信じてもらえなければ申し込みません。
そして、**一度来てくださったお客様が、また来てくれて、まわりに話してくれる**。ここがいちばん大きな力になるのに、ほとんどの会社が手をつけていません。

この章では、お客様との出会いから紹介までを**1本の道**にして、どの段で「つまっているか」を見つけ、それぞれの段に仕組みを置いていきます。

### 目指す姿

- 社長がいなくても、決まった担当が決まった間隔で動いて、新しいお客様が毎月やってくる
- 「今月はおためしが少ないね」「おためしからの申し込みが下がっているね」と、つまっている段を数字で話せる
- 来てくださったお客様が長く通い続け、「あそこ、いいわよ」とまわりに紹介してくれる

## ③ 考え方

### 1. 転校生と、親友になるまで

あなたのクラスに転校生が来たときのことを思い出してみてください。

最初は「あ、新しい子が来たな」と**名前と顔を知る**だけです。
話してみると「この子、おもしろいな」と**好きになり**、何度か話すうちに「この子は約束を守る子だ」と**信じられる**ようになります。
「今度の日曜、一緒に遊ぼうか」と**ためしに遊んでみて**、楽しければ「同じ班になろう」と**決める**。
それから毎日一緒に帰るようになって**ずっと仲良し**になり、やがて「この子、いい子だよ」と**ほかの友だちに紹介**してくれます。

いきなり「親友になってください！」と言われても、困ってしまいますよね。

お客様も同じです。
**知らない会社から、いきなり「買ってください」と言われても、誰も買いません。**
一段ずつ、順番に階段をのぼってもらう。その階段を、会社の側で用意しておくのが、この章でつくる**「お客様との出会いの道」**です。

> 💡 専門用語では、この流れを「集客・販売プロセス」といいます。

### 2. 7つの段を「砂時計」で考える

出会いの道は、**砂時計**の形をしています。

![お客様との出会いの道：砂時計の7つの段。上の広いところで知ってもらい、まん中のくびれで買ってもらい、下でまた広がって、また来てもらい、紹介してもらう。紹介された人が、また上の段に入ってくる](assets/img/ch18-hourglass.svg)

| 段 | お客様の気持ち | うちがやること |
|---|---|---|
| 👀 **① 知ってもらう** | 「そんな会社があるんだ」 | 見つけてもらえる場所に、顔を出しておく |
| 💗 **② 好きになってもらう** | 「なんだか、いい感じ」 | 「らしさ」が伝わる見た目や言葉で、興味を持ってもらう |
| 🤝 **③ 信じてもらう** | 「ここなら、ちゃんとしてそう」 | 役に立つ情報や、お客様の声で、安心してもらう |
| 🍵 **④ ためしてもらう** | 「ちょっとだけ、やってみようかな」 | 小さく、気軽に体験できる入口をつくる |
| ✍️ **⑤ 買ってもらう** | 「ここに決めた」 | 決める前の不安を、ひとつずつ消していく |
| 🔁 **⑥ また来てもらう** | 「やっぱり、ここがいい」 | 使い始めてからの「よかった」を積み重ねる |
| 📣 **⑦ 紹介してもらう** | 「あなたにも教えたい」 | 紹介しやすいように、きっかけと道具を用意する |

砂時計の上は広く、まん中でキュッとくびれています。
たくさんの人に知ってもらっても、買ってくださるのはその一部。これは自然なことです。

大事なのは**下半分**です。
砂時計の下は、また広がっていますよね。
一度買ってくださったお客様が、何度も来てくださり、まわりに紹介してくださると、**ひとりのお客様から、どんどん広がっていきます。**
そして、紹介された人は、砂時計の上の段に、最初から「信じた」状態で入ってきてくれます。

多くの会社は、上半分（知ってもらう）にばかり力を入れて、下半分を放っておいています。
**バケツの底に穴があいたまま、水を注いでいるようなもの**です。
まず底の穴をふさぐ（また来てもらう・紹介してもらう）ほうが、ずっと少ない力でお客様が増えていきます。

**道を通る人は、ひとりとはかぎりません**

お客様によっては、「使う人」「お金を出す人」「すすめる人」が別々のこともあります。
たとえば子どもの習い事なら、通うのは子ども、決めるのはお母さん、すすめるのは友だちのお母さん、ですよね。
そういうときは、**いちばん選んでほしい人（第17章で決めた人）の道**をまず書き、すすめてくれる人には「紹介の仕組み」で応えます。

### 3. 段ごとに「つまっている場所」をさがす

出会いの道を書き出すと、**どの段で、お客様が止まっているか**が見えてきます。

| こんな状態なら | つまっている段 | まず手を打つところ |
|---|---|---|
| そもそも問い合わせが少ない | ① 知ってもらう | 見つけてもらう場所をふやす |
| ホームページは見られているのに、連絡が来ない | ②③ 好き・信じる | 「らしさ」とお客様の声を見えるところに出す |
| 問い合わせはあるのに、見学やおためしに来ない | ④ ためしてもらう | 「気軽にためせる入口」を小さくする |
| おためしのあと「検討します」で終わる | ⑤ 買ってもらう | 決める前の不安を消す手伝いをする |
| 始めてくれても、すぐにやめてしまう | ⑥ また来てもらう | 使い始めの90日を手あつくする |
| 満足の声は多いのに、紹介がない | ⑦ 紹介してもらう | 紹介をお願いし、紹介しやすい道具を渡す |

私がご一緒した社長さんの多くは、「うちは知ってもらう力が足りない」と思っていました。
ところが道を書き出してみると、本当につまっていたのは**⑤や⑥だった**ということが、とても多いのです。
入口を広げる前に、まず**いちばん細くなっている段**をさがしましょう。

### 4. 伝える中身を「ためておく」

②好きになってもらう、③信じてもらう、の段で力を発揮するのが、**お客様に伝える中身**です。

スーパーの試食コーナーを思い出してください。
「おいしいですよ！」と100回言われるより、ひと口食べたほうが、ずっと信じられますよね。
伝える中身も同じで、**「うちはいいですよ」と言うより、先に役に立つものを渡す**ほうが、信じてもらえます。

| 中身の種類 | どんなもの？ | 例 |
|---|---|---|
| 📘 **お役立ち情報** | お客様が困っていることを、無料で解決してあげる | 「〇〇で失敗しない3つのコツ」の1枚の紙 |
| ❓ **よくある質問** | 決める前に、みんなが気にすることへの答え | 値段・期間・やめるとき、の答えを1枚に |
| 🗣️ **お客様の声** | 実際に使った人の、生の言葉 | 「最初は不安だったけれど〜」という感想 |
| 🌱 **できるようになった物語** | 使う前と、使ったあとの変化 | 「3か月で、ひとりで〇〇できるようになった」 |
| 🔢 **数字でわかる結果** | 変化を数字で見せる | 「ご利用の方の9割が〜」 |

ポイントは、**思いついたときに作るのではなく、ためておく**ことです。
冷蔵庫に作り置きのおかずがあれば、急なお客様にもすぐに出せますよね。
中身を「いつ・誰が・何を作るか」の予定表にして、少しずつためていきましょう。

そしてどの中身にも、第17章で決めた**選ばれる理由のひとこと**が、同じ声で入っていることが大切です。
チラシとホームページと職員さんの説明で、言っていることがバラバラだと、お客様は信じてくれません。

### 5. 「ためしてもらう」は、入口を小さくする

プールに飛びこむのはこわくても、足だけなら入ってみようと思えますよね。

④ためしてもらう、の段では、**お客様が「失うもの」をできるだけ小さくした入口**をつくります。

| ✕ 入口が大きい | ◯ 入口が小さい |
|---|---|
| 「まずは1年契約から」 | 「1回だけ、おためしで」 |
| 「ご契約の前に、ご説明に2時間いただきます」 | 「30分だけ、見に来てください」 |
| 「お見積もりは、ご相談のうえで」 | 「この形なら、ひと月この金額です」 |

ためしてもらったあとに、**誰が・いつ・どんなふうに「いかがでしたか？」と聞くか**まで決めておくと、⑤買ってもらう、へ自然につながります。

### 6. 「決める前の不安」を、ひとつずつ消す

⑤買ってもらう、の段で、お客様の足を止めているのは、たいてい**不安**です。

はじめての習い事を決めるときのことを思い出してください。
「月謝はいくら？ 教材費は別？」「うちの子についていけるかな」「先生と合わなかったら？」「途中でやめられる？」「申し込みの書類がめんどうそう」……
どれかひとつでも引っかかると、「もう少し考えます」になってしまいます。

お客様の不安は、だいたい次の5つに分かれます。

| 不安 | お客様の心の声 | 消すための手伝いの例 |
|---|---|---|
| 💴 **お金** | 「結局、全部でいくらかかるの？」 | 総額がひと目でわかる紙を、先に渡す |
| 🔍 **中身** | 「本当に、うちに合うの？」 | 「何に困っているか」を一緒に整理してから、合うものをすすめる |
| 🙂 **相性** | 「どんな人が担当なの？」 | 担当になる人に、先に会ってもらう |
| 📄 **手間** | 「手続きがめんどうそう」 | 書類は1枚に。書くのを手伝う |
| 🚪 **やめるとき** | 「合わなかったら、どうなるの？」 | やめ方を先に説明する。「いつでもやめられます」と言える仕組み |

ここで大事なことがあります。
**できないことは、先に正直に伝える**ことです。
「何でもできます」と言って始めてもらい、あとで「話がちがう」となるのが、いちばんお客様をがっかりさせます。
「ここまではできます。ここから先はできません」を先に伝えておくと、かえって信じてもらえます。

### 7. 紹介は「お願い」ではなく「仕組み」にする

⑦紹介してもらう、は、たまたま起きるものだと思われがちです。
でも私は、**紹介こそ、いちばん仕組みにしやすい段**だと思っています。

紹介が自然に生まれる会社には、だいたい次の5つがそろっています。

| 紹介の準備 | どういうこと？ |
|---|---|
| 🎯 **紹介してほしい人を伝える** | 「どんな方がいらしたら、ぜひご紹介ください」と、具体的に伝えておく。ぼんやりしていると、紹介する人も思い浮かばない |
| 📨 **話のタネを届け続ける** | 紹介してくれる人に、うちの新しい話題や空き状況を、決まった間隔で届ける。忘れられないことが大事 |
| 🧰 **紹介しやすい道具を渡す** | 「これを渡してください」と言える1枚の紙や、かんたんな連絡のしかた。紹介する人の手間をへらす |
| 📞 **紹介のあとに報告する** | 「ご紹介いただいた方、こんなふうに始められました」と、紹介してくれた人に必ず伝える |
| 🎁 **ありがとうを返す** | お礼の言葉やお手紙。業界によっては、お礼の品やお金が決まりで禁止されていることもあるので注意 |

この中で、いちばん効くのは**「紹介のあとに報告する」**です。
紹介した人は、「あの人、ちゃんとしてもらえたかな」と気にしています。
報告があると「紹介してよかった」と思えて、**次の紹介につながります。**
逆に、報告がないと、紹介した人は少し不安になって、次は別の会社を紹介するかもしれません。

### 8. 道を動かすのは「活動」と「担当」、はかるのは「ものさし」

道を書いただけでは、お客様は来てくれません。
道を動かすのは、**くり返しやる活動**です。

部活動を思い出してください。
「強くなりたい」と思っているだけでは強くなりませんよね。
「月・水・金に走りこみ」「土曜日に練習試合」と決めて、くり返すから強くなります。

出会いの道も、それぞれの段の施策を、**「誰が・どのくらいの間隔でやるか」**まで決めて、はじめて仕組みになります。
そのとき、「社長」の名前ばかりにならないように、第7章のチーム図の**役割**に当てはめていきましょう。

そして最後に、**ものさし**を決めます。
ものさしは、各段を「何人が通ったか」と「次の段へ何割が進んだか」で考えるとわかりやすくなります。

| ものさしの種類 | 例 | 第6章の言い方 |
|---|---|---|
| 段を通った人数 | 問い合わせの数、おためしに来た人数、紹介の数 | 🏁 結果の数字 |
| 次の段へ進んだ割合 | おためしから申し込みに進んだ割合、1年後も続けている割合 | 🏁 結果の数字 |
| 段を動かす活動の数 | 紹介してくれる人を訪ねた回数、中身を出した数 | 👣 行動の数字 |

全部の段にものさしを置く必要はありません。
第6章の**8つの作戦**のうち、お客様に関わる作戦（お客様の笑顔・評判とファン・売れる力・知ってもらう力など）のものさしを、道のどの段ではかるのかを確かめ、**3〜5本**にしぼりましょう。
**結果の数字と行動の数字を、両方まぜる**のがコツです。

## ⑧ 講師ガイド

### この回のねらい
受講者が、自社のお客様が知ってから紹介してくれるまでの道を7つの段に分けて書き出し、つまっている段を見つけたうえで、各段の施策・紹介の仕組み・活動と担当・ものさしの下書きを完成させること。

### 事前準備
- 受講者には、第17章の「選ばれる理由のひとこと」と、第6章の8つの作戦を見直してから参加してもらう
- いまのパンフレット・チラシ・ホームページの印刷を持ってきてもらう
- できれば、この半年の「問い合わせの数・おためしや見学の数・申し込みの数・やめた方の数・紹介の数」を調べてきてもらう（わからない数字があってもOK）
- 砂時計の形を描いたA3の紙と、付せん（3色）

### 時間配分（90分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「最近のお客様は、どうやってうちを知りましたか？」を1人1文で |
| 0:05〜0:20 | お話：③考え方の1〜3 | 転校生のたとえと砂時計の図。「バケツの底の穴」をいちばん強調する |
| 0:20〜0:35 | ワーク：ステップ1〜2（いまの道の点検） | 持ってきた数字を砂時計の紙に書きこみ、つまっている段に赤い付せんを貼る |
| 0:35〜0:45 | お話：③考え方の4〜8 | 試食コーナー、プールの足だけ、習い事の不安のたとえ。紹介は「報告」がいちばん効くことを伝える |
| 0:45〜1:10 | ワーク：ステップ3〜6（道・紹介・中身・不安） | つまっている段から先に書く。ペアで「お客様の言葉になっている？」と読み合う |
| 1:10〜1:25 | ワーク：ステップ7〜8（活動・担当・ものさし） | 担当が「社長」ばかりになっていないか、おたがいに確かめる |

### 問いかけの例
- 「最近来てくださったお客様は、どの段で、何がきっかけで次の段に進みましたか？」
- 「入口を広げる前に、いちばん細くなっている段はどこですか？」
- 「おためしのあと、お客様から連絡がなかったら、誰がいつ連絡しますか？」
- 「紹介してくださった方は、そのあとどうなったかを知っていますか？」
- 「その活動は、社長が1か月入院しても続きますか？」
- 「このものさしは、毎月はかれますか？ 誰がはかりますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| ①知ってもらう、の施策ばかり書いて、⑥⑦が空いている | 「バケツの底の穴」の話に戻り、「いま来てくださっているお客様に、何ができますか？」と聞く |
| 「お客様に思ってほしいこと」が、会社の言葉（「当社の強みを理解してもらう」など）になる | 「お客様は、心の中で何とつぶやいていますか？」と聞き、かぎかっこのセリフにしてもらう |
| 施策が「がんばって営業する」「信頼を得る」など、気合いの言葉になる | 「明日入った職員さんでも、同じようにできますか？」と聞き、道具と手順の言葉に直してもらう |
| 紹介のお礼に、品物やお金を考える | 業界の決まりを確かめてもらう。いちばん効くのは「紹介のあとの報告」だと伝える |
| 活動の担当がすべて「社長」になる | 第7章のチーム図を横に置き、「この活動は、どの役割の仕事ですか？」と1つずつ聞く |
| ものさしを段の数だけ（7本）置こうとする | 「毎月の会議で、全部見られますか？」と聞き、作戦のものさし1本＋つまっている段＋行動の数字で3〜5本にしぼる |
| いまの数字がわからず、手が止まる | 「わからない」と書いてよいことを伝え、来月からはかる担当を決めてもらう。はかり始めることが最初の一歩 |
