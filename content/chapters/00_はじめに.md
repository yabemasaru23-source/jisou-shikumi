## ① この章でできるようになること

- 「あの人頼みの会社」と「仕組みで回る会社」のちがいを、自分の言葉で話せるようになる
- これから進む20章の地図と、進む順番がわかる
- 自分の会社がいまどこにいるのかを点数で知り、どこから始めればいいかがわかる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 社長が休むと、現場の「どうしよう？」が止まってしまう
- 「あの人しかできない仕事」がいくつもある
- 同じミスが、担当者が変わるたびにくり返される
- 新しく入った人が、育つ前にやめてしまう
- 毎日いそがしすぎて、会社の未来を考える時間がない

私がこれまで多くの社長さんとお話ししてきて、いちばんよく聞くのがこの悩みです。
そして、話を聞けば聞くほど気づくことがあります。

**これは、社員さんの力や、がんばりが足りないから起きているのではない**ということです。

原因は、**会社のやり方が「人の頭の中」にしかないこと**。
仕事のやり方が頭の中にしかないと、その人がいないときに誰も同じようにできません。その人がやめたら、やり方も一緒に消えてしまいます。

### 目指す姿

| いま（あの人頼みの会社） | 目指す姿（自走する会社） |
|---|---|
| 答えは社長が持っていて、みんなが社長に聞きに来る | 「こういうときはこうする」が共有されていて、みんなが自分で決められる |
| 仕事のやり方が人によってバラバラ | 「いまいちばん良いやり方」が決まっていて、誰がやってもうまくいく |
| 人がやめると、やり方も一緒に消える | やり方が会社に残って、次の人に受けつがれる |
| 社長は目の前の仕事でいっぱい | 社長は「会社の未来をつくる仕事」に時間を使える |

## ③ 考え方

### 1. 「仕組み」ってなに？

この教材でいう**仕組み**とは、

> **「誰がやっても、同じようにうまくいくように整えた、仕事のやり方」**

のことです。

たとえば、カレーライスを思いうかべてください。
料理が上手なお母さんが、目分量でパパッと作るカレーはとってもおいしい。でも、お母さんが出かけてしまうと、誰も同じ味を作れません。

そこで、**「たまねぎ2こ、にんじん1本、お水600ml、弱火で15分」とレシピに書いておく**。
そうすれば、お父さんが作っても、子どもが作っても、いつものおいしいカレーができあがります。

**このレシピが「仕組み」です。**

会社の中には、こうしたレシピにできることがたくさんあります。
会議のやり方、仲間の集め方、お客様へのあいさつ、目標の立て方――くり返し行うことは、ぜんぶ仕組みにできます。

そして、ここがとても大事なところなのですが、**仕組みは人をしばるためのものではありません。**
毎回同じことで迷わなくてよくなるので、人は「考えるべきこと」「人にしかできないこと」に力を使えるようになります。私は、仕組みは人を自由にするものだと思っています。

### 2. 社長には「3つの顔」がある

社長の仕事は、大きく3つの顔に分けられます。

| 顔 | やっていること | ひだまりケアの例 |
|---|---|---|
| 🔧 **現場の人** | 自分の手で、商品やサービスをお客様に届ける | シフトの穴うめで、訪問介護に入る |
| 📋 **まとめ役** | 人と仕事をまとめて、今日一日を回す | 職員さんの相談にのる、請求をチェックする |
| 🚀 **未来をつくる人** | 会社の行き先を決めて、仕組みをつくる | 3つ目の拠点の計画を立てる、仲間集めの仕組みを整える |

多くの会社では、社長の時間のほとんどが「現場の人」と「まとめ役」で終わってしまいます。
私も、社長さんに1週間の時間の使い方を書き出してもらうことがあるのですが、「未来をつくる人」の時間が**ほぼゼロ**という方が本当に多いんです。

この教材のゴールは、**社長が「未来をつくる人」として使う時間を、全体の3分の1以上にすること**です。

### 3. 仕組みづくりは「上から順番に」

仕組みづくりには、進む順番があります。
家を建てるときに、いきなり壁紙を選ぶ人はいませんよね。まず土台、次に柱、それから部屋です。

```
 自分を整える      会社の軸を決める      作戦を立てる          仕組みをつくる
（何のために？）→ （合言葉・夢）   → （3年後のゴール・チーム）→（会議・仲間・お客様）
     土台               柱                  間取り                  部屋
```

いきなりマニュアルを作り始めると、「何のためのマニュアルか」がふらふらして、結局使われないまま終わりがちです。
でも上の段がしっかり決まっていれば、下の段は「上と合っているかな？」で決められるようになります。

### 4. これから進む地図

| ステージ | 章 | 必修 |
|---|---|:-:|
| はじめに | 0 会社が自走するってどういうこと？ | ★ |
| 1 自分を整える | 1 私の人生の羅針盤／2 リーダーのクセ発見／3 時間と机のお片づけ | 1が★ |
| 2 会社の軸を決める | 4 わが社の合言葉／5 会社の夢の完成図 | ★ |
| 3 作戦を立てる | 6 未来の作戦マップ／7 3年後のチーム図と役割の約束書／8 仕組みの宝さがし | 6・7が★ |
| 4 会社を回す | 9 作戦会議のメンバーと会社のリズム／10 任せ方のルール／11 会社の取扱説明書と仕事のレシピ／12 変化を仲間に広げる | 9が★ |
| 5 人の仕組み | 13 仲間集めの仕組み／14 入社90日の歓迎プラン／15 人が育つ仕組み | |
| 6 お客様の仕組み | 16 お客様との約束と体験マップ／17 選ばれる理由と看板サービス／18 お客様との出会いの道／19 期待をこえるひと手間と品質を守る仕組み | |
| まとめ | 20 ふり返りと次の90日作戦 | ★ |

**まずは★の8章だけで大丈夫です。**
この8章を終えると、あなたの会社の「設計図」が一式そろいます。
残りの章は、このあとのチェックで点数が低かった分野から選んで進めてください。

### 5. 進めるときの3つのコツ

1. **100点を目指さない**
   最初は「とりあえず」で大丈夫です。書いたものは何度でも書き直せます。私自身、一度で完成したことはありません。
2. **ひとりで抱えない**
   ステージ2からは、幹部や信頼できる社員さんと一緒に考えてみてください。一緒に考えた人は、あとで一番の味方になってくれます。
3. **しめ切りを決める**
   「いつかやろう」の「いつか」は、残念ながらやってきません。1章ごとに「この日までにやる」と決めましょう（目安は2週間に1章です）。

## ④ ワーク：自走度チェック

いまの会社の状態で、正直に答えてください。
「できている＝2点」「少しできている＝1点」「できていない＝0点」です。

理想ではなく、**いまの本当の姿**で答えるのがポイントです。
点数が低くても大丈夫。低いところほど、これから伸びるところです。

```work
id: diag.basic
type: scale
label: 自走度チェック
scale: [{value: 2, label: できている}, {value: 1, label: 少しできている}, {value: 0, label: できていない}]
groups:
  - name: 会社の軸と作戦
    items:
      - 会社が大切にしていること（合言葉）が言葉になっていて、社員さんが言える
      - 10年後くらいの会社の姿（夢の完成図）が文章になっている
      - 3年後のゴールが数字で決まっていて、社員さんも知っている
      - ゴールに向けて、毎月チェックする数字が決まっている
  - name: 会社のリズム
    items:
      - 会議の目的・参加する人・回数が決まっていて、会議で物事が決まる
      - 上司と部下が、定期的に1対1で話す時間がある
      - 社長が1〜2週間休んでも、会社の判断が止まらない
      - 会社の基本ルールが、1冊（1か所）にまとまっている
  - name: チームと仕事
    items:
      - チーム図（組織図）があって、それぞれの役割と責任が書いてある
      - 主な仕事に、手順書やチェックリストがある
      - 仕事を任せるとき、「どこまで任せるか」「どう報告するか」が決まっている
      - 「あの人しかできない仕事」がほとんどない
  - name: 仲間集めと育成
    items:
      - どんな人に仲間になってほしいかがはっきりしていて、選び方の手順が決まっている
      - 新しく入った人の、最初の3か月の育て方が決まっている
      - 役割ごとに「何を学べばいいか」が決まっている
      - がんばりを評価する基準がはっきりしていて、社員さんが納得している
  - name: お客様への価値
    items:
      - お客様にどんな気持ちになってほしいかが言葉になっていて、社員さんがわかっている
      - 「他ではなく、うちが選ばれる理由」を社員さんが説明できる
      - 新しいお客様と出会う流れが決まっていて、数字で追いかけている
      - サービスの品質の基準があって、定期的にチェックしている
```

### 結果の見方

| 合計点 | いまの状態 | 次の一歩 |
|---|---|---|
| 0〜10点 | 🌱 **あの人頼み**：社長が倒れたら、会社が止まってしまう状態 | ★の8章を順番に。まずは第1章から始めましょう |
| 11〜20点 | 🌿 **仕組みの芽が出ている**：あるにはあるけれど、つながっていない | ★の8章を順番に。すでにあるものは「見直し」のつもりで |
| 21〜30点 | 🌳 **仕組みが育ってきた**：土台はある。すき間を埋める段階 | ★の章で土台を確認して、点数の低い分野の章へ |
| 31〜40点 | 🍎 **自走まであと一歩**：仕組みを良くし続ける段階 | 点数の低い分野の章と、第8章「仕組みの宝さがし」へ |

**分野ごとの点数（それぞれ8点満点）**も見てください。4点以下の分野があれば、その分野の章を優先して進めましょう。

| 分野 | おすすめの章 |
|---|---|
| 会社の軸と作戦 | 4・5・6 |
| 会社のリズム | 9・11・12 |
| チームと仕事 | 7・8・10・11 |
| 仲間集めと育成 | 13・14・15 |
| お客様への価値 | 16・17・18・19 |

## ⑦ 次の章へ

仕組みづくりのスタート地点は、会社ではなく**社長のあなた自身**です。

「自分は何のために経営をしているのか」がはっきりしないまま会社の合言葉や夢を考えると、どこかで聞いたような、借りてきた言葉になってしまいます。
私はこれまで、それで立ち止まってしまう会社を何度も見てきました。

次の**第1章「私の人生の羅針盤」**では、あなた自身が大切にしていることと、人生の目的を言葉にしていきます。

## ⑧ 講師ガイド

### この回のねらい
受講者が「仕組みづくりは自分の会社に必要だ」と心から思い、自分の会社の現在地を点数でつかむこと。

### 時間配分（90分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:10 | チェックイン | 「最近あった良いこと・新しいこと」を1人30秒。場をあたためる |
| 0:10〜0:30 | お話：③考え方の1〜3 | カレーのレシピのたとえと「社長の3つの顔」で、自分の時間の使い方をふり返ってもらう |
| 0:30〜0:45 | ワーク：自走度チェック | ひとりで記入。相談はしない |
| 0:45〜1:05 | グループで共有 | 3〜4人組で「一番点数が低かった分野」と「その理由」を話す |
| 1:05〜1:20 | お話：③考え方の4〜5 | 全体の地図と進め方。★の8章から始めることを強調する |
| 1:20〜1:30 | まとめ | 「目指す姿」を1人ずつ宣言。第1章のしめ切り日を決める |

### 問いかけの例
- 「もし明日から1か月、社長が入院したら、会社でいちばん最初に止まるのは何ですか？」
- 「この1週間で、『未来をつくる人』の顔でいた時間は何時間ありましたか？」
- 「『あの人しかできない仕事』を3つ挙げるとしたら、何ですか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 理想の状態で答えてしまい、点数が高く出る | 「社員さんに同じ質問をしたら、同じ点数になりそうですか？」と聞いてみる |
| 「うちは小さいから、仕組みはまだいらない」 | 小さいうちに作るほどラクで、人が増えてから作るほど大変になることを伝える |
| 最初からマニュアルを作りたがる | 家の建て方のたとえで、「何のためのマニュアルか」が先に決まっていないと使われないことを確認する |
| 点数が低くて落ちこむ | 点数が低いほど、伸びしろが大きい。第20章で比べるのが楽しみになる、と伝える |
