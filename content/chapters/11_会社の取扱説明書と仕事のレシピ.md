## ① この章でできるようになること

- これまでの章でつくってきたものを集めて、全員が知っておく会社のことを1冊にまとめた**「会社の取扱説明書」**の目次をつくれる
- 取扱説明書を**誰に配り、いつ、誰が見直すか**のルールを決められる
- 誰がやっても同じようにできる**「仕事のレシピ」**の書き方を知り、実際に**1本書き上げられる**
- 良いレシピかどうかを確かめる**チェック**と、会社全体で**言葉と書き方をそろえるルール**を決められる
- レシピを**誰と、どの順番で、どこに置いて、どう育てていくか**の計画を立てられる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 新しく入った人に、会社のことを説明するのが「教える人まかせ」で、人によって言うことがちがう
- 合言葉や夢の完成図をつくったのに、ファイルの奥にしまわれて、誰も読み返していない
- 「あの人が休むと、その仕事が止まる」という仕事がいくつもある
- マニュアルをつくったことはあるけれど、分厚すぎて誰も読まず、いつのまにか古くなっていた
- 同じ仕事なのに、ベテランと新人で、仕上がりも時間もぜんぜんちがう

私はこれまで、たくさんの会社の「マニュアル」を見せていただいてきました。
そこで気づいたのは、**マニュアルが「つくって終わり」になっている会社がとても多い**ということです。

がんばって分厚いマニュアルをつくった。でも、読むのに時間がかかるし、どこに何が書いてあるかもわからない。
現場のやり方はどんどん変わるのに、マニュアルは3年前のまま。
結局、「わからないことは、あの人に聞いて」に戻ってしまうんです。

この章では、2つのものをつくります。
ひとつは、**全員が知っておく会社のことを1冊にまとめた「会社の取扱説明書」**。
もうひとつは、**誰がやっても同じようにできる「仕事のレシピ」**です。
どちらも「読まれて、使われて、育っていく」ことを一番に考えてつくります。

### 目指す姿

- 新しく入った人が、取扱説明書を読めば「この会社は何を目指し、何を大切にしていて、誰が何をしているか」がわかる
- 「あの人しかできない仕事」が1つずつレシピになり、休みの日でも仕事が止まらない
- レシピを書いた人も、使った人も、「もっとこうしたら？」と気軽に書き直せる
- 社長に「これってどうするんでしたっけ？」と聞きに来る回数が、目に見えて減っている

## ③ 考え方

### 1. 取扱説明書は「家族のルールブック」、レシピは「料理のレシピ」

この章でつくる2つのものは、似ているようで役割がちがいます。
家族でたとえてみましょう。

| | 📘 会社の取扱説明書 | 🍳 仕事のレシピ |
|---|---|---|
| 家族でたとえると | わが家のルールブック（大切にしていること・家族の予定・お手伝いの分担） | カレーの作り方カード |
| 読む人 | **全員** | **その仕事をする人** |
| 書いてあること | 会社が目指すもの・大切にすること・チームの形・会社のリズム・みんなのルール | 1つの仕事の目的・手順・「ここまでできたら合格」の基準 |
| 数 | 会社に**1冊**（配る相手によって少し中身を変える） | 仕事の数だけ**何枚も** |
| 答えてくれる質問 | 「この会社は、どんな会社？」「迷ったら、どう考える？」 | 「この仕事は、どうやるの？」「これで終わりでいい？」 |

取扱説明書が**会社全体の案内図**だとすると、レシピは**ひとつひとつの部屋で使う道具の説明書**です。
案内図だけでは仕事はできませんし、道具の説明書だけでは、自分がどこにいて、何のためにその仕事をしているのかがわかりません。
2つそろってはじめて、「読めばわかる会社」になります。

![会社の取扱説明書と仕事のレシピの関係：全員が読む1冊の取扱説明書の下に、役割ごとの仕事のレシピが何枚も並ぶ](assets/img/ch11-two-books.svg)

> 💡 専門用語では、会社の取扱説明書を「運営マニュアル」、仕事のレシピを「作業マニュアル」といいます。この教材では、わかりやすい言葉で進めていきます。

### 2. 取扱説明書の目次は「これまでの章の完成物」でほぼできている

「会社の取扱説明書をつくりましょう」と言うと、多くの社長さんは「そんな大変なもの、書く時間がない」と身がまえます。
でも、安心してください。**ここまで学んできた方は、もう中身の半分以上を持っています。**

| 取扱説明書の章 | もとになるもの |
|---|---|
| 会社の物語（どうやって生まれた会社か） | 社長の思い出話・創業のころの出来事 |
| わが社の合言葉 | 第4章 |
| 会社の夢の完成図 | 第5章 |
| 3年後のゴールと8つの作戦 | 第6章 |
| 3年後のチーム図と役割のひとこと | 第7章 |
| 作戦会議のメンバーと会社のリズム | 第9章 |
| 任せ方のルールとチームの約束ごと | 第10章 |
| お客様との約束・選ばれる理由 | 第16・17章 |
| 毎日のルール（休みの取り方・連絡のしかた・緊急時の対応・個人情報の守り方など） | いまの就業規則や、口で伝えてきたルール |

つまり、取扱説明書づくりは「ゼロから書く」仕事ではなく、**「これまでつくったものを、1冊にとじる」仕事**なんです。
学校の卒業文集を思いうかべてください。一人ひとりの作文はもう書いてあって、最後に表紙と目次をつけて1冊にしますよね。あれと同じです。

ポイントは、**全部をのせようとしない**ことです。
取扱説明書にのせるのは「全員が知っておくこと」だけ。特定の役割の人だけが知っていればいいことは、レシピの方に入れます。

### 3. 取扱説明書は「配る相手」と「見直しのルール」までがセット

取扱説明書は、つくったあとが本番です。決めておくことは2つあります。

**① 誰に配るか**

全員に同じものを配るのが基本ですが、中身によって分けることもあります。

| 版 | 配る相手 | 中身の例 |
|---|---|---|
| 全員版 | 職員さん全員（パートさんもふくむ） | 合言葉・夢の完成図・チーム図・会社のリズム・毎日のルール |
| リーダー版 | 拠点長・部長など | 全員版 ＋ 8つの作戦のものさしの数字・任せ方のルール |
| 入社する人版 | 入社が決まった人 | 全員版のうち、最初の1週間で必要なところ |

**② いつ、誰が見直すか**

取扱説明書がいちばん困るのは、**中身が古いまま放っておかれること**です。
「書いてあるとおりにやったら、もうそのルールは変わっていた」ということが一度でも起きると、誰も取扱説明書を信用しなくなります。

そこで、次の3つを決めておきます。

- **見直しの担当**：取扱説明書の「持ち主」をひとり決める（社長ではなく、管理部の人などがおすすめ）
- **定期の見直し**：年に1回、決まった時期に全体を読み直す（たとえば、全員集合ミーティングの前）
- **変わったらすぐ直す**：作戦会議でルールが変わったら、その週のうちに直し、「どこが変わったか」をみんなに知らせる

表紙に**「〇年〇月〇日 改訂」**と書いておくと、「これが最新かな？」と迷うこともなくなります。

### 4. 仕事のレシピは「誰が作っても同じ味」

カレーのレシピを思いうかべてください。
「玉ねぎを適当に炒める」と書いてあったら、炒める時間は人によってバラバラになりますよね。
でも「玉ねぎがあめ色になるまで、中火で15分炒める」と書いてあれば、料理が初めての子どもでも、だいたい同じ味になります。

仕事のレシピも同じです。**誰がやっても、同じ仕上がりになる**ように書きます。

では、どの仕事からレシピにすればいいのでしょうか。
すべての仕事を一度にレシピにするのは無理ですから、次の4つにあてはまる仕事から始めます。

| こんな仕事から | 理由 |
|---|---|
| 🔒 **あの人しかできない仕事** | その人が休んだり、やめたりすると、会社が止まってしまう |
| ⚠️ **ミスすると大変な仕事** | お金・安全・信用にかかわる。やり方がそろっていないと危ない |
| 🔁 **くり返しが多い仕事** | 毎日・毎月やるので、レシピにした効果が一番大きい |
| 🔰 **新人さんが最初に覚える仕事** | 教える人によって教え方がちがうと、新人さんが迷う |

第6章の未来の作戦マップに書いた仕組みや、第10章の任せ方ボードの「必要な仕組み」の欄も、レシピの候補の宝庫です。

### 5. レシピは「8つの項目」で書く

仕事のレシピは、毎回同じ書式で書きます。書式がそろっていると、読む人は「どこに何が書いてあるか」がすぐにわかります。

| 項目 | 書くこと | 料理でいうと |
|---|---|---|
| ① 目的 | この仕事で、何を生み出すのか | 「家族が笑顔になる夕ごはん」 |
| ② 責任者 | この仕事に責任を持つ役割（人の名前ではなく役割） | 今日の料理当番 |
| ③ 始まる条件 | いつ、どんなときにこの仕事を始めるか | 夕方5時になったら |
| ④ 目安時間 | だいたい何分・何時間かかるか | 調理時間40分 |
| ⑤ 受け取るもの／渡すもの | 誰から何を受け取り、終わったら誰に何を渡すか | 買い物係から材料を受け取り、食卓に出す |
| ⑥ 手順 | 順番どおりのやること。コツや注意も添える | 1. 玉ねぎを切る 2. 炒める…… |
| ⑦ 基準 | 「ここまでできたら合格」の目印 | 野菜がやわらかく、ルーが焦げていない |
| ⑧ 困ったとき | よくあるトラブルと、そのときの動き方・相談先 | 焦げたら火を止めて、お母さんに声をかける |

ここで大事なのが、**②責任者は人の名前ではなく、役割で書く**ということです。
第7章で学んだ「役割に人をつける」と同じ考え方ですね。「石田さん」と書くと、石田さんがいなくなったときにレシピが使えなくなります。「事務・請求担当」と書けば、誰がその役割についても使えます。

そして、**①目的と⑦基準を必ず書く**こと。
手順だけのレシピは、書いてあることはできても、書いていないことが起きたときに動けません。
「何のための仕事か」がわかっていれば、レシピにないことが起きても、自分で考えて動けるようになります。

### 6. 良いレシピかどうかの「7つのチェック」

レシピを書いたら、次の7つで確かめます。

| チェック | 質問 | ✕ の例 | ◯ の例 |
|---|---|---|---|
| ① 目的がわかる | 「何のための仕事か」が書いてある？ | 手順だけが並んでいる | 「会社のお金を1円ももらさず受け取るため」 |
| ② 合格がわかる | 終わったとき「これでOK」と自分で判断できる？ | 「きれいにそうじする」 | 「床に髪の毛やゴミが1つも落ちていない」 |
| ③ 1つの手順に1つの動き | 1行に、やることが1つだけ？ | 「確認して入力して保存する」 | 「1. 確認する 2. 入力する 3. 保存する」 |
| ④ 誰でもわかる言葉 | 入ったばかりの人が読んでもわかる？ | 社内だけの略語や、専門用語がそのまま | 略語には一度だけ意味を添える |
| ⑤ 新人さんがためした | 書いた人以外が、レシピだけ見てやってみた？ | 書いた人が読み返しただけ | 新人さんがやってみて、つまずいたところを直した |
| ⑥ 困ったときがある | よくあるトラブルと相談先が書いてある？ | 「何かあれば上司へ」だけ | 「金額が合わないときは、管理部長に当日中に相談」 |
| ⑦ いまの一番いいやり方 | 昔のやり方のままになっていない？ | 3年前のやり方のまま | 最近うまくいったやり方に書き直してある |

この中で、私がいちばん大事にしているのは**⑤新人さんがためした**です。
書いた本人は、その仕事を知りつくしています。だから、自分では「わかりやすい」と思っていても、知らない人にとっては、ぬけていることがたくさんあるんです。
**レシピの本当の先生は、その仕事を知らない新人さん**です。

### 7. 言葉と書き方を、会社全体でそろえる

レシピを何人かで書くと、書く人によって書き方がバラバラになります。
ある人は「〜してください」、ある人は「〜すること」、ある人は「できるだけ〜する」。
これでは、読む人が「これは必ずやること？ それとも、できればでいいこと？」と迷ってしまいます。

そこで、会社全体で**書き方のルール**を先に決めておきます。

| ルール | ◯ そろえた書き方 | ✕ バラバラの書き方 |
|---|---|---|
| やる人を主語にして「〜します」で書く | 「記録を確認します」 | 「記録を確認してください」「確認すること」 |
| 言い切る | 「午前10時までに送ります」 | 「なるべく早めに送ります」「がんばって送ります」 |
| 数字で書く | 「3日以内に」「2人で確認します」 | 「すぐに」「しっかり確認します」 |
| です・ます調でそろえる | 「〜です」「〜します」 | 「〜だ」「〜である」がまざる |
| 同じものは同じ言葉で呼ぶ | 「ご利用者」に統一 | 「利用者さん」「お客様」「〇〇様」がまざる |

最後の「同じものは同じ言葉で呼ぶ」のために、**会社の言葉の辞書**（よく使う言葉と、その意味の一覧）をつくっておくと便利です。
新人さんにとっては、辞書そのものが「この会社の言葉を覚える教材」になります。

### 8. レシピは「みんなで作って、使いながら育てる」

最後に、いちばん大事なことをお伝えします。
**レシピは、社長がひとりで書くものではありません。**

社長が全部書こうとすると、時間が足りずに止まります。
それに、現場の仕事を一番よく知っているのは、毎日その仕事をしている人です。

| | ✕ うまくいかない作り方 | ◯ うまくいく作り方 |
|---|---|---|
| 書く人 | 社長がひとりで書く | その仕事を一番うまくできる人が**先生役**になって書く |
| 順番 | 全部の仕事を一度に書こうとする | 4つの「こんな仕事から」で選んだ**3本から**始める |
| 確かめ方 | 書いた人が読み返して終わり | **新人さんや別の拠点の人がためして**、つまずいたところを直す |
| 置き場所 | 人によってパソコンの中・紙のファイルとバラバラ | **決まった1か所**に置き、誰でもすぐに開ける |
| その後 | つくったら終わり | 「もっといいやり方」が見つかったら、**誰でも直しを提案できる** |

「先生役」をお願いするときに、気をつけたいことがあります。
その仕事を長く一人で抱えてきた人の中には、「レシピにしたら、自分の仕事がなくなるのでは」と不安に思う方がいます。
私はそういうとき、**「あなたのやり方を、会社の宝物として残したい」「レシピができたら、次はもっと大きな仕事をお願いしたい」**と、社長の言葉で伝えてもらうようにしています。
レシピは、その人の居場所を奪うものではなく、**その人の腕前を会社に残し、その人が次へ進むための道具**なんです。

> 💡 レシピを置く場所・直し方・見直しの時期などを決めたルールを、専門用語では「マニュアル管理」といいます。

#### 記入例：毎月の介護保険の請求のレシピ

ひだまりケアの日向社長は、最初の1本に**「毎月の介護保険の請求」**を選びました。
これまで事務長の石田さんがひとりで担当していて、石田さんが休むと誰にもわからない仕事だったからです。
日向社長は石田さんに「あなたのやり方を、会社の宝物として残したい。レシピができたら、3つ目の拠点の事務の立ち上げをお願いしたい」と伝え、**石田さんに先生役**をお願いしました。

| 項目 | 内容 |
|---|---|
| 仕事の名前 | 毎月の介護保険の請求 |
| ① 目的 | 毎月のサービスの代金を、**ミスなく期日どおりに請求し、会社のお金を1円ももらさず受け取る**。そのことで、職員さんのお給料と、ご利用者へのサービスを守る |
| ② 責任者 | 事務・請求担当（確認役：管理部長） |
| ③ 始まる条件 | 毎月1日。前の月のサービスの実績が、各拠点からそろったとき |
| ④ 目安時間 | 毎月 約16時間（1日〜10日のあいだ） |

**⑤ 受け取るもの／渡すもの**

| 受け取る・渡す | 誰から・誰へ | 何を | いつまでに |
|---|---|---|---|
| 受け取る | 各拠点の拠点長・サービス提供責任者から | 前の月のサービスの実績（誰に・いつ・何をしたか） | 毎月3日 |
| 渡す | 請求の窓口へ | 介護保険の請求データ | 毎月10日 |
| 渡す | ご利用者・ご家族へ | ご利用者が払う分の請求書 | 毎月15日 |
| 渡す | 管理部長へ | 請求額のまとめと、気になったことのメモ | 毎月10日 |

**⑥ 手順**

| 手順 | やる役割 | コツ・注意 |
|---|---|---|
| 1. 各拠点から、前の月の実績を受け取ります | 事務・請求担当 | 3日の正午までに届かない拠点には、電話で声をかけます |
| 2. 実績と、介護の計画にある予定とを1件ずつ見比べます | 事務・請求担当 | 予定とちがう日は、拠点に理由を聞いてメモします |
| 3. 加算の取りこぼしがないか、チェックリストで確かめます | 事務・請求担当 | 「加算を取りこぼさないチェックリスト」を使います |
| 4. 請求のシステムに実績を入力します | 事務・請求担当 | 入力したら、ご利用者ごとに合計金額を印刷します |
| 5. 別の人が、印刷した合計金額と実績を見比べます | 管理部長 | 2人目の確認は、入力した人とは必ず別の人がします |
| 6. 請求データを送ります | 事務・請求担当 | 送ったら、受け付けられたことを画面で確かめて、印刷して保管します |
| 7. ご利用者が払う分の請求書をつくり、送ります | 事務・請求担当 | 金額が先月と大きくちがう方には、拠点長からひとこと説明してもらいます |
| 8. 請求額のまとめを、管理部長に報告します | 事務・請求担当 | 先月とくらべて、増えた・減ったところを一行で書き添えます |

**⑦ 基準（ここまでできたら合格）**

1. 請求データを、毎月10日までに送り終えている
2. 戻ってきた請求（まちがいで差し戻された件数）が、毎月0件
3. 加算のチェックリストが、全員分うまっている
4. 入力した人とは別の人が確認し、確認した印がある
5. 請求書が、毎月15日までにご利用者・ご家族に届いている

**⑧ 困ったとき**

| こんなときは | こうする・ここに相談 |
|---|---|
| 3日を過ぎても、実績が届かない拠点がある | その日のうちに拠点長へ電話し、届く時間を決める。5日を過ぎそうなら管理部長に相談 |
| 予定と実績が合わない | 自分で直さず、拠点に理由を聞いてから直す。わからないときは管理部長へ |
| システムが動かない・データが送れない | 管理部長に連絡し、システムの会社の問い合わせ窓口に電話する（電話番号はレシピの最後のページ） |
| 請求がまちがいで戻ってきた | その日のうちに管理部長へ報告。原因と直し方をこのレシピの「困ったとき」に書き足す |

| 最後に直した日と、直した人 |
|---|
| 2027年1月20日　石田（先生役）が書き、事務の職員さん（パートの方）がためして、手順3と5を直した |

> 📝 パートの事務の職員さんがレシピだけを見て12月分の請求をためしてみたところ、「加算のチェック」と「2人目の確認」でつまずきました。石田さんにとっては当たり前すぎて、書いていなかったところです。
> 石田さんは「自分の頭の中に、こんなに書いていないことがあったとは」と笑いながら、その場で書き足していました。

## ⑦ 次の章へ

取扱説明書とレシピができると、「聞かないとわからない会社」から**「読めばわかる会社」**へ、一歩近づきます。
でも、ここで多くの会社がぶつかる壁があります。
それは、**「新しいやり方に、みんながついてきてくれない」**という壁です。

「前のやり方の方が早い」「レシピなんて読まなくてもできる」。そんな声が出てくるのは、自然なことです。
次の**第12章「変化を仲間に広げる」**では、こうした反対や不安を味方に変えて、新しい仕組みを会社に根づかせていく方法を学びます。

また、ここでつくったレシピは、**第15章「人が育つ仕組み」**の教材として、そのまま使えます。
レシピがそろうほど、第10章の任せ方ボードの矢印も、安心して右へ進められるようになります。

### 事前準備
- 受講者には、できれば第4〜7章・第9章を終えてから参加してもらう（終えていない章は「準備中」として扱う）

- 付せん（2色：取扱説明書に入れる＝青、レシピに回す＝黄）

### 時間配分（90分の例）

| 時間 | 内容 | ポイント |
|---|---|---|

### 問いかけの例
- 「その内容は、パートさんも入ったばかりの人も、全員が知っておく必要がありますか？」（取扱説明書に何でも入れようとするとき）
- 「この取扱説明書の持ち主は誰ですか？ その人が1年後も直し続けられますか？」
- 「その仕事を、明日あの人が休んだら、誰がどうやりますか？」（レシピにする仕事を選ぶとき）
- 「『きれいに』は、どのくらいきれいなら合格ですか？ 目で見てわかる言葉にすると？」
- 「このレシピだけを渡されて、知らない人がひとりでできますか？ どこでつまずきそうですか？」
- 「この仕事は、何のためにやっているのですか？ やらなかったら、誰が困りますか？」（目的が書けないとき）

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 取扱説明書に、何でもかんでも入れようとして分厚くなる | 「全員が知っておくこと？」と1つずつ聞き、特定の役割だけのものはレシピに回す |
| 取扱説明書の持ち主を社長にしてしまう | 「社長がいそがしい月に、止まりませんか？」と聞き、管理部などの人を持ち主にする |
| レシピの責任者に、人の名前を書く | 「その人がいなくなったら、このレシピは使えますか？」と聞き、役割の名前に直す |
| 手順だけを書いて、目的や基準がない | 「やらなかったら誰が困る？」「どうなったら終わり？」と聞いて、目的と基準を書き足す |
| 1行に「確認して、入力して、保存する」と動きがいくつも入る | 「1行に1つの動き」に分ける。分けると、ぬけていた手順が見つかることが多いと伝える |
| 「しっかり」「なるべく」「すぐに」が多い | 書き方のルール表を見ながら、数字や言い切りに直す |
| 社長が全部のレシピを自分で書こうとする | 「その仕事を一番うまくできるのは誰ですか？」と聞き、その人に先生役をお願いする計画にする |
| 先生役の人が「自分の仕事がなくなる」と不安がる | 「あなたの腕前を会社に残したい」「次はもっと大きな仕事を」と、社長の言葉で伝えてもらう |
| 一度に何十本もつくろうとして止まる | 4つの「こんな仕事から」で選んだ3本にしぼり、1本ずつためして直す |
