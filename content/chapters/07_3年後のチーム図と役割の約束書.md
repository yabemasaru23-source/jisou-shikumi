## ① この章でできるようになること

- 未来の作戦マップの8つの作戦から、**3年後の会社に必要な「役割」**を洗い出せる
- 「人に役割をつける」のではなく**「役割に人をつける」**考え方で、**3年後のチーム図**を1枚に描ける
- いま社長が**兼務している役割**と、まだ**空欄の役割**が、ひと目でわかるようになる
- それぞれの役割が何のためにあるのかを**「役割のひとこと」**で言えるようになる
- 目的・仕事・基準を本人と上司で約束する**「役割の約束書」**をつくれる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 組織図はあるけれど、壁に貼ってあるだけで、誰も見ていない
- 「それ、誰の仕事だっけ？」が毎週のように起きる。やり忘れと、二重にやっていることの両方がある
- できる人のところに、どんどん仕事が集まっていく。そして、その人がつかれてやめていく
- 役職の名前はあるのに、「管理者って、結局なにをする人？」と聞かれると答えにくい
- 人がやめるたびに、その人がやっていた仕事ごと、会社から消えてしまう

私はこれまで、たくさんの会社の組織図を見せていただいてきました。
そこでよく気づくのが、**組織図が「いまいる人の名前を並べた表」になっている**ということです。

「Aさんは営業が得意だから営業部長」「Bさんは長くいるから管理者」。
こうして人に合わせて役割をつくると、Aさんがやめたとき、営業部長という役割ごと消えてしまいます。
その結果、ぽっかり空いた穴を、社長が自分で埋めることになる。私が出会ってきた社長さんの多くが、こうして**気づけばいくつもの役割を一人で抱えていました。**

第6章で、3年後のゴールと8つの作戦を決めましたね。
でも作戦は、それを**「私が責任を持ってやります」と言う人がいなければ、ただの紙**です。
この章では、作戦を実行するためのチームの形と、ひとりひとりの役割をはっきりさせます。

### 目指す姿

- 3年後のチーム図が1枚あって、「会社がどこに向かって、どんな人を必要としているか」が誰にでもわかる
- どの役割にも「役割のひとこと」があり、職員さんが「私の役割は〇〇をすることです」と自分の言葉で言える
- 社長が兼務している役割が見えていて、「いつまでに、誰に手わたすか」の計画がある
- 役割の約束書が、仲間集め・育成・評価・1対1の応援面談の「ものさし」として使われている

## ③ 考え方

### 1. 役割は「劇の配役表」と同じ

学芸会の劇を思いうかべてください。
先生はまず**台本**を用意します。台本には「王様」「旅人」「村人A」といった**役**が書いてあります。
そのあとで、「王様の役は誰がやる？」と**配役**を決めますよね。

もし先生が、先に集まった子どもの顔ぶれを見て「この子たちでできる劇をつくろう」と考えたら、どうなるでしょう。
その年はなんとかなっても、毎年ちがう劇になり、「この劇で何を伝えたいのか」がぶれてしまいます。

会社も同じです。

| | ✕ 人に役割をつける | ◯ 役割に人をつける |
|---|---|---|
| 考える順番 | いまいる人 → その人ができること → 役割 | 3年後のゴールと8つの作戦 → 必要な役割 → 人 |
| 人がやめたら | 役割ごと消える。社長が穴を埋める | 役割は残る。次の人を探せばいい |
| 採用 | 「誰かいい人いない？」になる | 「この役割の人を探しています」と言える |
| 本人にとって | 何を期待されているかわからない | 自分の目指す場所と、次に目指せる役割が見える |

**台本（8つの作戦）が先、配役（人）はあと。** これがこの章でいちばん大事な考え方です。

> 💡 専門用語では、3年後のチーム図をつくることを「組織戦略」、役割のひとことを「成果定義文」、役割の約束書を「職務契約書」といいます。この教材では、わかりやすい言葉で進めていきます。

### 2. 3年後のチーム図は「5つのステップ」で描く

チーム図は、次の5つのステップで描きます。いきなり名前を書かないのがコツです。

| ステップ | やること | ポイント |
|---|---|---|
| ① 役割を洗い出す | 8つの作戦と64個の仕組みを見ながら、「これを実行するのはどんな役割？」を書き出す | 人の名前はまだ書かない |
| ② 社長のすぐ下を決める | 洗い出した役割を、大きなまとまり（部門）に分けて、社長の直下に置く | 社長の直下は多くても5〜6つまで |
| ③ その下を決める | それぞれの部門に、どのくらいの仕事がありそうかを考えて、下の役割を置く | 「〇人くらい必要」と人数も書く |
| ④ 現実性チェック | 人数・人件費・3年後のゴールと合っているかを確かめて、調整する | ゴールの数字と矛盾したら、図の方を直す |
| ⑤ 人を当てはめる | 最後に、いまいる人の名前を書く。いない役割は空欄のまま | 社長が兼務している役割に印をつける |

ステップ④の**現実性チェック**は、次の3つの質問で行います。

1. **人数**：3年後に、全部で何人になっている？ いまから何人増やす必要がある？
2. **人件費**：その人数で、人件費はいくらになる？ 売上の何%？
3. **ゴールとの整合**：その人件費を払っても、3年後のゴール（例：経常利益3,000万円）にたどり着ける？

夢を描くのは大切ですが、ゴールにたどり着けないチーム図では意味がありません。
逆に、人が足りなくて8つの作戦が動かないチーム図でも困ります。この2つの間の「ちょうどいいところ」を探すのが、ステップ④です。

### 3. 空欄があっていい。社長の兼務は「見える化」する

チーム図を描くと、名前の入らない役割がたくさん出てきます。
**それで大丈夫です。むしろ、空欄があるのが正しいチーム図です。**

空欄は「足りないところ」ではなく、**「これから仲間を迎える席」**です。
空欄がはっきりしていれば、第13章「仲間集めの仕組み」で「どんな人を探すか」がすぐに決まりますし、社内の職員さんにとっては「次に目指せる役割」になります。

そして、もうひとつ大事なのが、**社長が兼務している役割を正直に書くこと**です。

私が社長さんと一緒にチーム図を描くと、たいてい「社長」の名前が5つも6つもの役割に入ります。
ご本人も、描いてみてはじめて「私、こんなに持っていたんですね……」と苦笑いされることが多いんです。

これは悪いことではありません。小さな会社では当たり前のことです。
ただ、**見えていないものは、手ばなせません。** 兼務している役割に印をつけて、「この役割は、いつまでに、誰に手わたすか」を決めることが、社長が「未来をつくる人」の時間を取りもどす第一歩になります。

### 4. 上司はひとり

チーム図の線を引くときに、守ってほしい原則がひとつあります。
それは、**「ひとりの人の上司は、ひとりだけ」**ということです。

サッカーの試合中に、監督が2人いて、ひとりは「攻めろ！」、もうひとりは「守れ！」と叫んでいたら、選手は困ってしまいますよね。

会社でも、拠点長と社長の両方から別々の指示が来ると、職員さんは「どっちに従えばいいの？」と迷います。
そして、たいていは「社長の言うこと」が優先されて、拠点長の立場がなくなってしまいます。

社長が現場の職員さんに何かを伝えたいときは、**直属の上司を通す**。
これだけで、リーダーが育つスピードがぐっと変わります。

> 💡 専門用語では、この原則を「命令系統の一元化」といいます。

### 5. 役割のひとこと：「何をするか」ではなく「何を生み出すか」

チーム図ができたら、それぞれの役割に**「役割のひとこと」**をつけます。
その役割が**何を生み出すためにあるのか**を、1文で書いたものです。

ここでよくある失敗は、「何をするか（作業）」を書いてしまうことです。

| 役割 | ✕ 作業を書いている | ◯ 生み出すものを書いている |
|---|---|---|
| デイサービス拠点長 | デイサービスを運営する | ご利用者が「また来たい」、職員さんが「ここで働き続けたい」と思える、黒字の拠点にする |
| 事務担当 | 請求業務を行う | 毎月の請求を、ミスなく期日どおりに終え、会社のお金を1円ももらさず受け取る |
| サービス提供責任者 | ヘルパーの調整をする | ご利用者が住みなれた家で安心して暮らせるように、ヘルパーさんのサービスの質をそろえる |

見分け方はかんたんです。
**「その役割がうまくいったら、誰がどうなっている？」**と聞いてみてください。答えが出てくれば、それが役割のひとことです。

役割のひとことが決まると、「これは私の仕事かな？」と迷ったとき、職員さんが自分で判断できるようになります。

### 6. 役割の約束書は「係のお仕事カード」

小学校の係決めを思い出してください。
「生きもの係」になったら、「毎朝メダカにエサをあげる」「金曜日に水そうをそうじする」と、やることが黒板に書いてありましたよね。

役割の約束書は、この**係のお仕事カードの会社版**です。書くことは5つだけです。

| 項目 | 書くこと |
|---|---|
| ① 目的 | 役割のひとこと |
| ② 上司と部下 | 誰に報告するか（上司はひとり）。部下がいるなら、部下の役割とそのひとこと |
| ③ 主な仕事 | 🚀 **未来をつくる仕事**：いまより良くするための仕事（3〜5つ）<br>🔧 **毎日の仕事**：くり返し回していく仕事（3〜5つ） |
| ④ 仕事の基準 | 📏 **その役割特有の基準**：「ここまでできたら合格」を数字や状態で（3〜5つ）<br>🤝 **全社共通の基準**：わが社の合言葉を、この役割ではどう行動に移すか |
| ⑤ 署名 | 本人と上司が、読んで話し合ったうえで、それぞれ署名する |

③で「未来をつくる仕事」と「毎日の仕事」を分けるのには理由があります。
毎日の仕事だけを書くと、その役割は「いまを回す人」になってしまいます。
**リーダーの役割ほど、未来をつくる仕事の割合を多くする**のがポイントです。第0章の「社長の3つの顔」と同じ考え方ですね。

④の全社共通の基準には、第4章でつくった**わが社の合言葉**を使います。
合言葉は、どの役割の人にも共通の約束です。ただし「その人らしさをいちばんに」を、拠点長と事務担当とでは行動の形が変わります。役割ごとに「うちの役割では、こうする」と書くのがコツです。

### 7. 約束書は「しばる紙」ではなく「応援の約束」

「約束書」と聞くと、「社員さんをしばるものでは？」と心配される社長さんもいます。
でも、ここで大事なのは**⑤の署名が「本人と上司の両方」**だということです。

- 本人は、「この目的・仕事・基準を果たします」と約束する
- 上司は、「この役割を果たせるように、時間・道具・学びの機会を用意して応援します」と約束する

つまり、**上司の側も約束をする**のです。
だから私は、約束書を上司がひとりで書いて渡すのではなく、**本人と上司がいっしょに話しながら書く**ことをおすすめしています。
話し合う中で、「そんなことまで期待されていたの？」「その基準なら達成できそう」といった本音が出てきます。その時間そのものが、信頼を育ててくれるんです。

できあがった約束書は、このあと、仲間集め（第13章）、人が育つ仕組み（第15章）、1対1の応援面談（第9章）で、何度も使うことになります。

## ⑦ 次の章へ

これで、「3年後のゴール」「8つの作戦」「それを実行するチームと役割」がそろいました。
あとは、このチームが**毎週・毎月、同じリズムで集まって作戦を進めていく**ことが必要です。

必修ルートの次は、**第9章「作戦会議のメンバーと会社のリズム」**です。
社長ひとりで決めずに、一緒に会社の舵を取る仲間（作戦会議のメンバー）を決め、いつ・誰と・何を話すかの決まりごとをつくります。
この章でつくった役割の約束書は、第9章の「1対1の応援面談」で、上司と部下が話し合う土台になります。

もうひとつの選択肢は、**第8章「仕組みの宝さがし」**です。
第6章で書き出した最大64個の仕組みを、「どれから、誰がつくるか」を決めていきます。チーム図ができた今なら、仕組みごとに「担当する役割」を決められます。
時間に余裕がある方は、第9章の前に取り組んでみてください。

### 問いかけの例
- 「その役割は、8つの作戦のどれを実行するためにありますか？」（作戦とつながらない役割が出てきたとき）
- 「もしその人が明日やめたら、この役割はどうなりますか？」（人に合わせて役割をつくっているとき）
- 「赤い付せん（社長兼務）が全部なくなったら、社長は何に時間を使いたいですか？」
- 「この職員さんには、上司が何人いますか？ 指示がぶつかったら、どちらに従いますか？」
- 「その役割がうまくいったら、誰がどうなっていますか？」（役割のひとことが作業になっているとき）
- 「その基準は、本人が『達成できた』と自分でわかりますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| いきなり、いまいる人の名前でチーム図を描きはじめる | 名前を書いた付せんをいったん外してもらい、「8つの作戦を実行するのはどんな役割？」から考え直す |
| 空欄を嫌がり、無理に誰かの名前を入れる | 「空欄は、これから仲間を迎える席です」と伝える。無理に入れると、その人が役割を持ちすぎることを確認する |
| 社長兼務を書かない（「私がやるのは当たり前」） | 1週間の時間の使い方を思い出してもらい、実際にやっている役割をすべて書き出してもらう |
| 社長の直下に役割が8つも10も並ぶ | 「似ているものをまとめると？」と聞いて、5〜6つまでにまとめる |
| 1人の職員さんに上司が2人いる線が引かれている | サッカーの監督2人のたとえで、「上司はひとり」の原則を確認する |
| 人件費を計算すると、ゴールにとどかない | チーム図の方を直す。役割を減らすか、兼務させるか、時期をずらすかを一緒に考える |
| 役割のひとことが「〜を運営する」「〜を行う」になる | 「うまくいったら、誰がどうなっている？」と聞いて、生み出すものの言葉に直す |
| 約束書の仕事が20個も30個も並ぶ | 「未来をつくる仕事」と「毎日の仕事」に分けて、それぞれ大事な5つにしぼる。残りは第11章の仕事のレシピで扱う |
| 上司が約束書をひとりで書いて、本人に渡そうとする | 「上司の側も約束をする紙です」と伝え、必ず本人と話し合いながら書いてもらう |
