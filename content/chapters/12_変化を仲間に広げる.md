## ① この章でできるようになること

- 新しい仕組みに出てくる**反対や不安の「正体」**を見ぬき、相手の気持ちに合わせて応えられる
- お客様・職員さん・会社のそれぞれにとって、**「なぜ変わるのか」**を自分の言葉で伝えられる
- **作戦会議のメンバーで心をそろえ**、「いつ・誰に・どうやって」伝えるかの計画を立てられる
- すぐに目に見える**小さな成功**をつくり、職員さんに**任せて自分ごとにしてもらう**流れをつくれる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 全員集合ミーティングで夢や作戦を話したのに、職員さんの反応がうすかった
- 新しいやり方を始めたら、「前のほうがよかった」「また社長の思いつきだ」という声が聞こえてきた
- 会議では誰も反対しないのに、現場に戻ると、いつのまにか元のやり方に戻っている
- 社長と幹部で、職員さんへの説明がちょっとずつちがっている
- 「わかってくれないなら、もういい」と、社長ひとりで仕組みをつくって押しつけてしまう

私が社長さんとお話ししていてよく聞くのが、「仕組みづくりは楽しいけれど、**社員さんに広げるところで止まってしまう**」という声です。
立派な作戦マップも、役割の約束書も、会社のリズム表も、現場で使われなければ、引き出しの中の紙のままです。

そして、うまくいかない会社には、共通点がありました。
それは、**反対や不安を「やる気のなさ」だと思ってしまう**ことです。

私の経験では、反対する職員さんの多くは、会社のことを真剣に考えている人です。
ただ、**「変わったら、自分はどうなるの？」が見えていなくて、こわい**のです。
その「こわい」に先に寄りそえば、いちばん強く反対していた人が、いちばん頼りになる味方に変わることもめずらしくありません。

### 目指す姿

- 新しい仕組みを始めるとき、職員さんから「なぜやるのか」がちゃんと聞ける
- 不安や反対の声が、かげ口ではなく、会議や面談の場で正直に出てくる
- 作戦会議のメンバーの誰に聞いても、同じ説明が返ってくる
- 「この仕組み、私たちでつくりました」と言う職員さんが、少しずつ増えていく

## ③ 考え方

### 1. 反対は「不安のサイン」

人は、なぜ変化をこわがるのでしょうか。
子どものころの**転校やクラス替え**を思い出してみてください。

新しい学校が、いまよりいいところかもしれない。それでも前の晩は、なんとなく眠れませんでしたよね。
「友だちができるかな」「授業についていけるかな」「いまの仲よしとはなれたくない」……。
新しい学校がきらいなのではなく、**わからないことと、なくすものがこわかった**のです。

職員さんも同じです。反対の言葉の奥には、たいてい次のような気持ちがかくれています。

| 表に出てくる言葉 | 奥にある気持ち（正体） | 先に伝えたいこと |
|---|---|---|
| 「いまのやり方で困っていません」 | 慣れたやり方や、自分の得意を**なくすのがこわい** | これまでのやり方のいいところは残す。あなたの経験が必要 |
| 「何のためにやるんですか？」 | 理由が**わからないのがこわい** | なぜ変わるのか、変わると誰がどう助かるのか |
| 「私にはできないと思います」 | 新しいやり方を**覚えられるか不安** | 練習の時間と、教えてくれる人を用意する |
| 「これ以上、仕事が増えるのは無理です」 | **忙しさがもっとひどくなる**のが心配 | 何をやめるのか。いつ楽になるのか |
| 「どうせ、またすぐ終わりますよ」 | **前にも期待して、がっかりした** | 今回は何がちがうのか。続ける決まりがあること |
| 「勝手に決められても……」 | **知らないうちに決まった**のがさびしい | 決める前に聞く。いっしょにつくる場をつくる |

いちばん気をつけたいのは、**声に出さない反対**です。
会議ではうなずいて、現場では元のやり方を続ける。これは、反対の声が出るよりずっと手ごわいものです。
ですから、反対の声が出たら「やっと本音を聞かせてもらえた」と、まずはお礼を言いましょう。

### 2. 変化を広げる6つのステップ

変化を仲間に広げるには、順番があります。
この章では、次の6つのステップで進めます。

![変化を広げる6つのステップ：反対・不安の正体を知る → 変わる理由を伝える → 作戦会議のメンバーで心をそろえる → 伝える計画を立てる → すぐ見える小さな成功 → 任せて自分ごとにしてもらう](assets/img/ch12-steps.svg)

| ステップ | やること | 料理にたとえると |
|---|---|---|
| ① 正体を知る | 反対・不安の奥にある気持ちを書き出す | 食べる人の好ききらいを聞く |
| ② 理由を伝える | お客様・職員さん・会社の「いま」と「これから」を言葉にする | 「今日はなぜこの料理なのか」を話す |
| ③ 心をそろえる | 作戦会議のメンバーで、同じ説明ができるようにする | 料理人どうしで味つけを決めておく |
| ④ 計画を立てる | いつ・誰に・どうやって伝えるかを決める | 誰から先に、どの順でお皿を出すか決める |
| ⑤ 小さな成功 | すぐに「よくなった」と感じられることを先にやる | まずは一口、味見してもらう |
| ⑥ 任せる | 職員さんにつくる側に回ってもらう | いっしょに台所に立ってもらう |

> 💡 こうした進め方は、専門用語では「チェンジ・マネジメント（変化の進め方）」と呼ばれます。この教材では「変化を仲間に広げる」で進めます。

### 3. 「正しさ」より「困りごと」で伝える

社長が新しい仕組みを説明するとき、いちばん多い失敗があります。
それは、**正しさだけを伝えてしまう**ことです。

> ✕「これからは仕組みで回る会社にします。そのほうが効率的だからです」

まちがってはいません。でも、聞いている職員さんの心は動きません。「効率的」は、社長にとってのうれしさに聞こえてしまうからです。

人の心を動かすのは、**「このままだと、誰が困るのか」**と**「変わったら、誰がどううれしいのか」**です。
しかも、相手によってうれしいことはちがいます。ですから、次の3つの立場で考えます。

| 立場 | このままだと困ること | 変わったあとのうれしいこと |
|---|---|---|
| 😊 お客様 | 担当する人によって、ケアの質がちがう | 誰が来ても「いつもの安心」が届く |
| 🙋 職員さん | 「あの人しか知らない」仕事で、休みが取りにくい | 困ったときに頼れるやり方と仲間がいて、休みも取りやすい |
| 🏢 会社 | 社長が倒れたら止まってしまう | 社長がいなくても回り、新しい拠点も出せる |

> ◯「いまは、ベテランの〇〇さんがお休みの日に、ご利用者さんから『今日はいつもとちがう』と言われることがありますよね。それは〇〇さんのせいではなく、やり方がまだ〇〇さんの頭の中にしかないからです。みんなが同じ安心を届けられるように、そして〇〇さんがちゃんと休めるように、やり方をみんなで形にしたいんです」

このように、**職員さんがふだん感じている困りごと**から話し始めると、「それなら」とうなずいてもらいやすくなります。

### 4. 作戦会議のメンバーで心をそろえる

ボートレースを思いうかべてください。
こぎ手が4人いても、1人だけ逆向きにこいだら、ボートはその場でくるくる回るだけです。

会社も同じです。社長が「やろう」と言っても、部長候補のひとりが現場で「まあ、社長がまた言ってるだけだから」とつぶやけば、職員さんはそちらを信じます。
職員さんは、**社長の言葉より、身近なリーダーの顔つき**を見ているからです。

だからこそ、職員さんに広げる前に、**作戦会議のメンバー（第9章）**で、次の3つをそろえておきます。

| そろえること | 中身 |
|---|---|
| 🔍 いまの困りごと | 会社がいま、何に困っているのか。このままだと何が起きるのか |
| 🏔️ 目指す姿 | 会社の夢の完成図・3年後のゴール・3年後のチーム図 |
| 🧭 進め方と心がまえ | 何から、いつまでに変えるのか。反対の声が出たら、どう受けとめるのか |

もう1つ大事なのが、**メンバーに足りない力**を確かめることです。
たとえば、メンバーが全員正社員だと、パートさんの不安が見えにくくなります。そんなときは、パートさんの声を代わりに届けてくれる人を、相談役として迎えるのも1つの方法です。

### 5. 伝える計画は「内側から外側へ」「何度も、ちがう方法で」

伝える順番は、池に石を投げたときの波紋のように、**内側から外側へ**広げるのが基本です。

1. 作戦会議のメンバー
2. 拠点長やサービス提供責任者など、現場のまとめ役
3. 職員さんの中で、影響力の大きい人（ベテラン・相談役・ちょっと辛口な人）
4. 職員さん全員（パートさんも含めて）

いきなり全員に話すと、まとめ役が「私も今日はじめて聞きました」という顔をしてしまいます。それでは、職員さんは不安になりますよね。

そしてもう1つ。**大事なことは、1回伝えただけでは届きません。**
学校の先生も、大事な持ちものは、プリントで配って、朝の会で言って、前の日にもう一度言いますよね。

| 方法 | 向いていること |
|---|---|
| 全員集合ミーティング | 夢と方針を、全員に同じ言葉で伝える |
| 1対1の応援面談 | 一人ひとりの不安を聞き、その人にとっての意味を話す |
| 拠点ごとの小さな説明会 | 現場の具体的な「何が変わるか」を話す |
| 社内だより・掲示 | 決まったことや、小さな成功を何度も目にふれさせる |

### 6. 「すぐ見える小さな成功」で、味方を増やす

自転車に乗る練習を始めたばかりの子に、「1年後には坂道も登れるよ」と言っても、あまり元気は出ません。
それより、「今日は5メートル進めたね！」のほうが、ずっとやる気になります。

変化も同じです。3年後のゴールは遠すぎて、職員さんには手ごたえがありません。
ですから、**3か月以内に、職員さんが「あ、楽になった」「よくなった」と感じられること**を、先に1つか2つ実現します。

| 小さな成功の選び方 | ◯ の例 | ✕ の例 |
|---|---|---|
| すぐできる（3か月以内） | 会議の時間を半分にする | 新しい評価制度をつくる（1年かかる） |
| 目に見える | 申し送りのひな形をつくり、書く時間が減る | 「意識を高める」 |
| 職員さんがうれしい | シフトの穴を埋める連絡の順番を決め、夜の電話を減らす | 社長の報告書づくりが楽になる |

そして、小さな成功が出たら、**全員の前で、関わった人の名前を出してお礼を言いましょう**。「変わると、いいことがある」が、うわさになって広がっていきます。

### 7. 任せて「自分ごと」にしてもらう

家で、子どもといっしょにカレーをつくったことはありますか？
自分で野菜を切ったカレーは、少しくらい形がいびつでも、「おいしい！」と言って残さず食べてくれます。

仕組みも同じです。**社長がつくって配った仕組みは「やらされること」、自分たちでつくった仕組みは「自分ごと」**になります。

| ✕ 社長がぜんぶつくる | ◯ 職員さんに任せる |
|---|---|
| 社長が仕事のレシピを書いて、配る | 現場のチームが書いて、社長は「目的」と「しめ切り」だけ伝える |
| 社長が新しいルールを発表する | 職員さんの代表といっしょに、ルールの案をつくる |
| 社長が小さな成功を報告する | つくったチームが、全員集合ミーティングで発表する |

任せるときは、第10章の**「任せ方のルール」**を使って、どこまで任せるかをはっきりさせておくと安心です。
少しくらい出来が思いどおりでなくても、まずは「つくってくれてありがとう」。直すのは、使ってみてからで大丈夫です。

### ステップ3：変わる理由を言葉にする

```work
id: 12.why
type: table
label: 「このままだと困ること」と「変わったあとのうれしいこと」を、3つの立場で書いてください
columns: [立場, このままだと困ること（いま・これから）, 変わったあとのうれしいこと（すぐ・3年後）]
rows: [お客様, 職員さん, 会社]
hint: 社長の困りごとではなく、それぞれの立場の人が「そうそう、それ困ってる」とうなずく言葉で書きましょう。うれしいことは、「すぐ感じられること」と「3年後に感じられること」の両方があると伝わりやすくなります。
example:
  - [お客様, 担当する職員さんによって、ケアのやり方や記録の伝わり方がちがう。ベテランさんが休むと「今日はいつもとちがう」と言われる, すぐ：誰が来ても同じ手順で安心できる。3年後：住みなれた家での暮らしを、もっと長く支えてもらえる]
  - [職員さん, 「あの人しか知らない」仕事が多く、休みが取りにくい。見て覚えるしかないので、新人さんが不安なまま辞めてしまう, すぐ：困ったときに見るレシピと、相談できる仲間がいる。3年後：長く働けて、拠点長などのステップアップの道もある]
  - [会社, 社長が月の半分は現場に入り、社長が倒れたら止まってしまう。拠点ごとにやり方がちがい、利益も残りにくい, すぐ：社長の現場時間が減り、作戦を考える時間ができる。3年後：経常利益3,000万円を達成し、3つ目の拠点を出せる]
```


### ステップ4：作戦会議のメンバーで心をそろえる

```work
id: 12.team.gap
type: textarea
label: 変化を進めるうえで、いまの作戦会議のメンバーに足りない人や力は何ですか？ どう補いますか？
hint: 「どの職員さんの声が、メンバーに届きにくいか」を考えると見つけやすいです。足りない力は、新しくメンバーに入れるだけでなく、相談役や意見を聞く場で補うこともできます。
example: メンバーが全員正社員で、職員さんの4割近くをしめるパートさんの声が届きにくい。また、4人とも現場か事務の出身で、職員さんに伝える資料づくりや説明が得意な人がいない。パートさんの代表として、訪問介護とデイサービスから1人ずつ相談役をお願いし、2か月に1回、作戦会議に30分だけ参加してもらう。説明の資料は、石田さんと森さんがペアでつくる。
```

```work
id: 12.team.align
type: checklist
label: 職員さんに広げる前に、作戦会議のメンバーでそろえておくことを選んでください
```

## ⑧ 講師ガイド

### この回のねらい
受講者が、自社で起きている（起きそうな）反対や不安の「奥にある気持ち」をつかみ、変わる理由・伝える計画・小さな成功・任せることを1枚にまとめた「社内に広げる計画」の下書きを完成させること。

### 事前準備
- 受講者には、第9章（作戦会議のメンバーと会社のリズム）を終えてから参加してもらう。第10章・第11章も終えていると、任せることを考えやすい
- この1か月で、職員さんから聞こえてきた「反対の声」「ぼやき」「ため息」を、できるだけそのままの言葉でメモしてきてもらう
- 付せん（2色：表に出てくる言葉／奥にある気持ち）、社内に広げる計画の記入用紙（A3）

### 時間配分（45分の例）

### 問いかけの例
- 「その反対をしている方は、会社のどんなところを大事に思っているから、反対しているのだと思いますか？」
- 「その方が、いちばんなくしたくないものは何でしょう？」
- 「いまの説明を、パートさんが聞いたら『自分にとっていいことがある』と思えますか？」
- 「作戦会議のメンバーの誰かが、現場で『社長がまた言ってるだけ』と言っていたとしたら、どうしますか？」
- 「その小さな成功で、いちばん喜ぶのは誰ですか？ 社長ですか、職員さんですか？」
- 「それは、社長がやらなくても、職員さんに任せられませんか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 反対している人を「やる気がない」「わがまま」と書いてしまう | 「その方が新しく入った頃は、どんな職員さんでしたか？」と聞き、反対の奥にある「大事にしているもの」に目を向けてもらう |
| 「反対は起きていない」と言う | 「会議ではうなずいて、現場で元に戻っていることはありませんか？」と、声に出さない反対をさがしてもらう |
| 変わる理由が「効率化」「生産性」など社長目線の言葉になる | 「その言葉で、パートさんは何が変わると思うでしょう？」と聞き、職員さんのふだんの困りごとから話し始めるよう直す |
| いきなり全員に発表しようとする | 「当日、拠点の管理者さんが『はじめて聞きました』という顔をしたら、職員さんはどう感じますか？」と聞き、内側から外側への順番にする |
| 小さな成功に、大きくて時間のかかる取り組みを書く | 「3か月以内に、職員さんが『楽になった』と言いそうなことは？」と聞き、すぐできる・目に見えるものにしぼる |
| 任せることが1つも出てこない | 「社長がやったほうが早いこと」を3つ挙げてもらい、その中から1つ選んでもらう |
