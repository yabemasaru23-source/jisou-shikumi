## ① この章でできるようになること

- 「人を育てることについて、わが社が大切にすること」を**育て方の約束**として言葉にできる
- **全員共通・役割別・リーダー**の3段に分けて、誰が教えても同じように人が育つ**育成メニュー表**をつくれる
- 「研修をやった」で終わらせず、**人が本当に育ったかをはかる方法**を決められる
- **リーダーの成長チェック**で、リーダーの得意と伸びしろを点検し、**リーダー成長計画**を立てられる
- お給料や評価のルールを、育成とつなげて考える入り口に立てる

---

## ② なぜ必要なの？

### こんなこと、ありませんか？

- 新しく入った人の育て方が、教える先輩によってまったくちがう
- 「見て覚えて」「わからなかったら聞いて」で、新人さんが何を聞けばいいかもわからずに困っている
- 研修はときどきやるけれど、受けたあとに仕事ぶりが変わったかどうかは、誰も確かめていない
- できる人をリーダーにしたら、自分で全部やってしまい、部下が育たない
- 「がんばっても、がんばらなくても、お給料は同じ」という声が、ちらほら聞こえる

私が社長さんとお話ししていて気づいたのは、**「うちは人が育たない」と悩んでいる会社ほど、育て方が「教える人まかせ」になっている**ということです。
教えるのが上手な先輩についた人は育ち、そうでない人はやめていく。これは、新人さんの能力の問題ではなく、**運の問題**になってしまっています。

第6章の未来の作戦マップには、「🌱自分で考えて動ける職員さんを育てる」「🧭拠点を任せられるリーダーを育てる」のような作戦が入っていませんか。
人が育たなければ、ほかの作戦も、第7章で描いたチーム図の空欄も、うまりません。
この章では、人が育つことを「運」ではなく「仕組み」にしていきます。

### 目指す姿

- 新人さんが「何を・いつまでに・どうやって学べばいいか」を、1枚の育成メニュー表で確かめられる
- どの先輩が教えても、同じ順番・同じ教材で教えられる
- リーダーが自分の伸びしろを知っていて、上司と一緒に成長計画を立てている
- 「ここで働くと、自分が成長できる」と職員さんが感じ、それが長く働く理由になっている

## ③ 考え方

### 1. 人が育つ会社には「時間割」がある

学校を思いうかべてください。
学校には**時間割**があります。どの先生が担任になっても、1年生は1年生で学ぶことを、決まった順番で学びます。だから、担任の先生が変わっても、子どもたちはちゃんと育っていきますよね。

会社の育成も同じです。

| | ✕ 教える人まかせ | ◯ 時間割がある |
|---|---|---|
| 何を学ぶか | 先輩が思いついたことから | 育成メニュー表で決まっている |
| 教え方 | 先輩ごとにバラバラ | 同じ教材（仕事のレシピなど）を使う |
| 育ったかどうか | 「なんとなく大丈夫そう」 | 決めたものさしで確かめる |
| 先輩がやめたら | 育て方ごと消える | 時間割は残る。次の先輩が同じように教えられる |

> 💡 専門用語では、この仕組みを「人材育成システム」、時間割のことを「カリキュラム」といいます。

### 2. まず「育て方の約束」を決める

時間割をつくる前に、決めておきたいことがあります。
それは、**「わが社は、どんなふうに人を育てる会社なのか」**という約束です。

たとえば、こんな言葉です。

- 「失敗しても責めない。いっしょにふり返る」
- 「教えた人も、教わった人も、ほめられる」
- 「わからないことを聞くのは、えらいこと」

この約束は、第4章でつくった**わが社の合言葉**から生まれます。
合言葉に「迷ったら、まず聞く」がある会社なら、育て方の約束にも「聞きやすい空気をつくる」が入るはずです。
合言葉と育て方がちぐはぐだと、新人さんは「言っていることと、やっていることがちがう」と感じてしまいます。

### 3. 「何に困っているか」から始める

育成メニューを考えるときに、いきなり「研修を何にしよう」から始めないでください。
私がおすすめしているのは、**「いま、人が育っていないせいで困っていること」を書き出すこと**です。

- 新人さんが3か月以内にやめてしまう
- ご家族への説明が、人によってちがう
- 拠点長が、数字の話になると黙ってしまう

困りごとが書けたら、「人が育ったら、どうなっている？」と裏返します。
これが、育成で目指すゴールになります。困りごとから始めると、**「なんとなく良さそうな研修」に時間とお金を使ってしまうこと**がなくなります。

### 4. 育成メニューは「3段のお弁当箱」

育成メニューは、3つの段に分けてつくります。お弁当箱を思いうかべてください。いちばん下にごはん、その上におかず、いちばん上にデザートです。

![育成メニューは3段のお弁当箱。いちばん下が全員共通、まん中が役割別、いちばん上がリーダー。どの段も、学び方と教材で教え、育ったかどうかをはかる](assets/img/ch15-menu.svg)

| 段 | 誰が学ぶ？ | 何を学ぶ？ | 例 |
|---|---|---|---|
| 🍚 **全員共通**（ごはん） | 入社したすべての人 | 会社のこと・合言葉・基本ルール・どの仕事でも使う基本の力 | 会社の歴史と夢の完成図、合言葉、個人情報の守り方、電話の受け方、パソコンの基本 |
| 🍳 **役割別**（おかず） | その役割の人 | 役割の約束書を果たすための力と知識 | 拠点長なら「もうけ表の読み方」、事務担当なら「請求の仕事のレシピ」 |
| 🍓 **リーダー**（デザート） | 人をまとめる役割の人・その候補 | チームの行き先を示し、人を育て、仕組みで回す力 | 1対1の応援面談の進め方、任せ方、会議の進め方 |

**役割別の段には、第7章でつくった役割の約束書を使います。**
約束書に書いた「仕事」と「基準」を果たすために、どんな力が足りないか。そこから逆算すれば、役割別のメニューは自然にできあがります。

### 5. 学び方は「聞く・見る・やってみる・教える」を組み合わせる

自転車の乗り方を、本を読んだだけで覚えた人はいませんよね。
見本を見て、後ろを支えてもらいながらこいでみて、転んで、またこいで、やっと乗れるようになります。

| 学び方 | どんなもの？ | 向いていること |
|---|---|---|
| 👂 **聞く** | 研修や勉強会で話を聞く | 会社の歴史、合言葉、ルールなど「知っておくこと」 |
| 👀 **見る** | 先輩の仕事に同行して見る | 声のかけ方、段取りなど「言葉にしにくいこと」 |
| ✋ **やってみる** | 先輩に見守られながら、実際にやってふり返る | 介助の技術、請求の入力など「体で覚えること」 |
| 🗣️ **教える** | 学んだことを、後輩や仲間に説明する | 理解を深めて、自分のものにすること |

いちばん力がつくのは、最後の**「教える」**です。人に説明しようとすると、自分がどこをわかっていないかに気づくからです。
だから私は、「教わった人が、次は教える人になる」順番をメニューに入れることをおすすめしています。

そして、教えるときには**教材**を使います。第11章でつくる**仕事のレシピ**は、そのまま役割別の教材になります。教材があれば、教える先輩が変わっても、教える中身は変わりません。

### 6. 「受けた」で終わらせず、「できた」まではかる

研修をしたあとに、「みんな受けたから大丈夫」で終わっていませんか。
育ったかどうかは、4つの段階ではかれます。

| 段階 | はかること | はかり方の例 |
|---|---|---|
| ① 受けた | 予定どおりに学んだか | 研修を受けた記録表 |
| ② わかった | 中身を理解したか | かんたんなテスト、自分の言葉で説明してもらう |
| ③ できた | 仕事の場でできるようになったか | 先輩のチェック表、同行してのふり返り |
| ④ 成果が出た | 会社の数字が変わったか | 未来の作戦マップのものさし（離職率、ミスの数など） |

①だけをはかっている会社がとても多いのですが、本当に大事なのは③と④です。
**「その研修のあと、明日の仕事の何が変わる？」**と、メニューをつくる段階で決めておきましょう。

### 7. リーダーには「行き先を示す力」と「チームを回す力」がいる

リーダーの成長は、船にたとえるとわかりやすくなります。
船には、**どこへ向かうかを決めて、みんなに伝える力**と、**船をきちんと動かし、乗組員を育てる力**の両方が必要です。

![リーダーの成長チェックの5つの力。リーダーの力として、行き先を示す力・決めてやりぬく力・心に火をつける伝え方。まとめ役の力として、人を育てチームを回す力・仕組みと数字で回す力](assets/img/ch15-leader.svg)

| 種類 | 力 | ひとことで言うと |
|---|---|---|
| 🧭 リーダーの力 | 行き先を示す力 | 先を見て、「ここを目指そう」と描ける |
| | 決めて、やりぬく力 | 迷う場面でも決め、反対があっても最後までやる |
| | 心に火をつける伝え方 | 気持ちをこめて伝え、仲間をその気にさせる |
| 🔧 まとめ役の力 | 人を育て、チームを回す力 | 部下を育て、問題を人のせいにせず解決する |
| | 仕組みと数字で回す力 | 仕組みをつくり、数字を読んで手を打つ |

現場で仕事ができる人ほど、「自分でやったほうが早い」と考えがちです。
でも、リーダーの仕事は**自分が動くことではなく、チームが動くようにすること**です。
ワークの「リーダーの成長チェック」は、点数をつけて落ちこむためのものではありません。**どの力から伸ばすかを決めるための地図**です。上司と一緒につけて、点数が低かった力から、成長計画を立てていきましょう。

> 💡 専門用語では、行き先を示す力などを「リーダーシップ」、チームを回す力などを「マネジメント」といいます。

### 8. がんばりが報われるルールとつなげる

最後に、少しだけお給料と評価の話をします。
どれだけ育成メニューが立派でも、**学んで、できるようになって、成果を出した人が、そうでない人と同じあつかい**だったら、学ぶ気持ちはしぼんでしまいます。

がんばりが報われるルールは、3つの部品でできています。

| 部品 | ひとことで言うと | 育成とのつながり |
|---|---|---|
| 🪜 **段（だん）** | 役割や力に応じた階段 | 育成メニューの段と、階段の段をそろえる |
| 📏 **ものさし** | がんばりを見る基準 | 役割の約束書の基準と、わが社の合言葉どおりの行動 |
| 💴 **お給料** | 段とものさしに応じた支払い | 「この段に上がると、お給料はこう変わる」が見える |

第4章でお話ししたように、ものさしには**「仕事の成果」だけでなく、「合言葉どおりの行動ができているか」も入れる**のがポイントです。
この章では、くわしい制度づくりまでは進みません。まずは「いまのルールのどこで、がんばりが報われていないか」に気づくところまでで十分です。

> 💡 専門用語では、段・ものさし・お給料のルールをまとめて「人事制度（等級制度・評価制度・賃金制度）」といいます。

### ステップ3：育成メニュー表をつくる

まずは**ごはんの段（全員共通）**からです。入社した人なら、役割に関係なく全員が学ぶことを書きます。

```work
id: 15.menu.common
type: table
label: 全員共通の育成メニュー
columns: [学ぶこと, なぜ大事？, 学び方, いつ（入社から）, 教える人・教材]
min_rows: 3
max_rows: 10
hint: 「会社のこと（歴史・夢・合言葉）」「基本のルール」「どの仕事でも使う基本の力」の3つから考えましょう。学び方は、聞く・見る・やってみる・教えるのどれか（組み合わせOK）を書きます。
example:
  - [会社の歴史・夢の完成図・合言葉, 判断に迷ったときのよりどころになるから, 聞く（社長から直接）, 1日目, 社長・会社の取扱説明書]
  - [個人情報と秘密の守り方, ご利用者とご家族の信頼を守るため, 聞く＋小テスト, 1日目, 管理部長・ルールの説明資料]
  - [電話の受け方・ご家族への最初の返事の仕方, どの職員さんが出ても同じ安心を届けるため, 見る＋やってみる, 1週目, 生活相談員・電話の受け方のレシピ]
  - [記録の書き方とタブレットの使い方, 記録と請求の手間を減らすため, やってみる, 2週目, 介護リーダー・記録のひな形]
  - [事故やヒヤリハットの報告の仕方, 小さなことを早く共有して大きな事故を防ぐため, 聞く＋やってみる, 1か月目, 看護職員・報告のレシピ]
  - [合言葉どおりの行動のふり返り, 合言葉を毎日の行動に変えるため, 教える（事例検討会で自分の例を話す）, 3か月目, 拠点長・事例検討会]
```

### ステップ4：育ったかどうかをはかる

### ステップ6：リーダーの成長チェック

チェックするリーダーを1人決めます（社長ご自身でも、拠点長などのリーダーでもかまいません）。
**本人がつけたあと、上司も同じように点数をつけて見比べる**と、思いこみに気づけます。

```work
id: 15.leader.check
type: scale
label: リーダーの成長チェック
scale: [{value: 2, label: いつもできている}, {value: 1, label: ときどき}, {value: 0, label: まだ}]
groups:
  - name: 行き先を示す力
    items:
      - 3年後のチームの姿を、自分の言葉で部下に話せる
      - 目の前の仕事だけでなく、半年先・1年先のことを考える時間をとっている
      - 「いつもこうだから」で終わらせず、もっと良いやり方がないか探している
      - たくさんのやることの中から、いちばん大事なことを選べる
  - name: 決めて、やりぬく力
    items:
      - 情報が全部そろっていなくても、期限までに決められる
      - 反対の声があっても、理由を説明して前に進められる
      - 始めたことを、途中で投げださず最後までやりとげる
      - うまくいかなそうな気配に早めに気づき、先に手を打てる
  - name: 心に火をつける伝え方
    items:
      - 会社の夢や合言葉を、気持ちをこめて伝えられる
      - 言っていることと、やっていることが一致している
      - 部下の意見を引き出し、「やってみよう」と思わせられる
      - 大事なことは、くり返し何度でも伝えている
  - name: 人を育て、チームを回す力
    items:
      - 部下と定期的に1対1で話し、成長を応援している
      - 自分でやったほうが早い仕事も、部下に任せて育てている
      - 問題が起きたとき、人を責めずに「仕組みのどこが原因か」を考えられる
      - 仕事の基準を部下に伝え、その基準を自分も守っている
  - name: 仕組みと数字で回す力
    items:
      - 毎月の数字を読んで、良い・悪いの理由を説明できる
      - 数字を見て、「次に何をするか」を決められる
      - くり返し起きる困りごとを、仕組みやレシピにして解決している
      - 予算や人の手を考えて、無理のない計画を立てられる
hint: 「できていると思いたいこと」ではなく、この1か月の実際の行動で答えましょう。迷ったら「部下に聞いたら、同じ答えをくれるかな？」と考えてみてください。
example:
  行き先を示す力: [1, 1, 2, 1]
  決めて、やりぬく力: [1, 1, 2, 1]
  心に火をつける伝え方: [2, 2, 2, 1]
  人を育て、チームを回す力: [2, 1, 1, 2]
  仕組みと数字で回す力: [0, 0, 1, 1]
```

#### 結果の見方

| それぞれの力の点数（8点満点） | いまの状態 |
|---|---|
| 7〜8点 | 🍎 **得意な力**：まわりのリーダーに教える側に回れます |
| 4〜6点 | 🌳 **育ってきた力**：場面によってムラがあります。できている場面を増やしましょう |
| 0〜3点 | 🌱 **伸びしろの力**：ここから成長計画を立てると、いちばん変化が大きくなります |

```work
id: 15.leader.plan
type: table
```

## ⑦ 次の章へ

これで、人の仕組みの3つの章（仲間集め・入社90日の歓迎プラン・人が育つ仕組み）がそろいました。
**合言葉に共感する仲間と出会い、最初の90日で迎え入れ、誰が教えても育っていく**。この流れが回りはじめると、第7章のチーム図の空欄が、少しずつうまっていきます。

次の**第16章「お客様との約束と体験マップ」**からは、お客様の仕組みに入ります。
育った職員さんたちが、お客様にどんな気持ちを届けるのか。その「約束」を決めて、お客様が出会いからお別れまでに通る道すじを1枚の地図にしていきます。
この章でつくった育成メニューに、「お客様との約束」を学ぶ時間を加えるのも忘れないでくださいね。

## ⑧ 講師ガイド

### この回のねらい
受講者が、育成で目指す姿と育て方の約束を決め、全員共通・役割別・リーダーの3段の育成メニュー表の下書きをつくり、リーダー1人の成長チェックと成長計画を完成させること。

### 事前準備
- 受講者には、第4章（合言葉）・第7章（チーム図と役割の約束書）を終えてから参加してもらう
- いまある研修や勉強会の一覧、新人さんに渡している資料（あれば）、最近1年でやめた人の人数を持ってきてもらう
- 3段のお弁当箱を描いた育成メニュー表の記入用紙（A3）と、付せん（3色：全員共通＝黄、役割別＝緑、リーダー＝ピンク）
- リーダーの成長チェックの用紙を2枚ずつ（本人用と上司用）

### 時間配分（90分の例）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0:00〜0:05 | チェックイン | 「自分がいちばん成長できた職場や先生」を1人1文で発表 |
| 0:05〜0:20 | お話：③考え方の1〜4 | 学校の時間割のたとえと、3段のお弁当箱を見せる。「教える人まかせは運の問題」を強調する |
| 0:20〜0:30 | ワーク：ステップ2（困りごとと育て方の約束） | 困りごとを3つ以上出してから、合言葉を見ながら約束を書く |
| 0:30〜0:50 | ワーク：ステップ3（育成メニュー表） | 3色の付せんで出してから表に書く。役割別は3つの役割にしぼってよい |
| 0:50〜1:00 | お話：③考え方の5〜8 | 学び方の4つと、はかる4段階。がんばりが報われるルールは概要だけにする |
| 1:00〜1:10 | ワーク：ステップ4〜5 | 「できた」「成果」をはかる方法を必ず1つずつ入れる |
| 1:10〜1:25 | ワーク：ステップ6〜7（リーダーの成長チェックと成長計画） | 自分か、育てたいリーダー1人でつける。点数が低い力から計画を立てる |
| 1:25〜1:30 | まとめ | リーダー本人と上司で点数を見比べる日を決めて終了 |

### 問いかけの例
- 「その先輩がやめたら、新人さんへの教え方はどうなりますか？」（教える人まかせになっているとき）
- 「その研修を受けたあと、明日の仕事の何が変わりますか？」
- 「その役割の約束書の基準を果たすには、どんな力が足りませんか？」（役割別メニューが思いつかないとき）
- 「部下に同じ質問をしたら、同じ点数をつけてくれそうですか？」（リーダーの成長チェックが高すぎるとき）
- 「新しいことを学んで、できるようになった人は、いまの会社でどう報われますか？」

### よくあるつまずき

| つまずき | 対応 |
|---|---|
| 「研修をやる」「勉強会を開く」がゴールになってしまう | 「研修のあと、誰がどうなっていたら成功ですか？」と聞いて、困りごとの裏返しの姿にする |
| 全員共通の段に、専門的な技術まで入れて重くなる | 「事務の人にも必要ですか？」と聞いて、役割別の段に移す |
| 役割別メニューを全部の役割でつくろうとして時間切れになる | 人数の多い役割か、空欄の多い役割から3つにしぼってよいと伝える |
| 学び方が「聞く（研修）」ばかりになる | 自転車のたとえで、「見る」「やってみる」「教える」を1つは入れてもらう |
| リーダーの成長チェックで全部「いつもできている」をつける | この1か月の具体的な場面を1つ思い出してもらう。上司の点数と見比べる時間をとる |
| 点数が低くて落ちこむ | 「点数が低い力は、いちばん伸びる力です」と伝え、成長計画の1行目にする |
| お給料や評価のルールの話で時間がとられる | この章では「どこが報われていないか」に気づくところまで、と区切る。制度づくりは別の時間に専門家と進める |
